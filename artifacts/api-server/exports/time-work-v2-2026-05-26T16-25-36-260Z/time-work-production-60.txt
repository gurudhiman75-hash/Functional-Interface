Q1. The total wage is ₹9000. Actual work contributions are 24:36:40. Find the share.
A. ₹3240
B. ₹2156
C. ₹2163
D. ₹2160
Answer: ₹2160
Difficulty: Medium
Family: tw_wage_distribution_efficiency
Explanation:
Convert each person's work into contribution units.
\[
Share=\frac{c_i}{\sum c}\times W
\]
Use contribution ratio for the share.
\[
Share=\frac{24}{100}\times 9000
\]
Apply the wage or contract amount.
\[
Share=2160
\]
Shortcut / Exam Method:
\[
Share=contribution\ ratio\times wage
\]
Answer: ₹2160
