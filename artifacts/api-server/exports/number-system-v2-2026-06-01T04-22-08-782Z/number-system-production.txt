Q1. Digit sum \(13\) is given for a two-digit number. If the tens digit is \(7\), what is the number?
A. \(75\)
B. \(78\)
C. \(76\)
D. \(77\)
Answer: C

Explanation:
Concept
Digit questions convert place values into equations.

Given
Digit sum \(13\) is given for a two-digit number. If the tens digit is \(7\), what is the number?

Working
Use the digit sum to find the ones digit.
\[
7+u=13\Rightarrow u=6
\]
Now write the two-digit number by place value.
\[
N=10\times 7+6=76
\]
Therefore, the required answer is \(76\).
Hence, the correct answer is Option (C).

Shortcut / Exam Method
Find the missing digit from the digit sum, then place it.
\[
76
\]
Answer: \(76\), Option (C).


Hindi:

विचार
अंक वाले प्रश्न स्थान-मूल्य को समीकरण में बदलते हैं।

दिया गया
दो-अंकीय संख्या के लिए अंक-योग \(13\) दिया है। यदि दहाई अंक \(7\) है, तो संख्या क्या है?

हल

\[
N=10\times 7+6
\]

Q2. The number \(98x61\) is divisible by \(11\). What is the value of \(x\)?
A. \(5\)
B. \(3\)
C. \(6\)
D. \(4\)
Answer: D

Explanation:
Concept
Use the divisibility rule that fits the given divisor.

Given
The number \(98x61\) is divisible by \(11\). What is the value of \(x\)?

Working
Use the divisibility rule for 11; the chosen digit must make the completed number divisible by 11.
Test the valid digit in the blank.
\[
98x61\Rightarrow 98461
\]
Now verify divisibility.
\[
98461\div 11=8951
\]
Therefore, the required answer is \(4\).
Hence, the correct answer is Option (D).

Shortcut / Exam Method
Direct check: replace \(x\) by \(4\) in \(98x61\).
\[
98461\equiv 0\pmod{11}
\]
Answer: \(4\), Option (D).


Hindi:
संख्या \(98x61\), \(11\) से विभाज्य है। \(x\) का मान क्या है?
विचार
दिए गए भाजक के अनुसार विभाज्यता नियम लगाएं।

दिया गया
संख्या \(98x61\), \(11\) से विभाज्य है। \(x\) का मान क्या है?

हल
लुप्त अंक ऐसा होना चाहिए कि पूरी संख्या दिए गए भाजक से विभाज्य हो।

Q3. Between \(116\) and \(207\), how many integers are divisible by \(9\)?
A. \(11\)
B. \(12\)
C. \(10\)
D. \(13\)
Answer: A

Explanation:
Concept
Count multiples using the first valid multiple and the last valid multiple.

Given
Between \(116\) and \(207\), how many integers are divisible by \(9\)?

Working
Find the first multiple inside the range and the last multiple inside the range.
\[
117,\ 207
\]
Count the terms in this arithmetic sequence of multiples.
\[
\frac{207-117}{9}+1=11
\]
This avoids listing every integer in the interval.
Therefore, the required answer is \(11\).
Hence, the correct answer is Option (A).

Shortcut / Exam Method
Fast count with quotient floors.
\[
\left\lfloor\frac{207}{9}\right\rfloor-\left\lfloor\frac{115}{9}\right\rfloor=11
\]
Answer: \(11\), Option (A).


Hindi:
\(116\) और \(207\) के बीच कितने पूर्णांक \(9\) से विभाज्य हैं?

हल

\[

Q4. Two buses leave a stand every \(132\) and \(204\) minutes. When will they next leave together?
A. \(2020\)
B. \(2244\)
C. \(2468\)
D. \(2693\)
Answer: B

Explanation:
Concept
HCF-LCM questions use common factor or common multiple structure.

Given
Two buses leave a stand every \(132\) and \(204\) minutes. When will they next leave together?

Working
For first common repetition, use LCM.
Compare the prime-factor forms of the two numbers.
\[
132=2^{2}\times 3\times 11,\ 204=2^{2}\times 3\times 17
\]
Choose common lowest powers for HCF and highest powers for LCM.
\[
\operatorname{LCM}(132,204)=2244
\]
Therefore, the required answer is \(2244\).
Hence, the correct answer is Option (B).

Shortcut / Exam Method
Exam cue: common division means HCF; repeat together means LCM.
\[
2244
\]
Answer: \(2244\), Option (B).


Hindi:
दो बसें \(132\) और \(204\) मिनट बाद-बाद स्टैंड से चलती हैं। वे अगली बार साथ कब चलेंगी?
विचार
HCF-LCM प्रश्नों में साझा गुणनखंड या साझा गुणज की संरचना होती है।

दिया गया
दो बसें \(132\) और \(204\) मिनट बाद-बाद स्टैंड से चलती हैं। वे अगली बार साथ कब चलेंगी?

हल
साझा विभाजन के लिए HCF और साझा दोहराव के लिए LCM लें।

Q5. After prime factorising \(12\), what is the number of positive divisors?
A. \(7\)
B. \(5\)
C. \(8\)
D. \(6\)
Answer: D

Explanation:
Concept
Factor questions become simple after writing prime powers.

Given
After prime factorising \(12\), what is the number of positive divisors?

Working
First write the number as prime powers.
\[
12=2^{2}\times 3
\]
Each exponent contributes one more choice than its value.
\[
d(n)=(2+1)\times (1+1)=6
\]
Therefore, the required answer is \(6\).
Hence, the correct answer is Option (D).

Shortcut / Exam Method
Exponent-choice shortcut.
\[
(2+1)\times (1+1)
\]
Answer: \(6\), Option (D).

\]

\[

\]

Locate the exponent inside the cycle.

(57-1)\bmod 3+1=3
\]
Take the remainder at that cycle position.
\[

\]
Therefore, the required answer is \(1\).
