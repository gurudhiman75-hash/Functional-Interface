Explanation EN:
Assume D's income = 100.
Since C is 40% more than D, C = 100 x 140 / 100 = 140.
Since B is 25% less than C, B = 140 x 75 / 100 = 105.
Since A is 40% more than B, A = 105 x 140 / 100 = 147.
Compared with D = 100, A is 47% more.
