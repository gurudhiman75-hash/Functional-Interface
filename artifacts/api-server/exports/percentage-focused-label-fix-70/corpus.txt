ਅੰਤਿਮ ਮੁੱਲ =
100 x 140 / 100
= 140

ਅਗਲਾ ਪ੍ਰਤੀਸ਼ਤ ਸੰਬੰਧ ਲਗਾਓ:
ਅੰਤਿਮ ਮੁੱਲ =
140 x 60 / 100
= 84

ਅਗਲਾ ਪ੍ਰਤੀਸ਼ਤ ਸੰਬੰਧ ਲਗਾਓ:
ਅੰਤਿਮ ਮੁੱਲ =
84 x 140 / 100
= 117.6

= 17.6%
