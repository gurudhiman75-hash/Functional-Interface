Q1. With digit sum \(10\), a two-digit number has \(8\) in the tens place. Which number is it?
A. \(83\)
B. \(81\)
C. \(84\)
D. \(82\)
Answer: D

Explanation:
Concept
Digit questions convert place values into equations.

Given
With digit sum \(10\), a two-digit number has \(8\) in the tens place. Which number is it?

Working
Use the digit sum to find the ones digit.
\[
8+u=10\Rightarrow u=2
\]
Now write the two-digit number by place value.
\[
N=10\times 8+2=82
\]
Therefore, the required answer is \(82\).
Hence, the correct answer is Option (D).

Shortcut / Exam Method
Find the missing digit from the digit sum, then place it.
Answer: \(82\), Option (D).


Hindi:

Q2. The number \(114x8\) is divisible by \(12\). What is the value of \(x\)?
A. \(3\)
B. \(6\)
C. \(4\)
D. \(5\)
Answer: C

Explanation:
Concept
Use the divisibility rule that fits the given divisor.

Given
The number \(114x8\) is divisible by \(12\). What is the value of \(x\)?

Working
Use the divisibility rule for 12; the chosen digit must make the completed number divisible by 12.
Test the valid digit in the blank.
\[
114x8\Rightarrow 11448
\]
Now verify divisibility.
\[
11448\div 12=954
\]
Therefore, the required answer is \(4\).
Hence, the correct answer is Option (C).

Shortcut / Exam Method
Direct check: replace \(x\) by \(4\) in \(114x8\).
\[
11448\equiv 0\pmod{12}
\]
Answer: \(4\), Option (C).

Q3. Between \(114\) and \(220\), how many integers are divisible by \(18\)?
A. \(8\)
B. \(6\)
C. \(7\)
D. \(5\)
Answer: B

Explanation:
Concept
Count multiples using the first valid multiple and the last valid multiple.

Given
Between \(114\) and \(220\), how many integers are divisible by \(18\)?

Working
Find the first multiple inside the range and the last multiple inside the range.
\[
126,\;216
\]
Count the terms in this arithmetic sequence of multiples.
\[
\frac{216-126}{18}+1
\]
Now simplify the gap and add the first term.
\[
\frac{90}{18}+1=5+1=6
\]
This avoids listing every integer in the interval.
Therefore, the required answer is \(6\).
Hence, the correct answer is Option (B).

Shortcut / Exam Method
Fast count with quotient floors.
\[
\left\lfloor\frac{220}{18}\right\rfloor=12,\quad \left\lfloor\frac{113}{18}\right\rfloor=6
\]
\[
12-6=6
\]
Answer: \(6\), Option (B).


Hindi:

Q4. For two numbers \(66\) and \(42\), which common multiple is first reached?
A. \(462\)
B. \(485\)
C. \(508\)
D. \(439\)
Answer: A

Explanation:
Concept
HCF-LCM questions use common factor or common multiple structure.

Given
For two numbers \(66\) and \(42\), which common multiple is first reached?

Working
For first common repetition, use LCM.
Compare the prime-factor forms of the two numbers.
\[
66=2\times 3\times 11,\ 42=2\times 3\times 7
\]
Choose common lowest powers for HCF and highest powers for LCM.
\[
\operatorname{LCM}(66,42)=462
\]
Therefore, the required answer is \(462\).
Hence, the correct answer is Option (A).

Shortcut / Exam Method
Exam cue: common division means HCF; repeat together means LCM.
Answer: \(462\), Option (A).

Q5. For the number \(1440\), find the count of positive divisors?

D. \(37\)
Answer: C

Concept

Given
For the number \(1440\), find the count of positive divisors?

\[

\]

\[
d(n)=(5+1)\times (2+1)\times (1+1)=36

Factorial exponent questions count prime factors inside the factorial.

Given

\[

Concept
Count multiples using the first valid multiple and the last valid multiple.

Given

Working
Find the first multiple inside the range and the last multiple inside the range.
\[

\]

\[

\]

\[

\]
This avoids listing every integer in the interval.

Factorial exponent questions count prime factors inside the factorial.

Q60. What remainder will \(11^{24}\) leave on division by \(5\)?

B. \(3\)

D. \(2\)
Answer: C

Explanation:
Concept
Large powers are handled by modular cycles.

Given
What remainder will \(11^{24}\) leave on division by \(5\)?

Reduce the base first so the numbers stay small.
\[

\]
Write the repeating remainder cycle.
\[

\]
Locate the exponent inside the cycle.
\[
(24-1)\bmod 1+1=1
\]
Take the remainder at that cycle position.
\[

\]
Therefore, the required answer is \(1\).
Hence, the correct answer is Option (C).

Shortcut / Exam Method
Index the repeating list; do not expand the power.
\[

\]
