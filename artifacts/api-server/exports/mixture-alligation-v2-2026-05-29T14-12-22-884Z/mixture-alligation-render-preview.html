Concept

This is an alligation question. The required mean lies between the lower and higher values, so the quantities must balance the two gaps from the mean.

Given
Higher value = 80
Lower value = 48
Mean value = 60
Alligation Diagram
80
48
60
12
20
Working

Difference between 80 and 60:

80 - 60 = 20

Difference between 60 and 48:

60 - 48 = 12

Opposite differences give the required ratio.

Cq:Dq = 20:12 = 5:3
Shortcut / Exam Method

Write the opposite differences directly.

(D-M):(M-C)
(80-60):(60-48)=20:12=5:3

Therefore, the required answer is 5:3. Hence, the correct answer is Option (A).
