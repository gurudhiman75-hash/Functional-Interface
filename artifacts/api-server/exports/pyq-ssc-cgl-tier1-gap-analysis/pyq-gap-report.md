## Gap Findings
- **SSC Quant topic coverage**: Percentage and Profit/Loss cover only part of the extracted SSC CGL Quant mix; geometry, algebra, time-work, ratio, speed-distance, SI/CI, trigonometry, and DI need their own V2 chapters.
- **Percentage DI hybrid**: PYQs frequently ask percentage/comparison questions from bar graphs, pie charts, tables, imports, sales, and poverty-line data. Standalone Percentage V2 should add lightweight DI-percentage families if it is expected to cover SSC Tier 1 patterns.
- **Profit/Loss inventory and discount comparison**: Extracted PYQs include partial stock allocation, bill discount differences, maximum discount comparison, faulty weighing, dozen/unit conversion, and markup-discount inverses. Profit/Loss has many of these families, but needs more high-scale distractor-safe variants.
- **OCR extraction**: Many SSC official/challenge PDFs expose low-quality text layers. Re-run this audit with --ocr for the folder to extract those pages.
