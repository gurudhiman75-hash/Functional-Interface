\[

\]

Digit sum of 89 is 17.

Final Answer

Q2. The number \(298x4\) is divisible by \(12\). What is the value of \(x\)?
A. \(3\)
B. \(6\)
C. \(4\)
D. \(5\)
Answer: C

Explanation:
Step 1: Split the rule for 12

A number divisible by 12 must be divisible by both 3 and 4.

\[
N\equiv 0\pmod{3}
\]

\[
N\equiv 0\pmod{4}
\]

Step 2: Use the digit sum for divisibility by 3

The known digit sum is 23.

\[
23+x\equiv 0\pmod{3}
\]

Step 3: Use the last-two-digits rule for 4

The last two digits must form a number divisible by 4.

\[
10x+4=44
\]

\[
44\equiv 0\pmod{4}
\]

Step 4: Combine both conditions

The digit satisfying both tests is 4.

\[
23+x=27
\]

\[
x=4
\]

Answer Verification
With \(x=4\), the tests for 3 and 4 are both satisfied.
\[
23+4=27
\]
\[
27\equiv 0\pmod{3}
\]
\[
44\equiv 0\pmod{4}
\]

Final Answer
Therefore, the correct answer is Option (C). Computed value: \(4\).

Shortcut

Check 3 from the digit sum and 4 from the last two digits.

\[
x\equiv 4\pmod{3}
\]

\[
10x+4\equiv 0\pmod{4}
\]

\[
x=4
\]

Fast result: \(4\). Therefore, the correct answer is Option (C).

Q3. Between \(129\) and \(281\), how many integers are divisible by \(8\)?
A. \(21\)
B. \(19\)
C. \(20\)
D. \(18\)
Answer: B

Explanation:
Step 1: Find the first valid multiple

Therefore, the first multiple of 8 greater than 129 is 136.

\[
8\times 17=136
\]

Step 2: Find the last valid multiple

Therefore, 280 is the greatest multiple of 8 not exceeding 281.

\[
281=8\times 35+1
\]

\[
281-1=280
\]

Step 3: Count the valid multiples

The multiples form an arithmetic progression with common difference 8.

\[
\frac{280-136}{8}+1=18+1=19
\]

Answer Verification
The total number of multiples is 19.
Hence, there are 19 multiples of 8 in the given range.

Final Answer
Therefore, the correct answer is Option (B). Computed value: \(19\).

Shortcut

Count multiples using quotient floors on the range limits.

\[
\left\lfloor\frac{281}{8}\right\rfloor-\left\lfloor\frac{128}{8}\right\rfloor
\]

\[
35-16=19
\]

Fast result: \(19\). Therefore, the correct answer is Option (B).

\[

The multiples form an arithmetic progression with common difference 9.

\[
\frac{252-180}{9}+1=8+1=9

The total number of multiples is 9.

\[
