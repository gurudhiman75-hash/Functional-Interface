Q1. Tens digit \(3\), digit sum \(5\): which two-digit number satisfies both facts?
A. \(31\)
B. \(34\)
C. \(32\)
D. \(33\)
Answer: C

Explanation:
Concept
Digit questions convert place values into equations.

Given
Tens digit \(3\), digit sum \(5\): which two-digit number satisfies both facts?

Working
Use the digit sum to find the ones digit.
\[
3+u=5\Rightarrow u=2
\]
Now write the two-digit number by place value.
\[
N=10\times 3+2=32
\]
Therefore, the required answer is \(32\).
Hence, the correct answer is Option (C).

Shortcut / Exam Method
Find the missing digit from the digit sum, then place it.
\[
32
\]
Answer: \(32\), Option (C).


Hindi:

विचार

हल

\[

\]

Q2. The number \(4x125\) is divisible by \(11\). What is the value of \(x\)?
A. \(9\)
B. \(7\)
C. \(6\)
D. \(8\)
Answer: D

Explanation:
Concept
Use the divisibility rule that fits the given divisor.

Given
The number \(4x125\) is divisible by \(11\). What is the value of \(x\)?

Working
Use the divisibility rule for 11; the chosen digit must make the completed number divisible by 11.
Test the valid digit in the blank.
\[
4x125\Rightarrow 48125
\]
Now verify divisibility.
\[
48125\div 11=4375
\]
Therefore, the required answer is \(8\).
Hence, the correct answer is Option (D).

Shortcut / Exam Method
Direct check: replace \(x\) by \(8\) in \(4x125\).
\[
48125\equiv 0\pmod{11}
\]
Answer: \(8\), Option (D).

Q3. Between \(157\) and \(237\), how many integers are divisible by \(6\)?
A. \(13\)
B. \(14\)
C. \(12\)
D. \(15\)
Answer: A

Explanation:
Concept
Count multiples using the first valid multiple and the last valid multiple.

Given
Between \(157\) and \(237\), how many integers are divisible by \(6\)?

Working
Find the first multiple inside the range and the last multiple inside the range.
\[
162,\ 234
\]
Count the terms in this arithmetic sequence of multiples.
\[
\frac{234-162}{6}+1=13
\]
This avoids listing every integer in the interval.
Therefore, the required answer is \(13\).
Hence, the correct answer is Option (A).

Shortcut / Exam Method
Use first-last multiple count directly.
\[
\frac{234-162}{6}+1=13
\]
Answer: \(13\), Option (A).

Concept
HCF-LCM questions use common factor or common multiple structure.

Given
Two buses leave a stand every \(132\) and \(204\) minutes. When will they next leave together?

Working
For first common repetition, use LCM.
Prime-factor or Euclidean comparison gives the required common measure.
\[
\operatorname{LCM}(132,204)=2244
\]
Therefore, the required answer is \(2244\).
Hence, the correct answer is Option (B).

Shortcut / Exam Method
Pick HCF for common division and LCM for common repetition.
\[

\]

Concept
Factor questions become simple after writing prime powers.

Given
After prime factorising \(12\), what is the number of positive divisors?

Working
First write the number as prime powers.
\[

\]
Each exponent contributes one more choice than its value.
\[
d(n)=(2+1)\times (1+1)=6
\]
Therefore, the required answer is \(6\).

\]

Concept
Large powers are handled by modular cycles.

Given
What remainder will \(3^{51}\) leave on division by \(7\)?

Working
Reduce the base first so the numbers stay small.
\[
3\equiv 3\pmod{7}
\]
Write the repeating remainder cycle.
\[
3,\ 2,\ 6,\ 4,\ 5,\ 1
\]
Locate the exponent inside the cycle.
\[
(51-1)\bmod 6+1=3
\]
Take the remainder at that cycle position.
\[
6
\]
Therefore, the required answer is \(6\).
Hence, the correct answer is Option (C).

Use only the cycle position.
\[
51\equiv 3\text{ position in cycle}

Q59. A large power \(3^{27}\) is divided by \(5\). What is the remainder?
A. \(2\)
B. \(3\)
C. \(1\)
D. \(4\)
Answer: A

Explanation:
Concept
Large powers are handled by modular cycles.

Given
A large power \(3^{27}\) is divided by \(5\). What is the remainder?

Working
Reduce the base first so the numbers stay small.
\[
3\equiv 3\pmod{5}
\]
Write the repeating remainder cycle.
\[
3,\ 4,\ 2,\ 1
\]
Locate the exponent inside the cycle.
\[
(27-1)\bmod 4+1=3
\]
Take the remainder at that cycle position.
\[
2
\]
Therefore, the required answer is \(2\).
Hence, the correct answer is Option (A).

Shortcut / Exam Method
Use only the cycle position.
\[
27\equiv 3\text{ position in cycle}
\]
Answer: \(2\), Option (A).
