## Audit policy
Only examples that can be grounded in a natural Punjabi sentence with one clear grammatical role are retained.

The following remain quarantined:
- KARAN: donor records mix conjunctions and causal linkers with adverbs
- TAKID: donor records mix particles and emphasis markers with adverbs
- NIRNAY: donor records include discourse responses rather than a clean adverb class
- positive/comparative/superlative degree table: rejected as an imported English-style model of Punjabi comparison
- bare units such as ਕਿਲੋਗ੍ਰਾਮ, ਟਨ and ਕੁਇੰਟਲ: not adjective authorities by themselves
