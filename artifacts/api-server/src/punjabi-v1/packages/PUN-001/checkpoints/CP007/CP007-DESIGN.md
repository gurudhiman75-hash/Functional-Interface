# CP007 Design Contract

The checkpoint is intentionally split by operation rather than by one broad topic generator. Easy questions identify one grammatical feature. Medium questions map a feature to its sentence role or classify a governed connector. Hard questions combine two authorities or verify two independent grammatical claims.

This prevents difficulty relabeling, keeps distractors close to the tested sentence, and gives the reviewer separate surfaces for case, sambandhak, conjunction and interjection quality.
