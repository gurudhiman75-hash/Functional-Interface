## Audit model
The historical donor mixed three different evidence levels:
1. an affix exists and has a governed meaning;
2. a word genuinely uses that affix;
3. the exact recoverable root is known.

This retrofit keeps those levels separate.

### Membership layer
A donor word is retained only when:
- the affix is materially present in the word;
- the word is not in the donor's known false-root/trap surface;
- the mapping is not ambiguous with another governed affix;
- the formation is exam-grade and non-synthetic.

All 48 previously reviewed derivations remain represented in the membership bank.

### Root layer
Root-recovery families use only explicit audited root records.

Four donor root rows are excluded from root testing:
- `ਗ਼ੈਰਕਾਨੂੰਨੀ` — more than one morphological operation is involved;
- `ਲਿਖਾਵਟ` — stem/suffix change is not represented by simple root + affix;
- `ਸਮਾਜਿਕ` — donor affix label does not match the audited affix surface cleanly enough for simple decomposition;
- `ਲੋੜਵੰਦ` — donor root affix is absent from the audited donor affix inventory.

These words may remain valid lexical formations elsewhere, but they are not simplified into misleading root equations.
