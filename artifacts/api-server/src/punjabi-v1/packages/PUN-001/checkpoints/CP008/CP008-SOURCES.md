## Inputs
Historical donor:
- 60 prefix rows
- 60 suffix rows
- 24 explicit root-word rows
- 300 listed prefix-word examples
- 300 listed suffix-word examples

After duplicate affix rows are collapsed:
- 36 retained prefix concepts
- 33 retained suffix concepts
- 69 total audited affix concepts

## Final authority layers
- 374 high-confidence word↔affix memberships
  - 205 prefix memberships
  - 169 suffix memberships
- 63 explicit root derivations
  - 33 prefix-root derivations
  - 30 suffix-root derivations

## Quality exclusions
The donor contains repeated affix rows, words whose opening/ending letters only resemble an affix, and several lexicalized or etymologically mixed examples. Those are not promoted merely because they occur in donor arrays.

Known false-root/spurious lists are reference-only because some legacy trap entries themselves are inconsistent.

Root recovery requires stronger evidence than affix membership. Multi-operation or stem-changing donor root rows are excluded from simple root equations.

No fixed target count is used.
