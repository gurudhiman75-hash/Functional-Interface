# CP014 Approval Gate

CP014 is a human-review checkpoint.

Approval of the Markdown review pack authorizes forward-port closeout work only. It does not itself authorize permanent QL allocation, Question Studio registration, Question Bank writes, mock/test eligibility, or public/student delivery.

Any material change to learner-facing passages, question authorities, terminology mappings, or generation behavior after approval creates a new review head and requires renewed editorial approval.
