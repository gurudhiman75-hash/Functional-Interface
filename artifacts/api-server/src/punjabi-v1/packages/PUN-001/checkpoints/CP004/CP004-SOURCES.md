# CP004 Retrofit Source and Donor Boundary

## Inputs
- historical CP004 donor corpus
- previously approved CP004 forward-port authority bank

## Donor inventory
- 90 gender rows
- 70 number rows
- 8 oblique-case records

Oblique-case material is excluded from CP004 because it belongs to case grammar.

## Audit result
- 58 distinct high-confidence gender concepts
- 66 distinct high-confidence number concepts
- 12 retained reviewed agreement contexts

Duplicate donor rows are provenance only.

Ambiguous or invalid gender relations and weak number forms are excluded rather than retained for count. Existing reviewed authorities not present in donor are preserved.

No fixed numerical target is used.
