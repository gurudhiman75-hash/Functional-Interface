A 3-member committee is chosen at random from 10 men and 5 women. What is the probability that it contains exactly 1 woman?
  1. A.15/182
  2. B.45/92
  3. C.46/91
  4. D.45/91
  5. E.44/91
Correct answerD. 45/91

Worked solution

Method
A committee is an unordered selection. Use C(n, r) = n!/[r!(n-r)!]. For a probability, divide the number of required committees by the total number of committees.
  1. Total committees = C(15, 3).
  2. C(15, 3) = 15!/(3! × 12!) = (15 × 14 × 13)/(3 × 2 × 1) = 455.
  3. Choose 1 woman from 5: C(5, 1) = 5.
  4. Choose 2 men from 10: C(10, 2) = 10!/(2! × 8!) = (10 × 9)/(2 × 1) = 45.
  5. Required committees = 5 × 45 = 225.
  6. Probability = favourable cases ÷ total cases = 225/455.
Simplification
Divide the numerator and denominator by 5: (225 ÷ 5)/(455 ÷ 5) = 45/91.
Key point
Combinations count each committee once because changing the order of the same members does not create a different committee.
Final answer
The required probability is 45/91.
