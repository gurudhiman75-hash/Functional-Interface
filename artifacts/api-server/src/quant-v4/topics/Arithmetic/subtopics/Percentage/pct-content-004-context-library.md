# PCT-CONTENT-004 Context Library

Editorial-only context guidance for Percentage PCT-001 through PCT-005. This file is not a runtime contract.

## Phase C audit signals

The audit showed repeated overuse of abstract, money, population, education, production, and inventory contexts. The underrepresented context families were hospital/clinic, technology, transport passengers, animals/wildlife, area/agriculture, government records, museums/libraries, insurance, banking, electricity, rainfall, and water supply.

## Added or strengthened context families

| Context family | Intended use |
| --- | --- |
| Hospital / clinic | Direct increase/decrease, recovery from final value, percentage share, budget and patient-count situations. |
| Technology / internet usage | App usage, website traffic, subscriber counts, index/multiplier questions. |
| Transport / railway / airport / bus | Passenger counts, seat capacity, ridership changes, comparative branch-style questions. |
| Banking / insurance | Percentage of known total, premium adjustment, rebate/multiplier, amount-of-change questions. |
| Wildlife / animals | Ratio-to-percentage, survey/statistical-note contexts, population share. |
| Museums / libraries | Direct percent-of and ratio/share situations where counts are natural. |
| Agriculture / rainfall / crop area | Yield, loss, area-share, rainfall collection, and distribution questions. |
| Government / committee / statistical records | Net percentage change, survey tables, census/election-style reporting. |

## Editorial rule

Use these contexts only when they naturally fit the existing CP mathematics. Do not force a context if it makes the stem longer without changing the educational situation.
