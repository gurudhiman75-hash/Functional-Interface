## Non-English QL Selection Guard

- `foundation/parameter-generator.ts` keeps English selection unchanged.
- For `language="hi"` and `language="pa"`, selectable QLs are restricted to:
  - `PCT-QL-001`
  - `PCT-QL-002`
  - `PCT-QL-003`
  - `PCT-QL-004`
- This guard applies to random backend selection and direct backend generation.
- Forced non-English generation for QLs outside the allowlist is rejected.

## Why hi/pa Random Runtime Is Restricted To Localized Pilot QLs

- The hi/pa files still contain English placeholder-copy stems for `PCT-QL-005` to `PCT-QL-020`.
- Random non-English selection must not land on untranslated entries while the pilot is partial.
- Restricting random hi/pa selection to the localized QLs prevents accidental mixed-language output during backend smoke runs and manual checks.
- This keeps the backend pilot safe without expanding translation scope prematurely.
