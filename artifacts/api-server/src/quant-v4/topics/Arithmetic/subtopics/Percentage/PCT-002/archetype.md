# PCT-002: Percentage Transformations

## Mission

PCT-002 restores the foundational transformation layer of the Percentage roadmap. It sits after direct percentage-of-known-number work and before increase, decrease, and successive percentage change.

## Educational Boundary

- Focus: single-base percentage transformations.
- Scope: whole from part, another percentage from known percentage, reverse mapping, ratio-percentage conversion, complements, partitions, and single-level distributions.
- Excluded: advanced analytical percentage archetypes. Those are preserved under `PCT-X`.

## Package Philosophy

- Breadth first.
- Richness later.
- One explanation style.
- Approximately 20 first-pass packages per canonical problem over time.

## Architecture Reuse

PCT-002 reuses the existing Quant V4 stack:

- solver
- evidence
- reasoning graph
- explanation renderer
- validators
- routing
- activation
- qualification framework

No architecture redesign is introduced here.
