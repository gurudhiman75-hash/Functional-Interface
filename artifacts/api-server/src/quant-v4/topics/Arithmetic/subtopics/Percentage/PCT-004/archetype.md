# PCT-004: Percentage Decrease

## Mission

PCT-004 establishes the first-pass foundation for Percentage Decrease across direct decrease, reverse decrease, multiplier reasoning, successive decrease, comparisons, and contextual bridges.

## Educational Boundary

- Focus: decrease-only transformations.
- Scope: new value, decrease amount, original from decreased value, multiplier, successive decrease, net decrease, comparisons, part-wise decrease, required decrease, and simple decrease bridges.
- Excluded: mixed increase-decrease and advanced analytical percentage archetypes.

## Package Philosophy

- Breadth first.
- Richness later.
- One explanation style.
- Approximately 20 first-pass packages per canonical problem over time.

## Architecture Reuse

PCT-004 reuses the existing Quant V4 stack:

- solver
- evidence
- reasoning graph
- explanation renderer
- validators
- routing
- activation
- qualification framework

No architecture redesign is introduced here.
