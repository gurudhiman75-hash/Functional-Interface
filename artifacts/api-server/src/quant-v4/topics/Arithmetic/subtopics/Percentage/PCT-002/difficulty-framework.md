# PCT-002: Difficulty Framework

## Easy

- clean percentage values
- direct whole/part mappings
- minimal context switching

## Medium

- reverse mapping
- multi-category but single-level distributions
- slightly larger values or one extra comparison step

## Hard

- denser percentage partitions
- expense or population distributions with more labels
- less friendly numerical mappings without changing the base logic

Difficulty should emerge from arithmetic texture and relationship density, not from artificial wording.
