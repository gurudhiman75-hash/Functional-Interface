# PCT-006 Difficulty Framework

## Easy

- direct more-than comparison
- direct less-than comparison
- selected-base percentage difference on a named base
- required increase or decrease to a target

## Medium

- reverse base-switching comparison
- ratio-based percentage comparison
- percentage points vs relative change
- cross-base percentage comparison

## Hard

- compare two values after different percentage changes
- chain percentage comparison
- trickier selected-base switching prompts
