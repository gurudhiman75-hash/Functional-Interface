# PCT-006 Library Authority Map

- `task-registry.library.json` owns CP <-> QL <-> task-kind <-> solve-mode <-> answer-type mapping
- `question-language.*.json` owns stem language families
- `explanation.*.json` owns explanation ID mapping
- `variable-ranges.library.json` records runtime variable authority and generation notes
- `coverage-targets.library.json` records expected chapter coverage targets
- `distribution-targets.library.json` records difficulty and CP distribution targets
