# PCT-003: Percentage Increase

## Mission

PCT-003 establishes the first-pass foundation for Percentage Increase across direct increase, reverse increase, repeated increase, comparative increase, and growth-bridge problems.

## Educational Boundary

- Focus: increase-only transformations.
- Scope: new value, increase amount, original from increased value, multiplier, repeated increase, net increase, comparisons, part-wise increase, required increase, and simple growth bridges.
- Excluded: percentage decrease, mixed increase-decrease, and advanced analytical percentage archetypes.

## Package Philosophy

- Breadth first.
- Richness later.
- One explanation style.
- Approximately 20 first-pass packages per canonical problem over time.

## Architecture Reuse

PCT-003 reuses the existing Quant V4 stack:

- solver
- evidence
- reasoning graph
- explanation renderer
- validators
- routing
- activation
- qualification framework

No architecture redesign is introduced here.
