# PCT-CONTENT-005 Content Standard

## Purpose

This standard defines how Percentage drafts should be enriched before they enter the approved Examtree question bank.

Question Studio should generate draft inventory. A question should enter the approved bank only after human review confirms that it feels natural, exam-like, and useful for SSC, banking, or Punjab state exam preparation.

## Core rule

A richer stem must change at least one meaningful educational dimension:

- context
- information structure
- learning point
- calculation load
- exam tone
- explanation angle

A noun swap is not enough.

## Ready-for-bank checklist

Approve a question only if:

1. The wording is natural and not robotic.
2. The context fits the math naturally.
3. The stem is not a close duplicate of another approved family.
4. The structure is not overused inside the same CP.
5. The expected learning point or common error is clear.
6. The explanation can teach the concept, not only compute the answer.
7. The question can be confidently selected into a mock test.

## Exam-tone profiles

### SSC direct tone

Use short, practical wording. Good contexts include article price, stock, attendance, marked price, salary, population, production, discount, and target value.

### Banking data tone

Use branch record, statement, usage note, premium, account count, subscription, revenue, table-ready wording, and data-summary wording.

### Punjab state public-record tone

Use village survey, voter list, school attendance, crop yield, rainfall, electricity usage, water supply, transport passengers, departmental record, local inventory, clinic, and public-service contexts.

Use these only where they naturally match the math.

## Structure library

Avoid direct-only dominance. Mix these structures:

- direct statement
- register entry
- survey summary
- branch report
- office note
- newspaper-style snippet
- inventory record
- attendance register
- target note
- comparison statement
- table-ready statement
- revision note

Changing structure means changing how information is presented, not merely adding the word report.

## Percentage common-error library

Percentage questions should deliberately cover these mistakes:

- using the wrong base
- treating final value as original value
- adding successive percentages directly
- confusing discount amount with final price
- confusing percentage amount with total amount
- treating ratio part as the whole
- calculating target percentage on the wrong base
- not converting multiplier back to percentage change

## Manual review dispositions

Use these review decisions:

- Approve as-is
- Edit wording then approve
- Keep as practice-only
- Reject as duplicate
- Reject as unnatural
- Reject due to weak explanation

The approved bank should contain only reviewed, mock-ready inventory. Question Studio creates volume; human review creates trust.
