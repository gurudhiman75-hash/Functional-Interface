## Recovered PCT-002

Title:

- `Percentage Transformations`

Purpose:

- Collect all foundational single-base percentage relationships.

## Canonical Problems

1. Whole from Part

   Given `p% -> value`, find `100%`.

2. Another Percentage from Known Percentage

   Given `25% -> 180`, find `40%`, `70%`, `12%`.

3. Percentage from Part and Whole

   Given part and whole, find percentage.

4. Reverse Percentage Mapping

   Given `40% -> 240`, find what percent is `180`.

5. Ratio <-> Percentage Conversion

   Examples: `3:2`, `60%`, `40%`.

6. Complementary Percentage

   Examples: `25%` girls, remaining percentage.

7. Difference Between Percentage Parts

   Examples: `40%` boys, `25%` girls, difference.

8. Percentage Partition

   Examples: `40%`, `35%`, `25%`, partition of a whole.

9. Missing Percentage

   Known percentages add to `100%`; find missing percentage.

10. Multi-category Percentage Distribution

    Examples: population or expenses split across categories.
