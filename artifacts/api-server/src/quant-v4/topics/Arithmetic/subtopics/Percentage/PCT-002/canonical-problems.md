## Frozen foundational CPs

| CP ID | Name | Core idea |
| --- | --- | --- |
| PCT-CP-001 | Whole from Part | Given `p% -> value`, find `100%`. |
| PCT-CP-002 | Another Percentage from Known Percentage | Given `p% -> value`, find another percentage. |
| PCT-CP-003 | Percentage from Part and Whole | Given part and whole, find percentage. |
| PCT-CP-004 | Reverse Percentage Mapping | Given `p% -> value`, determine what percent another value is. |

| PCT-CP-006 | Complementary Percentage | Use `known + remaining = 100%`. |

| PCT-CP-008 | Percentage Partition | Recover one category from a single-level partition of a whole. |
| PCT-CP-009 | Missing Percentage | Known percentages sum to 100%; find the missing part. |
| PCT-CP-010 | Multi-category Percentage Distribution | Single-level multi-category percentage distribution. |

## Explanation standard V2.1

Every pedagogical sentence is immediately followed by a MathJax consequence beginning with `\Rightarrow`.

Forbidden:

- formula dumps
- downward arrows
- isolated equations
- algebra-first style
- `Let x be`
- AI filler
