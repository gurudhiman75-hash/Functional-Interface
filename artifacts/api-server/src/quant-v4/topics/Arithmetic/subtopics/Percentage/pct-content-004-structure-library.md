# PCT-CONTENT-004 Structure Library

Editorial-only structure guidance for Percentage PCT-001 through PCT-005. This file is not a runtime contract.

## Phase C audit signals

PCT-005 was dominated by timeline structures. PCT-002, PCT-003, and PCT-004 had acceptable raw family counts, but weak CPs still used too many direct statements. PCT-001 had high raw breadth but repeated old textbook shells.

## Strengthened structures

| Structure | Editorial purpose |
| --- | --- |
| Report | Makes percentage information feel like extracted data rather than a bare formula. |
| Notice | Useful for hospital, transport, stock, fee, and capacity changes. |
| Survey summary | Supports percentage share, missing percentage, ratio, and net-change prompts. |
| Office memo | Useful for target increase/decrease and budget adjustment questions. |
| Statistical note | Good for net percentage and multiplier questions without overusing timelines. |
| Committee report | Good for two-stage percentage changes and official-record phrasing. |
| Ledger or bank statement | Natural for known-percentage-to-target-percentage mapping. |
| Collection record | Useful for museum/library ratio and share questions. |
| Clinic or hospital record | Natural for direct change, reverse change, and part-of-whole questions. |

## Editorial rule

A structure change must change how the information is presented. Merely adding words like report to the same sentence is not sufficient.
