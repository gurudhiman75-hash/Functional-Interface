## Recurring editorial issues

- PCT-005 still feels structurally repetitive because timeline-style stems dominate the chapter.
- Abstract stems remain a drag on exam realism, especially in PCT-001 and PCT-005.
- Some explanations still feel more like solution text than stem-aware teaching, especially in legacy PCT-001 items.
- The strongest stems are short, context-familiar, and explicit about the asked quantity; weaker stems become generic when they fall back to "a value", "a quantity", or pure letter-style framing.

## Recurring wording problems

- Generic abstract openings such as "A value..." reduce exam realism.
- Some multi-stage stems carry too much information in a single sentence.
- Reverse and multiplier questions are clear mathematically, but a few still read more like exercise-bank prompts than polished book questions.
