# PNC-002 Canonical Problems

The package preserves six fixed ownership boundaries:

1. `PNC-CP-007 — Together, Apart & Block Restrictions`
2. `PNC-CP-008 — Position, Relative Order, Alternation & Gap Constraints`
3. `PNC-CP-009 — Conditional Selection from Categories`
4. `PNC-CP-010 — Circular Arrangements & Rotational Symmetry`
5. `PNC-CP-011 — Grouping & Distribution`
6. `PNC-CP-012 — Mixed Advanced Counting Systems`

## Active CP-007 scope

- one specified block together;
- two disjoint specified blocks together;
- specified objects not all together by complement;
- two specified objects apart by complement;
- exactly one of two specified pairs together;
- bounded recovery of the total number of objects from a block count.

## Explicit negative boundary

CP-007 does not own prescribed seats, starts/ends, relative order, alternating categories, or general no-adjacency solved by gap placement. Those remain CP-008. Circular block restrictions remain CP-010.
