# NUM-CP-001 Hindi/Punjabi localisation gate

This directory adapts the frozen English permanent runtime into deterministic `hi-IN` and `pa-IN` learner surfaces without changing mathematical authority.

Safety boundary:

- English permanent runtime remains canonical mathematical authority.
- Permanent QL, solve mode, proposal, seed, source seed, runtime prototype, hidden state, mathematical fingerprint, option order, correct index, misconception mapping and lifecycle are preserved.
- Localised questions are not Question Studio discoverable, Question Bank writable, test eligible or publicly publishable in this gate.
- Lifecycle promotion to multilingual frozen status requires exact-head parity and editorial CI to pass first.
