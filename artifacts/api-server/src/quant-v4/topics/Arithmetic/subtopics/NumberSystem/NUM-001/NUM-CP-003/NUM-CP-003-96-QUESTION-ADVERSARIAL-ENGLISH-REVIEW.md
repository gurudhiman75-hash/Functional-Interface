## 2. Critical numerical-authority defect

### Decorative divisibility in arithmetic-result questions

Nine review records belong to these temporary contracts:

```text
NUM-CP003-W2-PROT-MISSING-DIGIT-IN-SUM
NUM-CP003-W3-PROT-MISSING-DIGIT-IN-DIFFERENCE
NUM-CP003-W3-PROT-MISSING-DIGIT-IN-PRODUCT
```

In their current form, the visible exact equality already determines the missing digit. The divisibility statement only confirms a number that arithmetic has fully reconstructed.

Example topology:

```text
known addend + known addend = numeral containing X
result is divisible by k
find X
```

The ones, tens or another displayed column determines `X` before the divisibility condition is used.

Disposition:

```text
MATHEMATICALLY VALID
EDITORIALLY READABLE
NOT RETAINABLE AS CP-003 NUMERICAL AUTHORITIES
```

These prototypes remain useful negative evidence. They must be excluded from any permanent QL proposal unless regenerated so that arithmetic alone leaves multiple admissible candidates.

### Secondary but valid

- linked arithmetic-result divisibility.

### Advanced enrichment

- pair-set display with many ordered pairs;
- three-divisor inclusion–exclusion;
- data sufficiency;
- abstract algebraic identities.

The final distribution must not allow advanced prototypes to dominate the chapter simply because they are executable.

## 7. Editorial observations

Strengths:

- stems are concise and interrogative;
- options are readable and shuffled across all four positions;
- final explanations use state-specific values;
- option diagnostics describe the displayed option rather than generic labels;
- MathJax/control-character defects found during earlier waves are closed.

Remaining editorial risks:

- repeated phrases such as “test every candidate” and “direct enumeration confirms” require diversification in the eventual permanent runtime;
- abstract rule-recognition questions need exam-natural wording variants;
- set-valued ordered-pair answers can become visually dense and may be better suited to editorial review or advanced tests;
- data-sufficiency wording must use one stable five-option convention across the wider product;
- identity explanations must show the factorisation or modular reason, not merely test sample values.
