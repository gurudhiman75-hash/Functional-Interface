# NUM-CP-003 — QL-Template Approval Checklist

Review the 22-template proposal against these questions before authorising a retained registry:

- Does each template change task direction, answer semantic, uniqueness or misconception profile?
- Can any two templates merge without hiding a material learner target?
- Does any retained template belong primarily to CP-006, CP-007, CP-008, Algebra or P&C?
- Are routine SSC patterns adequately represented without advanced enrichment dominating?
- Are largest/smallest digit and greatest/smallest completed-number outputs all required?
- Should least/greatest n-digit multiples remain separate learner templates over one solver?
- Should data sufficiency and claim verification remain CP-003 templates or wider shared representations?
- Is the linked arithmetic–divisibility extremum sufficiently common to retain as a template?
- Are the three decorative arithmetic-result prototypes clearly excluded?
- Are table and caselet layouts correctly treated as adapters?

Approval result must be one of:

```text
APPROVE_22_TEMPLATE_BOUNDARIES
APPROVE_WITH_MERGES_OR_SPLITS
RETURN_FOR_MORE_DISCOVERY
```

None of these decisions automatically allocates permanent IDs.
