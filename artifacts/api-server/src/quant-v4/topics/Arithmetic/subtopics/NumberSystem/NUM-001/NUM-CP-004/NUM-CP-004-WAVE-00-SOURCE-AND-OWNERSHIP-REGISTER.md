## 3. Wave 1 retained exploration candidates

1. classifying one integer as prime, composite, unit or neither;
2. returning the complete prime set in a bounded inclusive interval;
3. returning the number of primes in that interval;
4. recovering the full prime factorisation of a constructed integer;
5. reading smallest/largest prime factor or distinct/total prime-factor count;
6. finding one missing prime or exponent in an exact factorisation;
7. selecting the unique co-prime pair from four candidate pairs;
8. distinguishing pairwise and collective co-primality for a triple.

The separate interval set and interval count prototypes deliberately test whether answer semantic warrants a later split. The prime-factor-property prototype deliberately tests whether its target parameter should later split by misconception profile.
