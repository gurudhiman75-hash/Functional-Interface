# NUM-CP-014 Wave04 — Saturation Merge/Split

Status: **proposal only** until executable discovery certification is green. No permanent QL is allocated; `NUM-QL-248` remains free.

## Discovery corpus

20 positive temporary prototypes survive Waves01–03 after redundancy rejection and answer-semantic saturation.

## Proposed permanent solve authorities

### AUTH-001 — Unique two-engine hidden scalar
Sources: P001, P002, P003, P004, P005, P006, P013, P014, P015, P016, P017, P018, P019.

This authority is component-dynamic. It owns a bounded scalar domain filtered by exactly two independently essential proven Number System engines. Hidden digit, number, base, exponent and divisor are projections of the same solve topology, not separate authorities.

Admission invariant:
- full intersection has exactly one scalar;
- removing either engine restores multiple candidates;
- component identity and representation are metadata/state, not authority identity.

### AUTH-002 — Two-engine extremum
Sources: P007, P008.

Compute the complete two-engine intersection and project `least` or `greatest`. Direction is a parameter. A component is essential only when removing it changes the reported extremum.

### AUTH-003 — Two-engine complete count
Sources: P009, P012.

Compute the complete intersection and return its exact cardinality. Scalar-base domains and ordered digit-pair domains remain representations/domain shapes under one count topology.

### AUTH-004 — Two-engine solution class
Source: P010.

Owns `NO_SOLUTION` and `ONE_SOLUTION` modes only when each component changes the learner-facing class under ablation. Ordinary conjunctive `MULTIPLE_SOLUTIONS` states are not admitted when removing either constraint still leaves the answer class `MULTIPLE_SOLUTIONS`.

### AUTH-005 — Unique three-engine hidden scalar
Source: P011.

Remains split because three independent one-component ablations and a three-node dependency graph are structurally different from two-engine synthesis.

### AUTH-006 — Two-engine complete valid set
Source: P020.

Remains split from count/class/scalar because set completeness has distinct omission and extraneous-member misconceptions. Removing either component must change the complete answer set itself.

## Rejected alternative split

CP014 will **not** allocate one authority per component pair. Pair-specific QLs would duplicate the same intersection algorithm and make every future Number System component combination consume another permanent QL.

It will also **not** collapse scalar, extremum, count, class, three-engine and complete-set outputs into one authority because their learner-facing answer semantics and ablation proofs differ materially.

## Permanent allocation proposal after green certification

If Wave01–Wave04 certification is genuinely green, the six authorities would consume the next six contiguous Number System QLs:

- proposed: `NUM-QL-248..NUM-QL-253`
- proposed next free after allocation: `NUM-QL-254`

These numbers are **not allocated by Wave04**. They remain a proposal until exact-head discovery certification succeeds.
