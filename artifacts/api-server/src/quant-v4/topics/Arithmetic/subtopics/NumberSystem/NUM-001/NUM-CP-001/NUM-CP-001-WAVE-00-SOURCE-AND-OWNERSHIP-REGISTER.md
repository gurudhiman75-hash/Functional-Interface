## 1. Source evidence

### Number System completeness audit

The repository completeness audit records repeated SSC/Railway/Banking/Defence/PCS relevance for general number classification and explicitly identifies the following uncovered families:

- natural, whole, integer, rational, irrational and real classification;
- parity of sums, products and powers;
- consecutive-integer properties beyond the already-owned co-prime case;
- number-line ordering and interval representation.

The audit also records the exam boundary that pure fraction/decimal representation belongs to the fraction-decimal authority rather than general set/order work.

### Number System roadmap V2 recovery

The earlier roadmap preserves `NS-CLASS-001` and `NS-NLINE-001` as source-history evidence. Their family names are not permanent V4 identities. They establish demand for:

- number-type recognition;
- positive/negative and even/odd properties;
- exact ordering on a number line;
- interval and placement questions.

The V4 checkpoint design supersedes the old archetype split: number-line layout is a representation unless it changes the evidence or inference.

### NUM-001 complete checkpoint design

The governing design explicitly requires coverage of:

- smallest applicable number set and membership claims;
- signed order and exact comparison;
- absolute distance and integer selection between bounds;
- open, closed and half-open integer interval counts;
- parity under arithmetic and powers;
- consecutive integer reconstruction and property claims.

It also requires explicit treatment of zero/one conventions, negative endpoints, strict integer bounds, empty intervals, inverse absolute-value branching and impossible consecutive-integer states.

### Cross-CP ownership matrix

The chapter ownership matrix fixes these boundaries:

- exact order of already represented numbers → CP-001;
- recurring/fraction representation conversion needed to compare → CP-002;
- prime/composite as the governing property → CP-004;
- generic inequality solving → Algebra;
- pattern continuation → Number Series;
- formed-number arrangement counting → P&C.

## 4. Wave 1 retained exploration candidates

Wave 1 deliberately proves only the architecture foundation through eight temporary contracts:

1. smallest applicable number-set classification under an explicit natural-number convention;
2. zero/one/negative membership or parity claim selection;
3. signed integer ordering;
4. absolute distance between signed integer points;
5. integer count in open/closed/half-open intervals;
6. direct parity discrimination among expressions;
7. parity claim topology with always/sometimes/never/special-case outcomes;
8. reconstruction of a short consecutive-integer block from its sum.

These are prototypes, not proposed permanent QLs. In particular, number-line rendering remains merged with the underlying order/distance authority unless a later evidence audit proves a different learner inference.
