## Mathematical controls

- ordinary remainder is always the least non-negative residue;
- negative differences are normalised rather than converted to absolute values;
- a nested remainder is inferred only when the smaller divisor divides the known divisor;
- polynomial propagation is bounded and uses no unproved power-cycle theorem;
- linked divisor–quotient states are independently enumerated and must be unique;
- bounded count and topology questions are verified by direct interval enumeration;
- nearest-multiple questions explicitly support lower, upper, tie and already-divisible states;
- all four options are distinct and exactly one is correct.
