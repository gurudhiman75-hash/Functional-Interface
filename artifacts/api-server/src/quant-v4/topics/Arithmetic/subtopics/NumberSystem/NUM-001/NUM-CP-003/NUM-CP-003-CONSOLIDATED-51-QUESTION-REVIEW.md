- unique digit;
- extremum digit;
- count;
- sum;
- complete set;
- extremum completed number.

Largest/smallest and greatest/smallest remain direction parameters inside shared templates.

### Ordered-pair family

The review confirms that pair answer, pair count, pair set and solution classification have materially different answer spaces and misconception profiles.

### Boundary and range family

Least/greatest n-digit multiple is one direction-parameter template. One-divisor range count remains separate because its answer is a cardinality over an interval.

### Repeated numeral

The completed repeated number is not shown in the stem. The learner must construct or factor it before testing divisibility.

### Linked hybrid

Arithmetic alone leaves multiple `(A, B)` candidates. Divisibility removes candidates, after which the requested A-extremum is selected. No reviewed state uses divisibility decoratively.

### Data sufficiency

The five standard classes are implemented in the runtime proof. Hosted records use one stable option convention and evaluate each statement separately before intersection.

### Claim verification

Assertion wording is independent of the underlying remainder fact. The requested correct/incorrect polarity therefore selects a genuinely true or false statement rather than a pre-labelled arithmetic fact.
