## Temporary prototype contracts

### NUM-CP001-PROT-025 — integer-structure data sufficiency

Determine whether an unknown bounded integer is uniquely determined from Statement I, Statement II, or their intersection. Statements use CP-001-owned evidence only: parity, exact number-line distance, sign/order and bounded integer intervals.

The generated corpus must reach exactly these four repository-standard classes:

- I alone is sufficient;
- II alone is sufficient;
- both together are sufficient;
- even together are insufficient.

The generator deliberately excludes a state where each statement alone is sufficient because the existing Number System four-class DS convention does not encode that fifth topology.

### NUM-CP001-PROT-026 — guaranteed consecutive-product divisor

For k consecutive integers, find the greatest positive integer guaranteed to divide their product for every integer starting value. The governing invariant is that the product of k consecutive integers is divisible by k!, and k! is sharp because the block 1,2,...,k has product exactly k!.

This closes the source/design trace for consecutive-product divisibility without moving prime factorisation, divisor functions or modular arithmetic into CP-001.
