# NUM-CP-011 Wave 03 Audit Note

Wave 03 adds only two compound trailing-zero authorities:

- factorial-ratio trailing zeroes, with base-10 and general-base representations;
- structured-product trailing zeroes, with base-10 and general-base representations.

It does not create separate authorities merely because the numeral base changes.

The dedicated edge-convention proof locks:

- `0! = 1`;
- `1! = 1`;
- `v_p(1) = 0`;
- distinction between the exponent `k` and the value `a^k` in highest-power wording;
- trailing-zero representation semantics;
- integrality of learner-facing factorial ratios.

All Wave 03 outputs remain discovery-only and no permanent QL identity is allocated.
