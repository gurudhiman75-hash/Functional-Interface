# SAP Localization Layer

The Simplification & Approximation localization layer is an editorial transform over the approved English Question Studio package.

`English canonical generator -> SAP Question Studio adapter -> localized editorial transform -> existing shared Question Studio preview/run/review pipeline`

It does not own mathematics, seeds, distractor order, correct indices, QL allocation, persistence, Question Bank conversion, test eligibility, or publication.

Supported review languages: `en`, `hi`, `pa`.

Hindi uses natural exam Hindi with Devanagari script. Punjabi uses natural exam Punjabi with Gurmukhi script. Mathematical notation remains canonical.
