# AVG-001: Canonical Problems

This document defines the independent reasoning systems for Average.

| CP ID | Name | Core Logic | Exam Realism |
| --- | --- | --- | --- |
| AVG-CP-001 | Foundational Sum-Count Mapping | Solving for $S, A, \text{or } C$ in basic scenarios. Finding missing values in a discrete set. | Foundational for all exams. |
| AVG-CP-002 | Symmetric AP Properties | Using middle-term logic for consecutive numbers, odd/even sequences, and fixed-interval series. | Primary SSC/PCS Topology. |
| AVG-CP-003 | Increment/Decrement & Replacement | Analyzing shifts when items are added, removed, or swapped. Includes "find new member's value". | High-Frequency SSC. |
| AVG-CP-004 | Weighted & Combined Aggregation | Merging 2-4 groups with distinct averages (e.g., Boys + Girls). | Banking & SSC Premium. |
| AVG-CP-005 | Error Detection & Delta Correction | Correcting a calculated average by distributing the "Mistake Delta" over the total count. | Classic SSC Trophy Question. |
| AVG-CP-006 | Multi-Stage Hierarchical Systems | Resolving averages across nested levels (e.g., Class average from Section averages). | Banking & Data Interpretation. |

## CP Independence Analysis

### AVG-CP-001: Sum-Count Mapping
- **Focus**: Global totals.
- **Independence**: Solves via direct algebraic relation. Distinct from AP logic which doesn't always require a sum.

### AVG-CP-002: Symmetric AP Properties
- **Focus**: Positioning.
- **Independence**: Solves using structural properties (e.g., $Avg = (First + Last) / 2$). Reasoning is independent of the actual magnitude of the sum.

### AVG-CP-003: Replacement & Deviation
- **Focus**: Local Shifts.
- **Independence**: Focuses on the *change* ($\Delta$). Expert students solve this without calculating large totals (e.g., $New = Old + (Count \times \Delta)$).

### AVG-CP-004: Weighted Aggregation
- **Focus**: Proportional Impact.
- **Independence**: Uses ratio-weighted reasoning. The impact of group A depends on its relative count compared to group B.

### AVG-CP-005: Error Correction
- **Focus**: Retroactive Adjustment.
- **Independence**: Reasoning starts with a "wrong" state and applies a precise adjustment factor. Distinct because the count remains fixed but the sum is corrected.

### AVG-CP-006: Hierarchical Systems
- **Focus**: Level-by-level Resolution.
- **Independence**: Requires multi-step weighted averaging. Solver must treat intermediate results as inputs for the next stage.
