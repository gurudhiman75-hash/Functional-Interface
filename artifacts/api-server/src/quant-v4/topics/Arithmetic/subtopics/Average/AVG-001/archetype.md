# AVG-001: Average

## Domain Description
Foundational and intermediate applications of Average (Arithmetic Mean). This archetype focuses on the properties of balanced distributions, net shifts caused by incremental changes, and the aggregation of multiple weighted groups.

## Exam Context
- **SSC (CGL/CHSL)**: High emphasis on Replacement systems (One leaves, one joins), Error Correction (Misread data), and consecutive number properties.
- **Banking**: Focus on complex combined groups and multi-entity weighted averages.
- **RRB/State Exams**: Foundational sum-count mapping and basic unitary extraction.

## Mathematical Scope
1. **Sum-Count Mapping**: The fundamental relation $Sum = Average \times Count$.
2. **Symmetric Distribution**: Properties of Arithmetic Progressions (Consecutive, Odd, Even) where the average is the middle term or mean of extremes.
3. **Net Shift (Deviation)**: Analyzing how the average changes when terms are added, removed, or replaced without calculating total sums.
4. **Weighted Aggregation**: Combining $N$ groups with independent counts and averages.
5. **Delta Correction**: Adjusting an existing average based on "incorrect" vs "correct" value differences.
6. **Hierarchical Resolution**: Resolving multi-level averages (Sub-group -> Group -> Super-group).

## Performance Targets
- Solver must handle up to 4 combined groups.
- Solver must support deviation-based logic for large-number inputs.
- Multi-lingual parity (EN, HI, PA) for all teacher-voice templates.
