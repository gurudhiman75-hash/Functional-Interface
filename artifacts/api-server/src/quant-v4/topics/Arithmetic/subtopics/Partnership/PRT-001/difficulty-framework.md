# Difficulty framework

- **Easy:** one direct capital or capital-time transformation and a direct ratio/share output.
- **Medium:** one event interpretation, a reverse unknown, a three-partner distribution, or one ordered allocation.
- **Hard:** multiple timeline events, dynamic capital plus remuneration, or reverse reconstruction after a deduction.

Difficulty is attached to the human-owned task entry, not inferred from cosmetic number size. Parameter generation may scale values without changing the reasoning contract.
