# RAP-001: Ratio & Proportion

## Domain Description
Foundational and intermediate applications of Ratio and Proportion. This archetype focuses on the relational properties between quantities, their transformation under specific operations, and their distribution across multiple entities.

## Exam Context
- **SSC (CGL/CHSL)**: High emphasis on Income-Expenditure systems, Coin problems, and Multi-entity merging.
- **Banking**: Focus on partnership-style distribution and complex fractional ratios.
- **RRB/State Exams**: Unitary method applications and formal proportionality (Mean/Third/Fourth).

## Mathematical Scope
1. **Relational Merging**: Unifying separate ratios into a single chain (A:B:C:D).
2. **Partitioning Logic**: Distributing a global constant into discrete buckets based on ratio weights.
3. **Linear Transformations**: Modeling state changes (Before -> Action -> After) using cross-product logic.
4. **Proportionality**: Solving for mathematical properties of proportion and functional variation (Direct/Inverse).
5. **Weighted Relational Systems**: Systems involving counts vs. values (Coins/Denominations).
6. **Binary Mixtures**: Foundation of concentration changes via component addition.

## Performance Targets
- Solver must handle up to 4 linked entities.
- Solver must support cross-multiplication for non-uniform additive changes.
- Multi-lingual parity (EN, HI, PA) for all templates.
