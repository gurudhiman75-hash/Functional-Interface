## Editorial standards

The unified gate rejects a question when any of the following occurs:

- unresolved placeholders or invalid runtime tokens;
- a non-interrogative or under-specified stem;
- fewer or more than four unique options;
- mismatch between the canonical answer and correct option;
- more or fewer than one correct option in the audit;
- missing source authority;
- fewer than four worked explanation steps;
- missing verification or conclusion;
- missing diagram or stage ledger;
- use of alligation terminology for repeated replacement;
- leaked permanent QL identity or enabled delivery flag.

## Corpus audit

The dedicated audit generates:

```text

```

It verifies:

- deterministic regeneration;
- mathematical and package validation;
- source attachment;
- answer-position balance;
- stem, fingerprint and answer diversity;
- no exact stem shared across different contracts;
- minimum diversity for each individual contract;
- balanced sampling of all three final-state representations;
- complete explanations and stage visuals;
- no permanent allocation or product exposure.
