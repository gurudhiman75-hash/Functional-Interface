## 2. Resolved ownership boundaries

### Static concentration blending

The value unit does not decide ownership.

```text
complete one-stage blend of known source concentrations
→ MAL-CP-001

component conserved through dilution, strengthening, evaporation,
wet/dry conversion or nested component reconstruction
→ MAL-CP-004
```

A static concentration question may therefore reuse the existing CP-001 target-ratio, final-mean, unknown-source or unknown-quantity template. It does not create a concentration-only QL.

A recovered XAT 2015 problem builds Product M from nested mixtures, reconstructs the amount of raw material B, and then adds water until B is 50% of the final mixture. The worked solution derives final total quantity as an intermediate and asks for water added. Its decisive invariant is conserved raw material B, so it is direct CP-004 boundary evidence rather than support for a CP-001 final-total output template.

### Direct vessel combination

A vessel noun does not decide ownership.

```text
contents poured together once; source vessels then cease to matter
→ MAL-CP-001 static weighted blend

transfer, return, equalisation or chained movement requiring each
vessel's current composition at an intermediate stage
→ MAL-CP-006 transfer ledger
```

Direct one-stage combination reuses existing CP-001 templates. CP-006 begins only when the learner must maintain a vessel-by-vessel state ledger.
