## Four-tier explanation model

Every Wave 05 review package must contain:

1. **Core Concept & Formula** — plain teacher language and a valid MathJax governing formula;
2. **Step-by-Step Solution** — number-specific intermediate calculations;
3. **Exam Speed Shortcut** — a shorter route containing the generated values and final answer;
4. **Common Traps & Distractor Analysis** — the actual displayed letter and value for all three wrong options, a numerical wrong route, and the correction.

A generated review export is evidence for human review, not approval by itself.
