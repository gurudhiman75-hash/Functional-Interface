## Final-ratio runtime

The runtime supports both requested orientations:

- original liquid : replacement liquid;
- replacement liquid : original liquid.

The answer is always an exact reduced integer ratio. Distractors are attached to identifiable misconceptions such as ratio reversal, using only one operation, linear subtraction, or an incorrect operation count.

## Vessel-capacity inverse runtime

The generator constructs a valid vessel state first, derives the exact final ratio, and then asks the inverse capacity question. This guarantees an exact rational root and a unique vessel capacity within the discovery contract.
