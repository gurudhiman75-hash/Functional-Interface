## 2. Main consolidation result

The earlier discovery checkpoint reported ten provisional learner contracts. Source-format review shows that three quantity families perform the same decisive operation after the alligation ratio is known:

```text
find both quantities from a stated total
find one component share from a stated total
find both quantities from their stated difference
```

In each case:

```text
derive reduced alligation ratio
→ determine one common scale from an external constraint
→ project one or both component quantities
```

The total constraint uses the sum of ratio parts. The difference constraint uses the absolute difference between ratio parts. This is a parameterised scale constraint, not a distinct reasoning contract.

Therefore:

```text
15 executable prototype identities
→ 8 freeze-preparation candidate contracts

ANCHOR: 8
MERGE:  7
```

No executable identity is deleted. The three quantity variants remain separately testable evidence inside one freeze candidate.

## 4. Source reconciliation

### Directly supported

Direct uploaded-book or SSC reference evidence supports:

- ratio from two source values and a target mean;
- final mean from a ratio or explicit component quantities;
- reverse recovery of an unknown source value;
- recovery of one unknown component quantity;
- ratio scaling from a total or one known counterpart quantity;
- compound or pre-blended forward final-mean questions.

### Supported with a variant-level gap

`MAL-CP001-FREEZE-QUANTITIES-FROM-RATIO-SCALE`

- the total/known-counterpart variants have direct reference evidence;
- the difference-as-scale presentation is legacy-attested and executable;
- no direct uploaded-book fixture for the exact difference wording was recovered;
- it remains a merged variant and does not justify a separate permanent QL by itself.

`MAL-CP001-FREEZE-TWO-STAGE-UNKNOWN-QUANTITY`

- references directly combine two pre-blended mixtures and solve their required quantities;
- the current second-stage added-quantity framing is mathematically analogous and independently verified;
- one exact direct source fixture for that precise wording/topology is still desirable before freeze.

### Allocation blocker

`MAL-CP001-FREEZE-THREE-WAY-RELATION-QUANTITY`

Three-source blending is well supported, but no recovered reference fixture yet matches the exact combined constraint:

```text
three source values
+ total quantity

```

The executable prototype is mathematically valid, but executable validity alone is not enough to create a permanent QL. This candidate remains blocked pending direct target-exam or trusted reference evidence.

## 5. Ownership decisions

### Average boundary

```text
generic weighted mean of groups, marks, salaries or observations
→ Average

mixture composition, source values and a target blend relation are essential
→ MAL-CP-001
```

Changing a generic weighted-average noun to rice, tea or oil is not enough. The mixture/component state must be instructionally material.

### MAL-CP-002 boundary

```text
static blend of complete source components
→ MAL-CP-001

one substance is added, removed or replaced while the counterpart is conserved to change a composition ratio
→ MAL-CP-002
```

Addition wording stays in CP-001 only when it is simply the unknown source quantity in a target weighted blend, not a pre-existing two-substance composition adjustment.

### MAL-CP-004 boundary

```text
direct blending of complete solutions as source components
→ CP-001 mathematical state, with chapter ownership decided once

water addition, evaporation, pure-solute addition or fresh/dry transformation with a conserved solute
→ MAL-CP-004
```

No duplicate QLs are permitted across CP-001 and CP-004.

### MAL-CP-006 boundary

```text
combine completed homogeneous blends without transfer bookkeeping
→ MAL-CP-001

track composition through transfer between vessels, equalisation or a chain ledger
→ MAL-CP-006
```

A vessel noun alone does not create CP-006 ownership.

## 6. Representation decisions

### Compact table

A compact component table is a renderer/evidence-parsing variant. It is not a learner contract unless later proof shows a materially different reasoning burden.

```text
verdict: renderer variant, no new CP-001 freeze candidate
```

### Data Sufficiency

Statement-pair or Data Sufficiency presentation belongs to the platform's Data Sufficiency layer. The underlying arithmetic contract may call CP-001, but DS presentation must not create a MAL QL identity.

```text
verdict: reassign presentation ownership to Data Sufficiency
```

### Impossible or indeterminate state

Reference material includes indeterminate alligation questions when a required source value is missing. That is a determinacy/DS task, not automatically a blend-computation QL.

```text
verdict: defer unless direct target-exam evidence justifies a dedicated determinacy contract
```
