# INT-001 — INT-QL-094 Provenance Disposition

Status: **intentional permanent vacancy; provenance lock candidate**

## Disposition

`INT-QL-094` is not a missing implementation. It is an intentionally vacant historical ID.

The earliest CP005 registry introduced the contract **Periodic growth with explicit migration/event order** with the coverage tag:

`new:explicit-growth-plus-migration-order`

That tag identified a newly designed semantic lead, not a recovered legacy or exam-family authority. The original runtime was mathematically executable, but executable mathematics alone is not sufficient provenance for permanent Examtree Interest authority.

## Historical correction

V14 temporarily carried QL094 inside the ten-QL CP005 learner authority. That historical inclusion is retained as evidence of the old design state; it does not retroactively create source authority.

The later V16.1 source/editorial hardening explicitly excluded QL094 because no Interest-family source was recovered. The approved V16.1 freeze rejects QL094 in English, Hindi and Punjabi. The chapter closure registry therefore has 130 permanent QLs, keeps QL094 vacant, and leaves `INT-QL-132` as the next free ID.

## Protected interpretation

The vacancy must remain until all of the following occur:

1. a traceable exam or legacy source is recovered for the semantic;
2. the semantic is proven distinct from existing Percentage growth and Interest authorities;
3. an ID-free executable discovery/collision audit passes;
4. permanent allocation is explicitly approved.

A future source-backed authority must use the then-current allocation gate. This record does **not** reserve QL094 for reuse and does not move the current next-free ID.
