# DI-006 Caselet — V2 Review Candidate

Status: REVIEW-ONLY IMPLEMENTATION

## Why V2 exists
The Phase-5 DI-006 engine is mathematically sound and deterministic, but its learner surface is too narrow for final common-exam closure:

- only 5 task families
- no Easy questions
- one service-branch context
- one fixed relation topology
- one stem surface per family
- forced shortcut/trap explanation boilerplate

V2 keeps the exact arithmetic foundation but rebuilds the caselet/content layer.

## V2 learner contract
- genuine prose caselet; no table/graph serialization
- five categories per shared set
- stated overall total
- one directly stated category value
- three exact relational facts
- one remainder category
- four relation topologies
- six neutral exam-style contexts
- 5 linked questions per set
- exact difficulty mix: 1 Easy + 2 Medium + 2 Hard
- 12 task families
- three stem surfaces per family
- SSC CGL Tier I: 4 options
- Banking Prelims: 5 options
- question-specific worked explanations
- no forced shortcut/trap sections
- misconception-owned distractors

## Task families

Easy:
1. DIRECT_STATED_VALUE
2. SINGLE_RELATION_VALUE

Medium:
3. DIFFERENCE_BETWEEN_VALUES
4. COMBINED_TWO_VALUES
5. RATIO_OF_TWO_VALUES
6. SHARE_OF_TOTAL
7. AVERAGE_OF_TWO_VALUES

Hard:
8. CHAINED_RELATION_VALUE
9. REMAINDER_FROM_TOTAL
10. COMBINED_DERIVED_SHARE
11. REMAINDER_TO_DERIVED_RATIO
12. RELATIVE_PERCENT_EXCESS

## Variety
Neutral contexts cover service requests, department employees, course enrolment, product output, order categories and book categories. No local city names are used.

Four dependency topologies rotate which category is directly stated and how the other non-remainder categories depend on it. Arithmetic value families remain exact and integer-safe.
