## Why V2 exists
The Phase-5 DI-006 engine remains available for regression, but its learner surface is too narrow for final common-exam closure:

- only 5 task families
- no Easy questions

V2 keeps the exact deterministic arithmetic foundation and rebuilds the caselet/content layer.

- four relation topologies
