## DI-003 Stacked / Segmented Bar
Three visible labelled segments per category, with exact segment values available on the learner chart. Supports segment, category, group and grand-total operations.

## DI-004 Three-Series Line
Three independently plotted and labelled lines over five periods. Supports direct reads, period totals, within-series and cross-series comparisons, ratios and aggregate operations.

These are additive canonical modes. Existing grouped-bar, single-series bar, two-series line and single-series line authorities remain unchanged.
