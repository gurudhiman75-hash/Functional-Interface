# DI-014 Radar + Pie Hybrid — Review V1

Status: ENGLISH_REVIEW_CANDIDATE · BANKING_MAINS · CONTROLLED_REVIEW

The radar chart shows applications received by five categories. The fully-labelled pie chart shows the distribution of all approved applications across the same categories. The two representations are mathematically linked, enabling meaningful cross-chart approval counts, gaps, rates and ratios.

All counts are exact integers. Category approval rates are exact 25% or 50% by construction.
