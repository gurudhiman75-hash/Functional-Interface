# DI-005 Comparative / Double Pie — Exhaustiveness Retrofit V1

Status: ENGLISH_REVIEW_CANDIDATE · ADDITIVE MODE

This mode adds two fully-labelled pie charts with common categories but independent totals and percentage distributions.

## Profiles
Banking Prelims and Banking Mains.

## Task families
- same-category count difference
- same-category count ratio
- same-category combined count
- cross-category count sum
- largest absolute change
- two-category group ratio
- combined total across pies
- cross-pie group difference
- three-value cross total
- four-value cross ratio

Every task that matters requires values from both charts. Both pies use the existing shared DI pie renderer. Existing hidden-sector and fully-visible single-pie modes remain unchanged.

Lifecycle: English controlled review only; no Question Bank writes, tests/mocks, public delivery or production release.
