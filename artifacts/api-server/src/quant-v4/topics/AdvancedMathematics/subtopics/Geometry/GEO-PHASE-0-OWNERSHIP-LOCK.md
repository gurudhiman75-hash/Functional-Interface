# ExamTree Geometry — Phase 0 Ownership Lock

**Authority:** `GEO-END-TO-END-DESIGN.md` (Revision 2)

## Geometry owns

- Euclidean theorem/property reasoning over lines, angles, triangles, congruence, similarity, triangle centres, quadrilaterals, polygons and circles.
- Numeric angles, ratios or segment lengths when the essential learner burden is a Geometry theorem.
- Pythagorean content only when theorem/converse/configuration is the tested skill.

## Geometry does not own

- **Mensuration:** perimeter, area, circumference, sector/arc measurement, surface area, volume, fencing/flooring/cost and composite measurement.
- **Trigonometry:** trigonometric ratios, identities, standard-angle values, heights/distances and trigonometric side recovery.
- **Algebra:** free-standing equations with no geometric theorem burden.
- **Coordinate Geometry:** slope, Cartesian distance/section/midpoint formulas, line/circle equations and coordinate transformations.
- **Spatial Reasoning:** mirror image, paper folding, figure analogy/completion and embedded-figure tasks.

## Phase 0 hard locks

- Permanent QLs: **0**.
- Frozen solve modes: **0**.
- Question Studio: **disabled**.
- Question Bank writes: **disabled**.
- Test eligibility: **disabled**.
- Public publication: **disabled**.

These locks remain until the package-level discovery, review and freeze gates in the design authority are explicitly satisfied.
