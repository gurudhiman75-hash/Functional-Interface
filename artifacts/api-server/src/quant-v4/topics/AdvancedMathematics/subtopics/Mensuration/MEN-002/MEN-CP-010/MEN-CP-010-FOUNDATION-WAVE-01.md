## Mathematical authority

Right square pyramid:
- `V = a²h/3`
- `l² = h² + (a/2)²`
- `LSA = 2al`
- `TSA = a² + 2al`

Other pyramid bases represented in this wave:
- rectangular base: `V = Lbh/3`
- known base area `B`: `V = Bh/3`

Conical frustum:
- `l² = h² + (R-r)²`
- `V = πh(R² + Rr + r²)/3`
- `CSA = π(R+r)l`
- `TSA = π[(R+r)l + R² + r²]`

Right square-pyramid frustum, lower side `A`, upper side `a`:
- `l² = h² + ((A-a)/2)²`
- `V = h(A² + Aa + a²)/3`
- `LSA = 2(A+a)l`
- `TSA = 2(A+a)l + A² + a²`
