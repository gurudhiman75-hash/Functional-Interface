## Runtime method

For each permanent QL and deterministic seed, the runtime:

1. resolves the frozen QL definition;
2. selects one approved prototype ancestry within that QL family;
3. invokes the original proven generator from Foundation or Gap Wave 01–04;
4. preserves the generated stem, options, correct index, answer, exact answer, unit, explanation, state and independent-verifier result;
5. wraps the source package with permanent QL, template and canonical solve-mode traceability;
6. validates the frozen mapping and lifecycle locks;
7. rejects unknown QLs, empty seeds and unsupported languages.

No source solver or learner text is reimplemented in the permanent wrapper.
