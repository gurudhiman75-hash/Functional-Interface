## New retained reasoning clusters

### 1. PYRAMID_SURFACE_INVERSE

Surface-area evidence is a meaningful inverse direction not explicitly proven in Waves 01–02.

Representative forms:

- `LSA = Pl/2` → recover slant height or a corresponding surface dimension;
- `TSA = B + Pl/2` → subtract the base, then solve the same inverse contract.

Square-pyramid forms are special cases, not separate families.

### 2. CONICAL_FRUSTUM_SURFACE_INVERSE

Representative forms:

- `CSA = π(R+r)l` → exact π cancellation then recover `l`;
- `TSA = π[(R+r)l + R² + r²]` → remove end discs, then recover `l`.

CSA/TSA are retained as representations inside one inverse reasoning cluster unless later editorial evidence forces a split.

### 3. POLYGONAL_FRUSTUM_SURFACE_INVERSE

For corresponding regular-polygon bases:

- `LSA = (P₁+P₂)l/2`;
- `TSA = B₁ + B₂ + (P₁+P₂)l/2`.

The square-frustum relation is a special case. LSA/TSA target presentations merge into the same surface-inverse reasoning cluster.
