## Symmetry and non-gaps

The following do not presently justify new executable contracts:

- asking for cuboid length instead of breadth when the equation is symmetric;
- replacing one valid numerical dimension set with another;
- renaming a cuboid as a room, tank, crate or box without changing included surfaces or target;
- using another regular-polygon prism base when its area is directly supplied;
- changing direct cost rate values without changing the rate dimension;
- converting among equivalent cubic units when conversion is not the decisive student task;
- asking for the same comparison in reversed wording while preserving the same signed or absolute answer semantic.
