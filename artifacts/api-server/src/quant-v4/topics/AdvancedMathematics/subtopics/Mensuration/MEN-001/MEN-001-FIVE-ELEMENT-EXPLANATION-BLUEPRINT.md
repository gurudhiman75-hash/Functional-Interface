## Circle and ring authorities

- A circular path or annulus is pictured as a flat donut: outer circle minus inner circle.
- Use `R² − r² = (R − r)(R + r)` before multiplying by π.
- Under the declared `π = 22/7` policy, surface applicable benchmarks:
  - `r = 7`: circumference `44`, area `154`;
  - `r = 14`: circumference `88`, area `616`;
  - `r = 21`: circumference `132`, area `1386`.
- Arc and sector tasks use the selected fraction `θ/360` of the full circle.
- Wheel tasks use one circumference per revolution.
