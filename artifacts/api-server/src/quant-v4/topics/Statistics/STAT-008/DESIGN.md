# STAT-008 — Probability Theory

This English controlled-review package covers classical and empirical probability, complement and addition rules, conditional probability, intersections, independence, total probability, Bayes' theorem, and complements of compound events. Twelve permanent QLs reserve STAT-QL-084 through STAT-QL-095 for SSC CGL Tier II and JSO.

All event probabilities use explicitly defined events. In Bayes and total-probability questions, the two groups are exhaustive and mutually exclusive, with prior probabilities summing to one. Probability values and conditional events are bounded to valid ranges.

Question Bank writes, tests and mocks, localization, public publication, and production release remain disabled. Random variables and probability distributions are a later checkpoint.
