# STAT-014 — Index Numbers

This controlled-review package covers the simple aggregative price index, arithmetic mean of price relatives, Laspeyres and Paasche price indices, Fisher's ideal index, value and weighted quantity indices, chain-linking, base shifting, percentage inflation, and time- and factor-reversal tests.

Twelve permanent QLs reserve STAT-QL-164 through STAT-QL-175 for SSC CGL Tier II and JSO. Price/quantity and value ratios are stated with their weights. Index values are percentages unless the test conditions explicitly say ratio form. Fisher's ideal index uses the geometric mean of Laspeyres and Paasche.

Question Bank, test/mock use, localization, public publication, and production release remain disabled. Follow-up review should include weighted average-of-relatives variants, more complex basket tables, and base/chain indices across multiple periods.
