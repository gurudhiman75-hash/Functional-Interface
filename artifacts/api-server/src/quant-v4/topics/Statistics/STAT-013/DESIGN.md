# STAT-013 — Time Series Analysis

This controlled-review package covers the four classical components, additive and multiplicative decomposition, moving averages from raw observations, a least-squares trend, trend forecasting, seasonal-index construction and adjustment, additive seasonal forecasting, and multiplicative deseasonalization.

Sixteen permanent QLs use STAT-QL-152 through STAT-QL-163 and STAT-QL-191 through STAT-QL-194 for SSC CGL Tier II and JSO. STAT-QL-161 computes the least-squares intercept and slope from a stated coded-time series; STAT-QL-162 supplies a fitted trend line for forecasting. Moving-average values remain supplied. The seasonal index convention is seasonal average divided by overall average, multiplied by 100.

Question Bank, test/mock use, localization, public publication, and production release remain disabled. Follow-up review should add ratio-to-moving-average decomposition, deseasonalization and reseasonalization, and broader irregular/cyclical interpretation.
