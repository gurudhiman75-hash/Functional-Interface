# STAT-013 — Time Series Analysis

This controlled-review package covers the four classical components, additive and multiplicative decomposition, moving-average smoothing and centering, fitting a straight-line trend to raw observations by least squares, forecasting from a supplied fitted trend line, and seasonal indices using a stated overall average.

Twelve permanent QLs reserve STAT-QL-152 through STAT-QL-163 for SSC CGL Tier II and JSO. STAT-QL-161 computes the least-squares intercept and slope from a stated coded-time series; STAT-QL-162 supplies a fitted trend line for forecasting. Moving-average values remain supplied. The seasonal index convention is seasonal average divided by overall average, multiplied by 100.

Question Bank, test/mock use, localization, public publication, and production release remain disabled. Follow-up review should add ratio-to-moving-average decomposition, deseasonalization and reseasonalization, and broader irregular/cyclical interpretation.
