# STAT-013 — Time Series Analysis

This controlled-review package covers the four classical components, additive and multiplicative decomposition, moving-average smoothing and centering, fitted values and forecasts from a supplied trend line, and seasonal indices using a stated overall average.

Twelve permanent QLs reserve STAT-QL-152 through STAT-QL-163 for SSC CGL Tier II and JSO. Trend coefficients and moving-average values are supplied; the package does not estimate them from raw data. The seasonal index convention is seasonal average divided by overall average, multiplied by 100.

Question Bank, test/mock use, localization, public publication, and production release remain disabled. Follow-up review should add least-squares fitting from raw series, ratio-to-moving-average decomposition, deseasonalization and reseasonalization, and broader irregular/cyclical interpretation.
