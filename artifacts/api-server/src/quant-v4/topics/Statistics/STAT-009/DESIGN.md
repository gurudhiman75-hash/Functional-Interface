# STAT-009 — Random Variables and Probability Distributions

This controlled-review checkpoint covers discrete probability mass functions, expectation, variance and a higher central moment; affine expectation; binomial, Poisson, normal standardization, exponential survival; and marginal, conditional, independence, and covariance calculations for a two-variable discrete joint distribution.

Fifteen permanent QLs reserve STAT-QL-096 through STAT-QL-110 for SSC CGL Tier II and JSO. Distribution assumptions are stated in each stem. The joint table uses row-major cell frequencies for X and Y values 0 and 1. Exact state recomputation and deterministic checks guard each generated result.

Question Bank, test/mock use, localization, publication, and production release remain disabled. Sampling theory and statistical inference are separate future checkpoints.
