# STAT-010 — Sampling Theory

This controlled-review package covers population and sample, parameter and statistic, sampling and non-sampling error, simple random sampling, proportional stratified allocation, cluster, systematic and multistage designs, convenience, purposive and quota methods, the sampling distribution of a mean, standard error, and a basic sample-size calculation.

Thirteen permanent QLs reserve STAT-QL-111 through STAT-QL-123 for SSC CGL Tier II and JSO. Sampling method concepts are tested with explicitly described scenarios. Sample-size calculation states the normal-approximation formula and inputs; standard error uses independent observations.

Question Bank, tests/mocks, localization, public publication, and production release remain disabled. Statistical inference, hypothesis tests, and confidence intervals remain separate checkpoints.
