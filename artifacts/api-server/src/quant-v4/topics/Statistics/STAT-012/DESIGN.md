# STAT-012 — Analysis of Variance

This controlled-review package covers one-way ANOVA foundations and replicated two-way designs, including interaction degrees of freedom, interaction sums of squares and F tests, interaction interpretation, post-hoc follow-up, and classical one-way assumptions.

Eighteen permanent QLs use STAT-QL-140 through STAT-QL-151 and STAT-QL-185 through STAT-QL-190 for SSC CGL Tier II and JSO. The two-way residual-df formula `(a−1)(b−1)` applies only to the stated layout without replication. Critical-value decisions use the supplied F statistic and critical value; no p-value is inferred. A significant omnibus test supports that at least one population mean differs, without identifying which pairs differ.

The replicated numerical example uses a balanced 2×2 design with two observations per cell. Interaction and residual variation are separated; without replication, their separation is not estimable, so the existing (a−1)(b−1) residual-df convention remains limited to that stated layout. Diagnostic plots, robust alternatives, and additional post-hoc procedures remain future review work. Question Bank, test/mock use, localization, public publication, and production release remain disabled.
