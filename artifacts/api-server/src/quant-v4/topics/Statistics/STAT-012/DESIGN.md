# STAT-012 — Analysis of Variance

This controlled-review package covers the purpose and factor structure of one-way and two-way ANOVA, the sum-of-squares partition, one-way degrees of freedom, mean squares, F ratios, a one-way F calculation, the no-replication two-way residual degrees of freedom, a supplied critical-value decision, and the meaning of a significant omnibus result.

Twelve permanent QLs reserve STAT-QL-140 through STAT-QL-151 for SSC CGL Tier II and JSO. The two-way residual-df formula `(a−1)(b−1)` applies only to the stated layout without replication. Critical-value decisions use the supplied F statistic and critical value; no p-value is inferred. A significant omnibus test supports that at least one population mean differs, without identifying which pairs differ.

Question Bank, test/mock use, localization, public publication, and production release remain disabled. Follow-up review should add replicated two-way designs, interaction decomposition, post-hoc comparisons, and a wider range of ANOVA assumptions and diagnostic checks.
