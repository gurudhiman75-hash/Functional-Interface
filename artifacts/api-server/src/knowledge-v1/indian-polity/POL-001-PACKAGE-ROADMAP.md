## Binding rule

All 27 English CPs are approved/content-frozen. The shared `POL-001` package may register them only through the standard Question Studio **REVIEW_ONLY** lifecycle.

Review-only registration must remain non-writing and non-publishing:
- Question Bank writes disabled;
- tests and mocks ineligible;
- automatic student publication disabled;
- production release not authorised.

Any future content correction must be made in the owning CP source/generator and pass its chapter validation before the package adapter is refreshed.
