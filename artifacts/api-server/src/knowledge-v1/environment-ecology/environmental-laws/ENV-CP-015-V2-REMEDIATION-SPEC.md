# ENV-CP-015 V2 Remediation — Environmental Impact Assessment

**Parent CP:** ENV-CP-015 Environmental Laws & Institutions  
**Lifecycle:** REVIEW CANDIDATE  
**Review layer:** V2 remediation extension  
**Runtime registration:** review-only

## Added scope

- purpose of Environmental Impact Assessment
- EIA as a pre-approval project-impact assessment
- EIA Notification, 2006
- prior environmental clearance for specified projects and activities
- distinction between EIA and routine operational pollution monitoring

The extension deliberately avoids changing project-category lists, threshold values, current notifications and other mutable procedural detail.
