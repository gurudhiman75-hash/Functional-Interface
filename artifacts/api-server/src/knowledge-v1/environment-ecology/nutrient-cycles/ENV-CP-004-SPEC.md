# ENV-CP-004 — Nutrient Cycles

**Chapter:** ENV-001 Environment & Ecology  
**CP:** ENV-CP-004 Nutrient Cycles  
**Lifecycle:** REVIEW CANDIDATE  
**Runtime registration:** blocked pending human approval  

## Scope

Included:
- carbon cycle
- nitrogen cycle
- oxygen cycle
- water cycle
- phosphorus cycle
- nitrogen fixation
- ammonification
- nitrification
- denitrification
- photosynthesis, respiration and decomposition as cycle processes
- basic gaseous vs sedimentary-cycle distinction

Deferred:
- biome-specific ecology (ENV-CP-005)
- biodiversity and conservation (ENV-CP-006 onward)
- pollution-driven disruption of cycles (later pollution CPs)

## Design rules

1. Stems stay short and exam-like.
2. Explanations state the process and its direction clearly.
3. Nitrogen-cycle questions distinguish fixation, ammonification, nitrification and denitrification.
4. The phosphorus cycle is treated as mainly sedimentary and lacking a major atmospheric phase.
5. Water-cycle questions use standard processes such as evaporation, condensation, precipitation and transpiration.
6. Carbon/oxygen questions stay at school-level ecology depth.
7. No numerical flux values or obscure microbial species are required.
8. All questions remain `runtimeRegistered: false` until approval.
