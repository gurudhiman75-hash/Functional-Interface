## 2. Primary official coverage

### CWC — Indus Basin Organisation
Use for:
- Indus system and five main tributaries: Jhelum, Chenab, Ravi, Beas, Satluj
- Indus source description used by CWC
- Indus Tibetan name
- Zaskar, Shyok-Nubra, Shigar, Gilgit associations
- Jhelum source and Wular Lake association
- Chenab formation from Chandra and Bhaga at Tandi
- Ravi source region, perennial character and major tributaries
- Satluj source region, Shipkila course and Spiti association

### BBMB — Beas hydrology
Use for:
- Beas Kund source
- Pir Panjal / Rohtang Pass source area
- Beas as a principal tributary of Satluj

### Government of India Ravi & Beas Waters Tribunal report
Use only for durable river-system geography:
- Ravi belongs to the Indus system and merges into Chenab
- Beas meets Satluj
- Satluj belongs to the Indus system

Do not use this historical report as current treaty-policy authority.

## 3. Exam-frequency evidence

Real competitive-exam material shows repeated demand for:
- direct tributary/parent-river association
- river joining sequence inside the Indus system
- Chandra + Bhaga → Chenab at Tandi
- Sutlej/Shipki La/Trans-Himalayan association
- source and pass questions
- correct/incorrect pair questions
- statement questions using close Indus-system rivers

This evidence controls question-family emphasis, not factual truth.

## 4. Explicit exclusions from initial CP002

The first static CP002 authority excludes:
- current Indus Waters Treaty allocation/status questions
- current India-Pakistan policy or political developments
- changing project status
- exact lengths where official sources use different measurement conventions
- exact basin/catchment values that can vary by study boundary
- over-precise Chandra/Bhaga face-orientation claims where official descriptions are inconsistent
- Kabul/Attock questions until a separate authoritative locator is locked

## 5. Source-discrepancy rule

When two authoritative sources use different levels of precision:
- store the stable common relation
- preserve the exact source wording in provenance notes
- do not manufacture a reconciled precision that neither source explicitly supports

Example: Indus-source material may be expressed broadly as the Kailash/Mansarovar region in school material while CWC specifies Bokhar Chu glacier on the northern slopes of Mt Kailash. CP002 may store both a broad source-region relation and the CWC-specific source-feature relation, but must not rewrite them as a single unsupported exact statement.

## 6. Initial coverage gate

CP002 V1 should not enter question review until the canonical corpus covers at least:
- all five principal Indus tributaries
- Indus source/name/course anchors
- Jhelum source + Wular
- Chenab formation + Tandi + headstreams
- Ravi source + key tributaries
- Beas source + Satluj relation
- Satluj source + Shipkila + Spiti
- at least two cross-river joining relations suitable for order/chain questions

## 7. Editorial standard

Use simple exam English:
- short stems
- familiar geographical terms
- difficulty from relation depth, not wording
- concise question-specific explanations
- no textbook-style filler phrases
- no generic shortcut/trap sections
