# GEO-MIN-001 — Source & Coverage Audit V1

Status: OPEN — REQUIRED BEFORE FREEZE

## Purpose

This audit prevents GEO-MIN-001 from being closed merely because a preselected QL count has been filled. Coverage is expanded until the remaining omissions are either implemented or explicitly judged too low-value for the target exams.

## Stability classes

### Class A — permanent
Suitable for timeless owning QLs:
- mineral classification
- ore-to-metal relationship
- physical/industrial property
- stable major belt, field, basin or district
- durable mine/location association
- mode of occurrence
- long-lived industry linkage
- map relationship

### Class B — dated
Can be asked only with source year in the question/provenance:
- largest producer
- production share
- reserve/resource quantity
- export/import rank or quantity
- consumption share
- mine output
- latest discovery/resource augmentation

### Class C — exclude from static authority
- unsourced coaching-site rankings
- volatile commercial statistics without a named official period
- obscure mine trivia with little exam value
- facts that belong primarily to Current Affairs rather than Static GK

## CP001–CP005 breadth review

### CP001 — Mineral Foundations
Current coverage is strong on mineral/ore distinction, occurrence and classification.
Still inspect:
- resource/reserve terminology only if it can be kept simple and exam-relevant
- geological-control logic behind concentration
- mining/conservation concepts only where they belong to Geography rather than legislation

### CP002 — Iron Ore
Current core belts and major ore types are present.
Still inspect:
- Noamundi / Singhbhum depth
- Keonjhar/Mayurbhanj depth
- Bailadila and export/location significance
- Kudremukh geography
- Goa/west-coast transport logic
- any durable IBM/GSI belt fact absent from NCERT but frequently examinable

### CP003 — Manganese & Chromite
Current manganese, Sukinda and ferro-alloy core is present.
Still inspect:
- Nagpur–Bhandara manganese belt
- additional Odisha/Karnataka manganese districts where durable and exam-relevant
- nickel/cobalt only if they warrant independent semantic QLs
- chromite distribution beyond Sukinda if it adds meaningful examination breadth

### CP004 — Non-ferrous
Current bauxite, copper and lead-zinc core is present.
Still inspect:
- major bauxite plateau/state belts beyond the first examples
- Malanjkhand/Balaghat copper distinction
- Singhbhum copper depth
- Rajasthan lead-zinc district/map coverage
- aluminium location logic where it is truly geographical
- other non-ferrous minerals only if exam value is material

### CP005 — Non-metallic & industrial minerals
This CP is NOT ready to freeze at mica + limestone + gypsum alone.
Mandatory breadth decision required for:
- graphite
- magnesite
- dolomite
- apatite / rock phosphate
- salt
- other stable industrial minerals exposed by IBM reviews

Each candidate must be tested against:
1. Does it recur in SSC/Banking/state-level GK or standard geography material?
2. Is there a durable India/state/belt/use fact?
3. Can it support multiple non-trivial question forms?
4. Is it better placed here than in Industry, Agriculture or Current Affairs?

## Closure condition

CP001–CP005 may be approved only after every item above is either:
- implemented as semantic QLs, or
- explicitly recorded as deferred/excluded with a reason.

There is no target QL count and no target total question count.
