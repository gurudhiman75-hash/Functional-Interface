Q060|ਖਾਣ ਵਾਲੇ ਤੇਲਾਂ ਵਿੱਚ ਮੁੱਲ-ਵਾਧੇ ਦੀ ਸਹੀ ਲੜੀ ਕਿਹੜੀ ਹੈ?|ਕੱਚਾ ਲੋਹਾ → ਤੇਲ → ਸਟੀਲ‖ਕੋਲਾ → ਸਰ੍ਹੋਂ → ਤੇਲ‖ਬਾਕਸਾਈਟ → ਸੋਇਆਬੀਨ → ਐਲੂਮੀਨੀਅਮ‖ਤੇਲ ਬੀਜ → ਪਿੜਾਈ/ਸੋਧਾਈ → ਖਾਣ ਵਾਲਾ ਤੇਲ|ਪ੍ਰੋਸੈਸਿੰਗ ਦੌਰਾਨ ਖੇਤੀ ਤੋਂ ਮਿਲੇ ਤੇਲ ਬੀਜਾਂ ਵਿੱਚੋਂ ਤੇਲ ਕੱਢ ਕੇ ਸੋਧਿਆ ਜਾਂਦਾ ਹੈ।
