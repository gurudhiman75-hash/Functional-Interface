# GEO-PHY-001-CP002 — Himalayan Divisions & Ranges

Status: REVIEW CANDIDATE V1

## Scope

CP002 owns the Himalayan classification framework used in school-standard Indian Geography:

- longitudinal ranges: Himadri, Himachal and Shiwaliks
- range position, broad altitude/structural features and Duns
- west-to-east regional divisions demarcated by river valleys
- Punjab/Kashmir-Himachal, Kumaon, Nepal and Assam Himalayas
- Purvachal beyond the Dihang gorge and its major component hills

The longitudinal and regional classification systems remain separate semantic relations.
