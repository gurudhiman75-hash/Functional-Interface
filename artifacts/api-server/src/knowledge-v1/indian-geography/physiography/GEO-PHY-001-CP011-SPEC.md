# GEO-PHY-001 CP011 — Comparative Physiography & Classification

Status: REVIEW CANDIDATE V1  
Chapter: `GEO-PHY-001 — Indian Physiography & Physical Divisions`  
Permanent QLs: `GEO-PHY-001-QL-091` to `GEO-PHY-001-QL-099`

## Scope

CP011 is the chapter's comparison and classification checkpoint. It does not add obscure trivia. It combines already-qualified facts from earlier checkpoints so learners must distinguish physiographic regions by formation, surface, location and characteristic features.

### Qualified comparisons

- six major physiographic divisions and their defining descriptions
- Himalayan Mountains versus Peninsular Plateau
- Northern Plains versus Indian Desert
- Western versus Eastern Coastal Plains
- Coastal Plains versus offshore Islands
- Lakshadweep versus Andaman and Nicobar
- cross-division correct/incorrect classification
- multi-statement synthesis using only previously qualified relations

## Language and difficulty rule

Learner language must remain short and exam-like. Difficulty comes from comparing or combining qualified facts, not from obscure facts, difficult wording, or trick phrasing. Explanations state the decisive geography directly.

## Source rule
