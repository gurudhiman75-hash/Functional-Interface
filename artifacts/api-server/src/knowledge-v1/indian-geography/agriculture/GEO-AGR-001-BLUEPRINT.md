# GEO-AGR-001 — Indian Agriculture Blueprint

Status: IMPLEMENTATION STARTED — REVIEW ONLY

## 1. Scope

Exam-oriented Indian Geography coverage for agriculture, farming systems, cropping seasons, food crops, commercial crops, plantation crops, horticulture, irrigation-linked crop geography and integrated crop-region reasoning.

Primary authority:
- NCERT Class X Geography, Contemporary India-II, Chapter 4 — Agriculture (current reprint).
Supporting stable framing:
- NCERT social-science teacher material on Indian agricultural regions and cropping patterns.

Avoid unstable yearly production rankings unless explicitly locked to a named year/source.

## 3. Review contract

- CP size follows thematic breadth; there is no fixed 54-question CP target.
- Each permanent QL should have enough owning questions to support real variation. Six is the current baseline, not an upper limit.
- Difficulty should be balanced at the thematic checkpoint level; do not force difficulty by awkward wording.
- Answer positions should be reasonably balanced; no mechanical A/B/C/D quota is required for every CP.
- Stems and explanations must be unique and exam-like.
- Explanations should remain simple and coherent.
- Avoid option-by-option commentary unless the question form genuinely needs it.
- reviewOnly=true and runtimeRegistered=false until explicit release work.

## 4. Quality rules

- Do not hardcode current production ranks without a dated source.
- Prefer durable geography: season, climate, soil, irrigation dependence, crop belt and standard state associations.
- Hard questions must require relation/elimination, not obscure wording.
- Avoid “best describes”, “associated with”, “mainly”, “broadly”, and source-referential wording in learner text.
- Keep Hindi/Punjabi localization for a later dedicated pass after English content approval.
- Do not split a natural crop family merely to satisfy an arbitrary CP size.
