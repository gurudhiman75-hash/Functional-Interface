## 4. Quality rules

- Do not hardcode current production ranks without a dated source.
- Prefer durable geography: season, climate, soil, irrigation dependence, crop belt and standard state associations.
- Hard questions must require relation/elimination, not obscure wording.
- Avoid “best describes”, “associated with”, “mainly”, “broadly”, and source-referential wording in learner text.
- Keep Hindi/Punjabi localization for a later dedicated pass after English content approval.
