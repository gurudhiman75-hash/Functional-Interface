# GEO-IND-001 CP012 — Integrated Exam Forms

Status: NON-OWNING REVIEW LAYER

CP012 does not create permanent semantic fact ownership.

It recombines facts already owned in the industry corpus into:
- match-the-following
- multi-statement questions
- odd-one-out
- raw-material → industry chains
- location-clue identification
- comparative elimination

Its QL identifiers are review-generation families only and must not be counted in the permanent semantic QL total.
