#### English

#### 1. COM003-WORD-TABS-001 — EASY
**Question:** What does a group on the Word Ribbon contain?

A. Related commands
B. Only document pages
C. Only file names
D. Only spelling errors

**Answer:** Related commands
**Explanation:** A Ribbon group collects related commands so they can be used together.
**Trace:** COM003-WORD-TABS-001 · com003-word-tabs-ribbon-groups

B. Quick Access Toolbar

D. Ruler
