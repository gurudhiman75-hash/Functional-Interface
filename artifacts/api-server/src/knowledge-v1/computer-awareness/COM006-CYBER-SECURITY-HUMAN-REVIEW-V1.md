## Questions

### COM-006-QL-001 — Security basics

#### 1. What does the CIA triad protect?

A. Confidentiality, integrity and availability
B. Speed, size and cost
C. Input, output and storage
D. Files, folders and printers

**Answer:** Confidentiality, integrity and availability

**Explanation:** CIA means confidentiality, integrity and availability. These are three basic goals of computer security.

**Difficulty:** EASY

#### 2. What does confidentiality mean?

A. Data is always available
B. Only allowed people can see the data
C. Data is processed quickly
D. Data is printed correctly

**Answer:** Only allowed people can see the data

**Explanation:** Confidentiality keeps data away from people who are not allowed to see it.

**Difficulty:** EASY

#### 3. What does integrity mean?

A. Anyone can read the data
B. A device works without power
C. Data stays correct and unchanged
D. A file is always deleted

**Answer:** Data stays correct and unchanged

**Explanation:** Integrity means data stays correct and is not changed without permission.

**Difficulty:** EASY

#### 4. What does availability mean?

A. Data is hidden from everyone
B. A password is shared
C. A file is copied without checking
D. Data and services are ready when needed

**Answer:** Data and services are ready when needed

**Explanation:** Availability means an authorized user can use the data or service when needed.

**Difficulty:** EASY

### COM-006-QL-002 — Malware

#### 5. Which malware locks files and asks for money?

A. Ransomware
B. Spyware
C. Worm
D. Antivirus

**Answer:** Ransomware

**Explanation:** Ransomware is malicious software that locks or encrypts files and asks for payment.

**Difficulty:** EASY

#### 6. Which malware secretly watches user activity?

A. Firewall
B. Spyware
C. Ransomware
D. Compiler

**Answer:** Spyware

**Explanation:** Spyware is malicious software that secretly collects information about a user or device.

**Difficulty:** EASY

#### 7. Which malware can copy itself and spread through a network?

A. Trojan horse
B. Spyware
C. Worm
D. Screen lock

**Answer:** Worm

**Explanation:** A worm can copy itself and spread from one device to another through a network.

**Difficulty:** MEDIUM

#### 8. What is a Trojan horse in computer security?

A. A device that blocks traffic
B. A safe backup copy
C. A type of printer
D. A harmful program that looks useful

**Answer:** A harmful program that looks useful

**Explanation:** A Trojan horse looks like a useful program but performs a harmful action after it is opened.

**Difficulty:** EASY

### COM-006-QL-003 — Phishing and social engineering

#### 9. What is phishing?

A. A fake message used to steal information
B. A method of saving files
C. A way to cool a computer
D. A type of data cable

**Answer:** A fake message used to steal information

**Explanation:** Phishing uses a fake message or website to trick a person into giving information.

**Difficulty:** EASY

#### 10. What is spear phishing?

A. A virus that attacks only printers
B. A targeted fake message sent to a specific person
C. A method of encrypting a hard disk
D. A tool for cleaning a keyboard

**Answer:** A targeted fake message sent to a specific person

**Explanation:** Spear phishing is a targeted phishing attempt aimed at a particular person or organization.

**Difficulty:** MEDIUM

#### 11. What is social engineering?

A. Repairing damaged computer parts
B. Writing a computer program
C. Tricking people into giving information or access
D. Connecting two printers

**Answer:** Tricking people into giving information or access

**Explanation:** Social engineering uses human trust or fear to get information or access.

**Difficulty:** EASY

#### 12. What should you do with a suspicious login link?

A. Open it quickly
B. Forward it to all contacts
C. Enter the password to test it
D. Do not open it and verify the sender another way

**Answer:** Do not open it and verify the sender another way

**Explanation:** Do not open a suspicious link. Check the sender by using a trusted phone number or website.

**Difficulty:** EASY

### COM-006-QL-004 — Passwords and authentication

#### 13. Which password is safer?

A. A long, unique passphrase
B. A name and birth year
C. The same password used everywhere
D. A short word such as password

**Answer:** A long, unique passphrase

**Explanation:** A long, unique passphrase is harder to guess and should not be reused on another account.

**Difficulty:** EASY

#### 14. Why should passwords not be reused?

A. Reuse makes the computer faster
B. One stolen password can open many accounts
C. Reuse increases screen brightness
D. One password can store more files

**Answer:** One stolen password can open many accounts

**Explanation:** If a reused password is stolen, an attacker may try it on other accounts.

**Difficulty:** EASY

#### 15. What does multi-factor authentication require?

A. Only a username
B. Only a short password
C. Two or more different proof factors
D. A new computer

**Answer:** Two or more different proof factors

**Explanation:** Multi-factor authentication (MFA) uses two or more different proof factors, such as a password and a phone code.

**Difficulty:** EASY

#### 16. What is a one-time password?

A. A password used by every employee
B. A password that never changes
C. A name saved in a file
D. A code meant for one use or a short time

**Answer:** A code meant for one use or a short time

**Explanation:** A one-time password (OTP) is a code that works once or for a short period.

**Difficulty:** EASY

### COM-006-QL-005 — Security controls

#### 17. What does a firewall control?

A. Network traffic entering or leaving a device
B. The colour of a screen
C. The size of a hard disk
D. The speed of a keyboard

**Answer:** Network traffic entering or leaving a device

**Explanation:** A firewall checks network traffic and allows or blocks it according to security rules.

**Difficulty:** EASY

#### 18. What does antivirus software help to do?

A. Increase the monitor size
B. Detect, block or remove malicious software
C. Create a new keyboard
D. Print without paper

**Answer:** Detect, block or remove malicious software

**Explanation:** Antivirus software helps detect, block or remove malicious software.

**Difficulty:** EASY

#### 19. Why are software updates important for security?

A. They always delete personal files
B. They turn off all passwords
C. They can fix known security weaknesses
D. They remove the need for backups

**Answer:** They can fix known security weaknesses

**Explanation:** Software updates often fix security weaknesses that attackers could use.

**Difficulty:** EASY

#### 20. What does least privilege mean?

A. Give every user full access
B. Remove every user account
C. Allow access without a password
D. Give only the access needed for a task

**Answer:** Give only the access needed for a task

**Explanation:** Least privilege gives a user or program only the access needed to do its work.

**Difficulty:** MEDIUM

### COM-006-QL-006 — Safe computer use

#### 21. What is safer when using public Wi-Fi for banking?

A. Avoid banking on an untrusted public network
B. Share the banking password with a friend
C. Turn off every security feature
D. Open unknown links first

**Answer:** Avoid banking on an untrusted public network

**Explanation:** Avoid sensitive banking work on an untrusted public network when a safer connection is available.

**Difficulty:** EASY

#### 22. What should you do with an unknown USB drive?

A. Open every file on it
B. Do not plug it in and report or scan it safely
C. Use it on every computer
D. Give it administrator access

**Answer:** Do not plug it in and report or scan it safely

**Explanation:** An unknown universal serial bus (USB) drive may contain malicious software. Do not use it without a safe check.

**Difficulty:** EASY

#### 23. What should you do with an unexpected email attachment?

A. Open it to see what it contains
B. Send it to more people
C. Do not open it until the sender is verified
D. Rename it and open it

**Answer:** Do not open it until the sender is verified

**Explanation:** An unexpected attachment may contain malicious software. Verify the sender before opening it.

**Difficulty:** EASY

#### 24. Why should you lock your screen?

A. To make the battery charge faster
B. To remove all malware
C. To increase internet speed
D. To stop other people using the device without permission

**Answer:** To stop other people using the device without permission

**Explanation:** A locked screen helps stop unauthorized use when you leave the device.

**Difficulty:** EASY

### COM-006-QL-007 — Data protection

#### 25. What is the best protection against losing files to ransomware?

A. A tested offline backup
B. A longer screen cable
C. A brighter monitor
D. A second keyboard

**Answer:** A tested offline backup

**Explanation:** An offline backup can help restore files after ransomware. The backup should also be tested.

**Difficulty:** EASY

#### 26. What does encryption do?

A. Deletes every copy of the data
B. Changes data into a form that needs a key to read
C. Makes a keyboard wireless
D. Removes all computer viruses

**Answer:** Changes data into a form that needs a key to read

**Explanation:** Encryption changes readable data into protected form. A correct key is needed to read it.

**Difficulty:** EASY

#### 27. What is shoulder surfing?

A. Repairing a computer screen
B. Sharing a file with a team
C. Watching a person to steal private information
D. Cleaning a keyboard

**Answer:** Watching a person to steal private information

**Explanation:** Shoulder surfing means watching a person enter a password or other private information.

**Difficulty:** EASY

#### 28. Why should important backups be tested?

A. To make files public
B. To remove the need for passwords
C. To stop all software updates
D. To confirm that files can be restored

**Answer:** To confirm that files can be restored

**Explanation:** A backup is useful only if its files can be restored when needed.

**Difficulty:** MEDIUM

### COM-006-QL-008 — Incident response

#### 29. What should you do first after noticing a suspicious account login?

A. Change the password and report the event
B. Ignore it forever
C. Share the password online
D. Delete every file immediately

**Answer:** Change the password and report the event

**Explanation:** Change the password from a safe device and report the suspicious login to the service or security team.

**Difficulty:** EASY

#### 30. Who should receive a suspected workplace cyber incident?

A. Every person on social media
B. The workplace information technology or security team
C. An unknown caller
D. A public chat group

**Answer:** The workplace information technology or security team

**Explanation:** The information technology or security team can check the incident and take the correct action.

**Difficulty:** EASY

#### 31. What does a digital signature help verify?

A. The colour of a website
B. The size of a monitor
C. Who sent data and whether it was changed
D. The speed of a printer

**Answer:** Who sent data and whether it was changed

**Explanation:** A digital signature helps verify the sender and shows whether the signed data was changed.

**Difficulty:** MEDIUM

#### 32. What is the safest action after finding malware on a work device?

A. Keep using it for all work
B. Copy the malware to another device
C. Turn off every security tool
D. Disconnect it as instructed and report it

**Answer:** Disconnect it as instructed and report it

**Explanation:** Disconnecting as instructed can limit spread. Report the device so the security team can investigate it.

**Difficulty:** EASY
