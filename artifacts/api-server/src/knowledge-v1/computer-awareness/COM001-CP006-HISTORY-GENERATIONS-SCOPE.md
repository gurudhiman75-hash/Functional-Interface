# COM-001 CP-006 — Computer History and Generations

## Ownership

This CP belongs to **COM-001 Computer Fundamentals & Architecture**. It covers general computer history, early calculating devices, major pioneers, computer generations and basic historical terminology.

It does not cover Internet/Web history owned by COM-004 or networking history owned by COM-005.
