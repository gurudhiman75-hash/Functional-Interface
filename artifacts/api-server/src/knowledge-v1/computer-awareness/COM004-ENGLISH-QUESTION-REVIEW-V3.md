# COM-004 — English Question Review V3

Status: **Revised draft — not approved.**

34 questions with direct stems, four options and simple explanations.

## Q01

**Question:** What does ISP stand for?

A. Internet System Protocol

B. Integrated Service Portal

C. Internal Server Provider

D. Internet Service Provider

**Answer:** D. Internet Service Provider

**Explanation:** ISP stands for Internet Service Provider, the company that provides Internet access.

*Reference: COM004-EN-W1-001-02*

## Q02

**Question:** Which of the following correctly describes the Internet?

A. A collection of only public web pages

B. A global system of interconnected computer networks

C. A program used to open websites

D. A service used only for electronic mail

**Answer:** B. A global system of interconnected computer networks

**Explanation:** The Internet is a global system of interconnected computer networks. E-mail and the Web are services that use it.

*Reference: COM004-EN-W1-001-04*

## Q03

**Question:** Which of the following supports both the World Wide Web and other services such as e-mail?

A. World Wide Web

B. Internet

C. Web page

D. Homepage

**Answer:** B. Internet

**Explanation:** The Internet is the broader network. The World Wide Web is one service that operates over it.

*Reference: COM004-EN-W1-002-07*

## Q04

**Question:** E-mail can be sent through a mail application without opening a website. What does this show about the Internet?

A. E-mail and the World Wide Web are the same service

B. The Internet supports services other than the World Wide Web

C. The Internet exists only when a browser is open

D. Every Internet activity must be a web page

**Answer:** B. The Internet supports services other than the World Wide Web

**Explanation:** E-mail can use the Internet without being a webpage. Therefore, the Internet is broader than the World Wide Web.

*Reference: COM004-EN-W1-002-03*

## Q10

**Question:** Which statement correctly distinguishes a web browser from a search engine?

A. A browser supplies Internet connectivity, while a search engine installs network hardware

B. A browser displays and navigates Web resources, while a search engine helps find indexed resources

C. A browser and a search engine are two names for the same software category

D. A browser only sends e-mail, while a search engine only stores local files

**Answer:** B. A browser displays and navigates Web resources, while a search engine helps find indexed resources

**Explanation:** A browser opens and displays web resources. A search engine finds relevant resources from its index.

*Reference: COM004-EN-W2-005-01*

## Q11

A. Reload or Refresh

B. Bookmark

C. Back

**Answer:** A. Reload or Refresh

**Explanation:** Reload or Refresh requests the current webpage again.

*Reference: COM004-EN-W2-006-01*

## Q12

**Question:** Consider the following statements:

1. Browser cache and cookies serve the same purpose.
2. Browser history can help locate a previously visited page.

Which of the statements is/are correct?

A. Only statement 2 is correct

B. Only statement 1 is correct

C. Both statements are correct

D. Neither statement is correct

**Answer:** A. Only statement 2 is correct

**Explanation:** Cache stores copies of web resources; cookies store website-related data such as session identifiers. History records visited pages, so only statement 2 is correct.

*Reference: COM004-EN-W2-006-09*

## Q13

A. Uploading

B. Bookmarking

C. Refreshing

D. Downloading

**Answer:** D. Downloading

**Explanation:** Downloading means transferring data from a remote service to the user's device.

*Reference: COM004-EN-W2-007-01*

## Q14

**Question:** Which statement about uploading and downloading is incorrect?

A. The terms describe transfer direction relative to the local and remote sides

B. A document can be either uploaded or downloaded depending on direction

C. The terms are determined by whether the file is an image, document or video

D. A video can be either uploaded or downloaded depending on direction

**Answer:** C. The terms are determined by whether the file is an image, document or video

**Explanation:** Upload and download describe the direction of transfer, not the type of file.

*Reference: COM004-EN-W2-007-11*

## Q16

**Question:** Which part of `https://example.org/reports/index.html` is the URL scheme?

A. example.org

B. /reports/index.html

C. .org

D. https

**Answer:** D. https

**Explanation:** In this URL, `https` is the scheme. It identifies the access protocol used for the resource.

## Q17

**Question:** Which protocol uses TLS to protect communication between a browser and a web server?

A. HTTPS

B. HTTP

C. SMTP

D. FTP

**Answer:** A. HTTPS

**Explanation:** HTTPS is the secure form of HTTP and protects web communication using TLS.

*Reference: COM004-EN-W3-009-01*

## Q18

**Question:** Which statement correctly distinguishes HTTP from HTTPS?

A. HTTP is a browser and HTTPS is a search engine

B. HTTPS protects HTTP communication with TLS, while plain HTTP lacks that TLS protection

C. HTTPS is proof that every site using it is genuine

D. HTTP is used only for e-mail while HTTPS is used only for file storage

**Answer:** B. HTTPS protects HTTP communication with TLS, while plain HTTP lacks that TLS protection

**Explanation:** HTTPS adds TLS protection to HTTP communication. Plain HTTP does not provide that TLS protection.

*Reference: COM004-EN-W3-009-02*

## Q33

**Question:** Which of the following must an Internet-banking user keep confidential?

B. The name of the banking service

## Q34

**Question:** Which statement correctly describes the role of HTTPS when verifying a banking website?

A. HTTPS automatically proves every site owner's honesty

B. A correct bank domain makes connection protection irrelevant

C. Domain verification and HTTPS are two names for exactly the same check

D. HTTPS can protect the connection, while the user must separately verify that the domain belongs to the intended bank

**Answer:** D. HTTPS can protect the connection, while the user must separately verify that the domain belongs to the intended bank

**Explanation:** HTTPS protects the connection, but it does not prove that the website is the genuine bank. The domain must also be verified.

*Reference: COM004-EN-W5-017-07*
