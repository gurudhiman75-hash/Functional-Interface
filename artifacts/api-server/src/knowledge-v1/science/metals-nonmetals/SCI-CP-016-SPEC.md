# SCI-CP-016 — Metals & Non-Metals

Status: REVIEW-ONLY CANDIDATE V2
Chapter: `SCI-001`
CP: `SCI-CP-016`

## Scope

- physical properties and important exceptions
- common uses linked to metallic/non-metallic properties
- reactions with oxygen, water and dilute acids
- reactivity series and displacement
- ionic bonding, conductivity, melting point and qualified water-solubility behaviour
- mineral/ore vocabulary and common ore-metal pairs: bauxite, haematite, magnetite, zinc blende, calamine, galena and cinnabar
- gangue, flux, slag, roasting and calcination
- extraction according to reactivity, electrolysis, thermite and electrolytic refining
- corrosion of iron and copper, protection methods and alloys
- integrated metallurgy and reactivity applications
