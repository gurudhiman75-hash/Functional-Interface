# SCI-CP-012 — Atomic Structure

Status: REVIEW-ONLY CANDIDATE V1
Chapter: `SCI-001`
CP: `SCI-CP-012`

## Scope

- electron, proton and neutron: charge, relative mass and location
- atomic number and mass number
- nucleus and basic shell model
- proton-neutron-electron counting for neutral atoms and simple ions
- shell-wise electronic configuration for the first 20 elements
- valence electrons and simple valency
- formation of common cations and anions at school level
- isotopes and isobars with familiar examples
- Thomson, Rutherford, Bohr and Chadwick at general-exam depth
- simple application and statement questions using the above ideas

Periodic-table groups, periods and trends belong to `SCI-CP-013`. Chemical reactions belong to `SCI-CP-014`.
