# SCI-CP-013 — Elements, Compounds & Periodic Table

Status: REVIEW-ONLY CANDIDATE V1
Chapter: `SCI-001`
CP: `SCI-CP-013`

## Scope

- element and compound distinction, with mixture only where needed for comparison
- common chemical symbols and familiar compound formulae
- basic classification of metals, non-metals and metalloids
- modern periodic table: groups and periods
- important families: alkali metals, alkaline earth metals, halogens and noble gases
- locating first-20 main-group elements from shell-wise electronic configuration
- basic periodic trends: atomic size, metallic/non-metallic character and valency
- Döbereiner, Newlands, Mendeleev and the modern periodic law
- familiar exam-grade application and statement questions

Detailed metal/non-metal reactions and properties belong to `SCI-CP-016`. Bonding and carbon chemistry are handled in later Chemistry CPs.
