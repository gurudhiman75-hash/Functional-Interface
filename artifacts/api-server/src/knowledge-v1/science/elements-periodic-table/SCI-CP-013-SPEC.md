# SCI-CP-013 — Elements, Compounds & Periodic Table

Status: REVIEW-ONLY CANDIDATE V2
Chapter: `SCI-001`
CP: `SCI-CP-013`

## Scope

- element and compound classification, with mixture only where useful for comparison
- common element symbols and familiar compound formulae
- metals, non-metals, metalloids and broad table regions
- modern periodic table: groups, periods and outer-shell basis of similar properties
- important families: alkali metals, alkaline earth metals, halogens and noble gases
- locating familiar main-group elements from shell configuration and inferring configuration from position
- periodic trends: atomic size, metallic/non-metallic character and simple valency trend
- Döbereiner, Newlands, Mendeleev and the modern periodic law
- integrated multi-clue periodic reasoning suitable for one-day competitive exams

Formula construction, ions and bonding basics are owned by `SCI-CP-012`. Detailed metal/non-metal reactions belong to `SCI-CP-016`.
