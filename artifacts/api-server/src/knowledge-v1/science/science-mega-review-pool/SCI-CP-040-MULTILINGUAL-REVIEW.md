## Q01

**Hindi**: जूल किस भौतिक राशि की SI इकाई है?

D. ਸੰਵੇਗ ਪੁੰਜ 'ਤੇ ਨਿਰਭਰ ਨਹੀਂ ਕਰਦਾ
