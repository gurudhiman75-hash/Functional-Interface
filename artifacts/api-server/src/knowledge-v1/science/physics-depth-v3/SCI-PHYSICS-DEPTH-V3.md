# SCI Physics Depth V3 — Wave 1 (CP001–CP004)

Status: **REVIEW-ONLY CANDIDATE V3**

## Purpose

Physics Exhaustive V2 established broad exam-level coverage and a 3,480-question semantic pool. V3 does not duplicate that fixed semantic layer. It adds true solver-backed and parameterized application generation so that numerical and condition-change questions vary by the underlying physical data, unknown quantity and reasoning path.

## Wave 1 scope

### SCI-CP-001 — Measurement, Units & Basic Physics

Adds 124 generated questions across unit conversion, vernier reading, screw-gauge least count and reading, percentage error, density/reverse density calculation, area conversion and volume conversion.

### SCI-CP-002 — Motion, Force & Laws of Motion

Adds 144 generated questions across speed-distance-time, acceleration, F = ma, momentum, impulse, velocity-time graph area, centripetal force and equal-distance average speed.

### SCI-CP-003 — Work, Energy & Power

Adds 132 generated questions across work, power, kinetic energy, potential energy, machine efficiency, mechanical advantage, velocity ratio, MA/VR efficiency and lever-moment equilibrium.

### SCI-CP-004 — Gravitation, Pressure & Fluids

Adds 128 generated questions across weight, inverse-square gravitation, mass proportionality, density/reverse density, pressure, hydrostatic pressure, Pascal-law hydraulics, Archimedes/buoyancy, relative density, flotation and pressure-area change.

## Quality rules

- Every generated numerical item uses a deterministic solver relation.
- Explanations show the decisive calculation or relation.
- Four distinct options are mandatory; placeholder distractors are forbidden.
- Correct-answer position is exactly balanced inside each CP.
- Each CP contains Easy, Medium and Hard questions.
- Hard questions remain one-day-exam application/discrimination, not JEE/NEET-level derivations.
- Stable source/provenance IDs are retained.
- No Question Studio registration, Question Bank write, mock/test eligibility, learner publication or runtime registration is allowed before explicit human approval.
