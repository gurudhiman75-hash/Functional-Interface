## Q01 · Easy · QL 1

**English reference:** Which organ system takes in oxygen and removes carbon dioxide from the body?

### Hindi

B. पाचन तंत्र
C. उत्सर्जन तंत्र
D. अंतःस्रावी तंत्र

**Answer:** A. श्वसन तंत्र

**Explanation:** श्वसन तंत्र शरीर में ऑक्सीजन पहुँचाता है और कोशिकीय श्वसन से बनी कार्बन डाइऑक्साइड को बाहर निकालता है। यह कोशिकाओं में वायवीय श्वसन के लिए आवश्यक गैसों का आदान-प्रदान कराता है।

## Q03 · Medium · QL 1

**English reference:** Which sequence correctly shows the path of inhaled air?

### Hindi

श्वास में ली गई वायु का सही मार्ग कौन-सा है?

A. नाक → श्वासनली → ग्रसनी → कंठ → श्वसनी → फेफड़े
B. नाक → कंठ → ग्रसनी → श्वसनी → श्वासनली → फेफड़े
C. नाक → ग्रसनी → कंठ → श्वासनली → श्वसनी → फेफड़े
D. नाक → श्वसनी → श्वासनली → ग्रसनी → कंठ → फेफड़े

**Answer:** C. नाक → ग्रसनी → कंठ → श्वासनली → श्वसनी → फेफड़े

**Explanation:** वायु नाक, ग्रसनी, कंठ और श्वासनली से होकर श्वसनियों में जाती है। श्वसनियाँ आगे छोटी शाखाओं में बँटती हैं जो वायुकोषों तक पहुँचती हैं।

### Punjabi

ਸਾਹ ਨਾਲ ਅੰਦਰ ਗਈ ਹਵਾ ਦਾ ਸਹੀ ਰਸਤਾ ਕਿਹੜਾ ਹੈ?

A. ਨੱਕ → ਸਾਹ ਨਲੀ → ਫੈਰਿੰਕਸ → ਲੈਰਿੰਕਸ → ਬਰਾਂਕਾਈ → ਫੇਫੜੇ
B. ਨੱਕ → ਲੈਰਿੰਕਸ → ਫੈਰਿੰਕਸ → ਬਰਾਂਕਾਈ → ਸਾਹ ਨਲੀ → ਫੇਫੜੇ
C. ਨੱਕ → ਫੈਰਿੰਕਸ → ਲੈਰਿੰਕਸ → ਸਾਹ ਨਲੀ → ਬਰਾਂਕਾਈ → ਫੇਫੜੇ
D. ਨੱਕ → ਬਰਾਂਕਾਈ → ਸਾਹ ਨਲੀ → ਫੈਰਿੰਕਸ → ਲੈਰਿੰਕਸ → ਫੇਫੜੇ

**Answer:** C. ਨੱਕ → ਫੈਰਿੰਕਸ → ਲੈਰਿੰਕਸ → ਸਾਹ ਨਲੀ → ਬਰਾਂਕਾਈ → ਫੇਫੜੇ

**Explanation:** ਹਵਾ ਨੱਕ ਤੋਂ ਫੈਰਿੰਕਸ, ਲੈਰਿੰਕਸ ਅਤੇ ਸਾਹ ਨਲੀ ਰਾਹੀਂ ਬਰਾਂਕਾਈ ਵਿੱਚ ਜਾਂਦੀ ਹੈ। ਬਰਾਂਕਾਈ ਅੱਗੇ ਛੋਟੀਆਂ ਨਲੀਆਂ ਵਿੱਚ ਵੰਡ ਕੇ ਹਵਾ ਨੂੰ ਐਲਵੀਓਲਾਈ ਤੱਕ ਲਿਜਾਂਦੀ ਹੈ।

**Answer:** D. ਸਾਹ ਲੈਣਾ ਫੇਫੜਿਆਂ ਵਿੱਚ ਹਵਾ ਦੇ ਅੰਦਰ-ਬਾਹਰ ਜਾਣ ਦੀ ਭੌਤਿਕ ਕਿਰਿਆ ਹੈ

**Explanation:** ਸਾਹ ਲੈਣ ਵਿੱਚ ਹਵਾ ਫੇਫੜਿਆਂ ਅੰਦਰ ਅਤੇ ਬਾਹਰ ਜਾਂਦੀ ਹੈ। ਕੋਸ਼ਿਕੀ ਸ਼ਵਾਸ ਕੋਸ਼ਿਕਾਵਾਂ ਦੇ ਅੰਦਰ ਭੋਜਨ ਤੋਂ ਊਰਜਾ ਕੱਢਣ ਵਾਲੀ ਰਸਾਇਣਕ ਕਿਰਿਆ ਹੈ।
