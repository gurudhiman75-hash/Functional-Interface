**व्याख्या:** बैक्टीरिया प्रोकैरियोटिक कोशिकाएँ हैं जिनमें झिल्ली से घिरा सच्चा केंद्रक नहीं होता और कई बैक्टीरिया द्विखंडन से बढ़ते हैं।

A. ਫੰਗਸ
B. ਬੈਕਟੀਰੀਆ

D. ਕੇਂਦਰਕ ਵਾਲੀ ਐਲਗੀ
