## Q01 · Easy · QL 1

**English reference:** Which organ is the first part of the human alimentary canal?

### Hindi

D. ग्रासनली

**Answer:** A. मुख

**Explanation:** पाचन की शुरुआत मुख से होती है। यहाँ भोजन लिया जाता है, चबाया जाता है और लार के साथ मिलाकर ग्रासनली की ओर भेजा जाता है।

A. ਮੂੰਹ
B. ਅੰਨਦਰ
C. ਛੋਟੀ ਆੰਤ
D. ਭੋਜਨ ਨਲੀ

**Answer:** A. ਮੂੰਹ

**Explanation:** ਪਚਨ ਦੀ ਸ਼ੁਰੂਆਤ ਮੂੰਹ ਤੋਂ ਹੁੰਦੀ ਹੈ। ਇੱਥੇ ਭੋਜਨ ਲਿਆ, ਚੱਬਿਆ ਅਤੇ ਲਾਰ ਨਾਲ ਮਿਲਾਇਆ ਜਾਂਦਾ ਹੈ, ਫਿਰ ਭੋਜਨ ਨਲੀ ਵੱਲ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ।

## Q03 · Medium · QL 1

**English reference:** Which sequence correctly shows the passage of food through the alimentary canal?

### Hindi

आहार नाल में भोजन के मार्ग का सही क्रम कौन-सा है?

A. मुख → आमाशय → ग्रासनली → बड़ी आंत → छोटी आंत
B. मुख → छोटी आंत → आमाशय → ग्रासनली → बड़ी आंत
C. मुख → ग्रासनली → आमाशय → छोटी आंत → बड़ी आंत
D. मुख → ग्रासनली → बड़ी आंत → आमाशय → छोटी आंत

**Answer:** C. मुख → ग्रासनली → आमाशय → छोटी आंत → बड़ी आंत

**Explanation:** भोजन सामान्यतः मुख से ग्रासनली, फिर आमाशय, छोटी आंत और बड़ी आंत से होकर आगे बढ़ता है। हर भाग पाचन या अवशोषण में अलग भूमिका निभाता है।

### Punjabi

ਪਚਨ ਨਲੀ ਵਿੱਚ ਭੋਜਨ ਦੇ ਜਾਣ ਦਾ ਸਹੀ ਕ੍ਰਮ ਕਿਹੜਾ ਹੈ?

A. ਮੂੰਹ → ਅੰਨਦਰ → ਭੋਜਨ ਨਲੀ → ਵੱਡੀ ਆੰਤ → ਛੋਟੀ ਆੰਤ
B. ਮੂੰਹ → ਛੋਟੀ ਆੰਤ → ਅੰਨਦਰ → ਭੋਜਨ ਨਲੀ → ਵੱਡੀ ਆੰਤ
C. ਮੂੰਹ → ਭੋਜਨ ਨਲੀ → ਅੰਨਦਰ → ਛੋਟੀ ਆੰਤ → ਵੱਡੀ ਆੰਤ
D. ਮੂੰਹ → ਭੋਜਨ ਨਲੀ → ਵੱਡੀ ਆੰਤ → ਅੰਨਦਰ → ਛੋਟੀ ਆੰਤ

**Answer:** C. ਮੂੰਹ → ਭੋਜਨ ਨਲੀ → ਅੰਨਦਰ → ਛੋਟੀ ਆੰਤ → ਵੱਡੀ ਆੰਤ

**Explanation:** ਭੋਜਨ ਆਮ ਤੌਰ ਤੇ ਮੂੰਹ ਤੋਂ ਭੋਜਨ ਨਲੀ, ਫਿਰ ਅੰਨਦਰ, ਛੋਟੀ ਆੰਤ ਅਤੇ ਵੱਡੀ ਆੰਤ ਵਿੱਚੋਂ ਲੰਘਦਾ ਹੈ। ਹਰ ਹਿੱਸਾ ਪਚਨ ਜਾਂ ਸੋਖ ਵਿੱਚ ਵੱਖਰਾ ਕੰਮ ਕਰਦਾ ਹੈ।
