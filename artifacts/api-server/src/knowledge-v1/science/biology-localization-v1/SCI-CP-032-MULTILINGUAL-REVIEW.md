## Q03 · Medium · Taxonomy, hierarchy and binomial nomenclature

**English reference:** Which sequence shows the correct order from broader to more specific categories?

A. Species → Genus → Family → Order → Class → Phylum → Kingdom
B. Kingdom → Class → Phylum → Family → Order → Genus → Species
C. Kingdom → Phylum → Class → Order → Family → Genus → Species
D. Phylum → Kingdom → Class → Order → Family → Species → Genus

**Reference answer:** C. Kingdom → Phylum → Class → Order → Family → Genus → Species

### Hindi

D. संघ → जगत → वर्ग → गण → कुल → प्रजाति → वंश

**उत्तर:** C. जगत → संघ → वर्ग → गण → कुल → वंश → प्रजाति

**व्याख्या:** मानक वर्गीकरण क्रम जगत से शुरू होकर क्रमशः अधिक विशिष्ट होते हुए प्रजाति तक जाता है।

C. ਜਗਤ → ਸੰਘ → ਵਰਗ → ਗਣ → ਕੁਲ → ਵੰਸ਼ → ਪ੍ਰਜਾਤੀ

**ਵਿਆਖਿਆ:** ਵਰਗੀਕਰਨ ਦਾ ਮਿਆਰੀ ਕ੍ਰਮ ਜਗਤ ਤੋਂ ਸ਼ੁਰੂ ਹੋ ਕੇ ਹੌਲੀ-ਹੌਲੀ ਹੋਰ ਖਾਸ ਹੁੰਦਾ ਹੋਇਆ ਪ੍ਰਜਾਤੀ ਤੱਕ ਜਾਂਦਾ ਹੈ।

## Q06 · Hard · Taxonomy, hierarchy and binomial nomenclature

**Reference answer:** B. They are closely related but not the same species
