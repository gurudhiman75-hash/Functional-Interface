# SCI-CP-006 — Sound — Review Candidate V1

## Scope
Exam-level General Science coverage for SSC, Railways, Police and state one-day exams.

## QL contract
1. Sound production and vibrating sources
2. Propagation, media, compressions and rarefactions
3. Frequency, amplitude, pitch and loudness
4. Time period, wavelength and wave-speed relation
5. Audible, infrasonic and ultrasonic sound
6. Echo, reflection and SONAR
7. Human ear and hearing
8. Noise pollution and reverberation
9. Statement I/II synthesis
10. Mixed sound application and calculation

## Review batch
- 60 questions total; 6 per QL.
- Difficulty: Easy 18 / Medium 30 / Hard 12.
- Answer positions: A15 / B15 / C15 / D15.
- Explanations must be short, beginner-friendly and show calculations where needed.
- Distractors stay in the same conceptual neighbourhood.
- No runtime registration, Question Bank write, mock/test eligibility, or learner publication before explicit approval.

## Source anchors
- NCERT Science VIII — Sound
- NCERT Science IX — Sound

## Acceptance gate
The CP is review-ready only when its qualification test, review export and API build pass. Human approval remains mandatory before promotion.
