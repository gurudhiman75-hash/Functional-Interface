# SCI-001 — General Science Content Engine

Status: FOUNDATION BLUEPRINT V1
Lifecycle: REVIEW-FIRST

## Goal

Build exam-level General Science for SSC, Railways, Police, Banking and similar one-day competitive exams. The engine must remain fact-rich but concept-aware: direct recall, simple conceptual understanding and familiar everyday application are all required. Advanced JEE/NEET depth is out of scope.

## Engine rules

- Stems must read like real competitive-exam questions, not database prompts.
- Repeated wording is acceptable only where it is genuinely an instruction pattern such as statement questions.
- Distractors must come from the same conceptual neighbourhood as the answer.
- Explanations must be short, beginner-friendly and complete enough to teach the tested point.
- Easy = direct fact/basic recognition; Medium = concept + fact/application; Hard = multi-fact discrimination or simple reasoning with familiar concepts.
- Hard must not mean obscure trivia.
- Structured fact IDs and source IDs must be retained for every generated review item.
- Every CP is review-only until explicit human approval. No Question Studio runtime registration, Question Bank write, test/mock eligibility, public publication or automatic learner delivery is opened by review implementation alone.
