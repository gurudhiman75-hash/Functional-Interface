# SCI-CP-001 — Measurement, Units & Basic Physics

Status: REVIEW-ONLY CANDIDATE V1
Chapter: `SCI-001`
CP: `SCI-CP-001`

## Scope

Owns the measurement foundation needed by later physics CPs:

- SI base quantities and units commonly tested in one-day exams
- common derived SI units and their defining relations
- measuring instruments and their use
- scalar and vector distinction
- basic unit conversions
- area, volume, density and relative density units
- simple instrument-selection applications

Detailed motion/force belongs to `SCI-CP-002`; work/energy/power applications belong to `SCI-CP-003`; electricity theory belongs to `SCI-CP-008`.
