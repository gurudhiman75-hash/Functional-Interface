# PGK-001 Match-the-Following Extension V1

Status: REVIEW_CANDIDATE
Lifecycle: review-only / additive extension
Base authority: PGK-001-FINAL-FACTUAL-CERTIFICATION-V1
Frozen core impact: NONE — the approved 1,092-question English corpus and its 182 permanent QLs are not modified.

## Purpose

The PGK-001 blueprint explicitly includes `match the following` as an exam form, but the frozen corpus primarily realizes pair/set knowledge through ordinary MCQ wording such as "Which pair is correctly matched?". This extension adds genuine List-I / List-II questions with answer-code options.

## Design

- 24 genuine List-I / List-II questions.
- 12 carefully selected CPs, 2 questions per CP.
- Four entries in List I and four entries in List II.
- Answer options are mapping codes such as `A-3, B-1, C-4, D-2`.
- English, Hindi and Punjabi learner surfaces.
- Native-language instructions and explanations.
- No changes to the frozen 1,092-question core.
- No Question Bank writes, test/mock eligibility, public publication or production release.
- Question Studio integration is NOT authorized by this review artifact.
