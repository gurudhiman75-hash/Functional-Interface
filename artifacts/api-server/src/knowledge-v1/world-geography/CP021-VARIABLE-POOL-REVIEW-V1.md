## WGE-001-CP021-Q-VP01-DESERT-SAHARA

QL: WGE-001-CP021-QL001 · Difficulty: Easy · Source: WGE-PHY-021A

### English

A. Sahara **(Answer)**

C. Namib
D. Gobi

Explanation: Sahara: This vast hot desert covers much of North Africa.
