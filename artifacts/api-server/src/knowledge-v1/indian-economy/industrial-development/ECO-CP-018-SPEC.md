Static-GK coverage of India's industrial development, industrial policy, industrial statistics, MSMEs, core industries and major industrial-development frameworks.

## Editorial rules

- Use short SSC/Banking/State-exam style stems.
- Ordinary stems must be complete questions ending in `?`.
- Avoid editorial framing and terminal-colon prompt fragments.
- Explanations should normally be 1–2 short sentences with the deciding fact and minimum reason.
- Hard questions must test close distinctions, chronology or multi-concept classification rather than simple date recall.

## Static boundary

Exclude current IIP/core-industry growth rates, current MSME thresholds or registration counts, current manufacturing share, live FDI limits, current SEZ unit/export data, current corridor investment values, current Make in India sector statistics and current scheme allocations.
