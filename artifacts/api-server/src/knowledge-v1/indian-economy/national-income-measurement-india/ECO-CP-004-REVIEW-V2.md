### 1. Easy
Which method adds the value created at each stage of production?

A. Income method  
B. Value added method  
C. Expenditure method  
D. Price index method

**Answer:** B. Value added method

**Explanation:** The value added method sums the new value created at each production stage.

### 2. Easy
Which method adds incomes generated from production?

A. Expenditure method  
B. Value added method  
C. Income method  
D. Price index method

**Answer:** C. Income method

**Explanation:** The income method adds incomes generated through production.

### 3. Medium
An estimate adds household consumption, government consumption, investment and net exports. Which method is used?

A. Value added method  
B. Income method  
C. Expenditure method  
D. Price index method

**Answer:** C. Expenditure method

**Explanation:** These are components of final expenditure.

### 4. Hard
Sales are recorded at several production stages. Which method best avoids counting the same input twice?

A. Income method  
B. Value added method  
C. Expenditure method  
D. Price index method

**Answer:** B. Value added method

**Explanation:** It counts only the value created at each stage and avoids repeated counting of inputs.

### 5. Easy
How is flour bought by a bakery to make bread classified in national-income measurement?

A. Final  
B. Intermediate  
C. Depends on its use  
D. Cannot be classified from the information given

**Answer:** B. Intermediate

**Explanation:** The flour is used in producing another good, so it is intermediate consumption.

### 6. Medium
How is a new machine bought by a factory for production classified in national-income measurement?

A. Final  
B. Intermediate  
C. Depends on its use  
D. Cannot be classified from the information given

**Answer:** A. Final

**Explanation:** A capital good bought for investment is treated as final use, not intermediate consumption.

### 7. Medium
What problem arises if the full value of both flour and the bread made from it is counted?

A. Depreciation adjustment  
B. Double counting  
C. Under-counting final output  
D. Price-base adjustment

**Answer:** B. Double counting

**Explanation:** The value of flour is already included in the value of bread.

### 8. Hard

**Answer:** A. Intermediate output is counted more than once

**Explanation:** Earlier-stage output is already included in the value of the later product.

### 16. Hard
Sum of GVA is 700, product taxes are 60 and product subsidies are 20. What is GDP?

A. 660  
B. 680  
C. 740

**Answer:** C. 740

**Explanation:** Net product taxes = 60 - 20 = 40. GDP = 700 + 40 = 740.
