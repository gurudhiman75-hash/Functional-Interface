# ECO-CP-012 — Review V2 Stem Polish

V2 keeps the V1 facts, options, answers, explanations, sources and difficulty unchanged. Only question-stem wording is editorially improved.

## Rule

Normal MCQ stems must read as complete exam questions. Label-style prompts ending in a colon are not accepted.

Examples:

- `Public finance mainly deals with:` → `What does public finance mainly deal with?`
- `Fiscal deficit is calculated as:` → `Which formula is used to calculate the fiscal deficit?`
- `Government borrowing is classified as:` → `How is Government borrowing classified?`
- `FRBM stands for:` → `What is the full form of FRBM?`
- `An automatic stabiliser works:` → `How does an automatic stabiliser work?`

Statement-format questions may use a colon internally where structurally natural, but the overall stem should still end as a complete question.

The V2 QA test rejects any generated stem that ends with `:` and requires generated stems to end with `?`.
