# ECO-CP-025 — Banking Regulation, Financial Inclusion & Payment Systems

## Coverage-gap authority

Added by the exhaustive Economy gap audit to cover prudential regulation, inclusion architecture and payment systems that were not substantively represented in CP007–CP011.

## Scope

- Basel capital framework and capital-adequacy logic;
- Basel III implementation in India from 2013;
- financial inclusion concept and PMJDY;
- PMMY/MUDRA and micro-enterprise credit;
- NABARD SHG-Bank Linkage;
- NPCI and UPI basics;
- RTGS and NEFT distinction;
- Payment and Settlement Systems Act, 2007 and RBI's role;
- mixed institution/function and chronology questions.

## Static boundary

Exclude current capital ratios beyond framework recognition, current scheme beneficiary counts, changing PMMY loan limits, transaction caps/charges, live UPI volumes, current payment-system limits and current bank-specific metrics.

## Review architecture

32 questions / 8 QLs.
