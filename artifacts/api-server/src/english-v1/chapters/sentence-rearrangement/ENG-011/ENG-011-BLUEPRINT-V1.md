# ENG-011 — Sentence Rearrangement — Blueprint V1

Status: `IMPLEMENTATION_IN_PROGRESS__REVIEW_ONLY`

## Ownership
ENG-011 owns questions where labelled fragments / clauses must be rearranged to form one complete, grammatically and logically correct sentence.

It does not duplicate:
- ENG-010 Para Jumbles (multi-sentence paragraph ordering);
- sentence improvement / error detection;
- cloze or RC.

## Checkpoints
- CP001 — SSC Standard: 4 fragments, clear grammar/syntax chain, Easy/Medium.
- CP002 — SSC Advanced: 5 fragments, closer clause attachment and modifiers, Medium/Hard.
- CP003 — Banking Prelims: 4–5 fragments, business/economy/social contexts, Medium/Hard.
- CP004 — Banking Mains: 5–6 fragments, denser clause structure, Medium/Hard.
- CP005 — deterministic composer + Question Studio integration.

## Quality rules
- Exactly one best complete sentence.
- No punctuation/capitalisation leakage that gives away the answer.
- Distractor sequences must remain plausible.
- Explanation should identify the grammatical anchor and main clause chain.
- Review-only until human approval.
