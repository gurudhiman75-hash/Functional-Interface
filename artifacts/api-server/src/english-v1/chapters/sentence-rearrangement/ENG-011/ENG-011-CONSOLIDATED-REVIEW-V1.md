## Format
Each question presents 4–5 labelled fragments (up to 5 in current V1 sets), asks for the correct order, gives four sequence options and a short explanation identifying the grammatical anchor and clause chain.

## Quality controls
- exactly one keyed sequence per authority;
- deterministic generation;
- plausible sequence distractors;
- no Para Jumble ownership overlap;
- SSC and Banking profiles separated by clause complexity;
- review-only Question Studio lifecycle.

## Review focus
1. Does each reconstructed sentence sound natural and exam-grade?
2. Is there any alternate defensible fragment order?
3. Are distractors plausible enough?
4. Do Banking Mains items feel clearly denser than SSC Standard?
