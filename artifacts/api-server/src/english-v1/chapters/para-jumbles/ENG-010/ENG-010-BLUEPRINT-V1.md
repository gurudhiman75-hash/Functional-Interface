# ENG-010 — Para Jumbles — Blueprint V1

Status: `IMPLEMENTATION_IN_PROGRESS__REVIEW_ONLY`

## Ownership
ENG-010 owns sentence-ordering / para-jumble questions where a set of sentences must be arranged into one coherent paragraph.

It does not duplicate sentence-level grammar correction, cloze, RC, or standalone sentence rearrangement.

## Checkpoints
- CP001 — SSC Standard: 5 sentences, clear opening + logical links, Easy/Medium.
- CP002 — SSC Advanced: 6 sentences, closer transitions, pronoun/reference and cause-effect chains, Medium/Hard.
- CP003 — Banking Prelims: 5 sentences, business/social/economy contexts, Medium/Hard.
- CP004 — Banking Mains: 6 sentences, denser editorial/analytical structure, Medium/Hard.
- CP005 — deterministic full-set composer + Question Studio integration.

## Quality rules
- Exactly one best complete order.
- No answer leakage through labels.
- Distractors must be plausible permutations, not random noise.
- Explanation should state the opener and the key logical chain in simple language.
- Original passages only; public papers calibrate format, not wording.
- Question Studio remains review-only until human approval.
