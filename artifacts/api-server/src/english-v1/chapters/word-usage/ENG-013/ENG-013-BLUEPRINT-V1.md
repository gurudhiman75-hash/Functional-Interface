# ENG-013 — Word Usage / Contextual Usage — Blueprint V1

Status: `IMPLEMENTATION_IN_PROGRESS__REVIEW_ONLY`

## Ownership
ENG-013 owns vocabulary-in-context questions where the same target word is used in multiple sentences and the learner identifies:
- the sentence where the word is used correctly;
- the sentence where the word is used incorrectly;
- controlled Banking-style contextual usage sets.

ENG-013 does not own:
- sentence improvement/error correction (ENG-002);
- standalone grammar fillers (ENG-003);
- synonym/antonym recall (ENG-004);
- spelling (ENG-007);
- word swap (ENG-012).

## Checkpoints
- CP001 — SSC Standard Word Usage: common exam vocabulary, one clearly correct/incorrect use, Easy/Medium.
- CP002 — SSC Advanced Contextual Usage: polysemy, collocation, register and subtle semantic fit, Medium/Hard.
- CP003 — Banking Prelims Word Usage: business/economy/social vocabulary in concise contexts, Medium/Hard.
- CP004 — Banking Mains Contextual Usage: denser editorial/financial usage, subtle collocation and sense distinctions, Hard.
- CP005 — deterministic composer + Question Studio.

## Core question forms
1. **Correct usage** — choose the sentence in which the target word is used correctly.
2. **Incorrect usage** — choose the sentence in which the target word is used incorrectly.
3. **Controlled mixed mode** — deterministic alternation between the two forms.

## Quality rules
- Four concise sentences per authority.
- Exactly one keyed sentence.
- Wrong usages must be plausible semantic/collocational errors, not nonsense.
- Avoid testing obscure dictionary senses unless the context clearly supports them.
- Explanation should state the intended meaning/collocation and why the keyed sentence fits or fails.
- Original authored examples only.
- Review-only until human approval.
