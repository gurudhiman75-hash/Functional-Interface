- Two exam modes: correctly-spelt-word and misspelt-word identification.

## Source policy
Cambridge English Grammar identifies doubled letters and vowel clusters as common sources of English spelling errors and documents common learner spelling mistakes. ENG-007 uses those principles for trap design while keeping its lexical inventory local and reviewable.

## Quality rules
No accepted British/American variant is used as an error choice. Misspellings must remain unambiguous, plausible and distinct from every canonical spelling in ENG-007 CP001-CP004.
