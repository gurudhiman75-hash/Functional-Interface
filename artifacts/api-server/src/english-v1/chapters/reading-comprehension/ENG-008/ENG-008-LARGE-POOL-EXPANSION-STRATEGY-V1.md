# ENG-008 — Large-Pool Expansion Strategy V1

Status: `ACTIVE__REVIEW_ONLY`

## Principle

Reading Comprehension benefits directly from passage volume because each genuinely different passage creates a new:
- context;
- evidence structure;
- inference path;
- vocabulary environment;
- tone/purpose signal;
- distractor space.

Therefore ENG-008 should not stop at a small fixed passage count.

The constraint is **novelty**, not an arbitrary ceiling.

## Novelty gate

A new passage should be rejected or rewritten when it is merely:
- the same scenario with different names;
- the same intervention with a different institution;
- the same causal structure with cosmetic wording changes;
- a paraphrase of an existing Examtree passage;
- too close in setup or wording to a public source.

Each passage batch should intentionally vary:
- domain/topic;
- actors and setting;
- problem structure;
- evidence pattern;
- number/type of competing explanations;
- conclusion strength;
- tone;
- temporal structure;
- question-family evidence locations.
