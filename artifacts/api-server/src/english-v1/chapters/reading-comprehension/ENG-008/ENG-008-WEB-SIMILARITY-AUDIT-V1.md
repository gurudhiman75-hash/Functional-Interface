# ENG-008 — Web Similarity / Provenance Audit V1

Status: `NO_COPYING_SIGNAL_FOUND__SAMPLED_WEB_CHECK`

Date: 2026-09-26

## Purpose

Sanity-check whether approved ENG-008 Reading Comprehension passages appear to reproduce public-web text despite the source-audit declarations that the passages are original Examtree-authored material.

This is a sampled web-similarity check, not a legal plagiarism certification and not an exhaustive crawl of every indexed or unindexed source.

## Method

Exact-phrase web searches were run against distinctive long sentence fragments sampled across:
- CP001 SSC Foundation RC;
- CP002 SSC Editorial / Current-Affairs RC;
- CP003 Banking Prelims RC;
- CP004 Banking Mains Analytical RC;
- CP005 Research / Survey / Report RC.

The sample prioritised phrases unlikely to occur naturally by coincidence:
- distinctive narrative conclusions;
- multi-clause analytical claims;
- study/evaluation conclusions;
- unusual cause/effect formulations;
- passage-specific wording rather than generic titles.

## Result

No sampled distinctive long sentence produced evidence of a matching source passage from newspapers, books, coaching material or previous-year papers.

The search did surface one generic phrase collision around:

`treating everyone identically is not always the same as treating everyone fairly`

Similar formulations appear independently on public pages discussing equity/fairness. The surrounding ENG-008 passage wording did not match those pages, so this is treated as a common-expression collision rather than evidence of copied passage content.

## Interpretation

Current evidence supports the existing provenance records:
- ENG-008 passages are original/synthetic Examtree-authored text;
- exam papers/paper analyses inform profile, length, topic mix, question families and difficulty behaviour;
- learner-facing passage wording is not intentionally reproduced from those sources.

## Limits

This audit cannot prove absence of every possible match because:
- web search indexes are incomplete;
- some books/PDFs/paywalled/coaching materials may not be indexed;
- paraphrased similarity is harder to detect than verbatim similarity;
- common phrases may naturally appear in unrelated sources.

## Expansion rule

Future ENG-008 expansion must preserve:
1. original passage wording;
2. no copied PYQ/newspaper/coaching passage text;
3. exam-pattern inspiration only;
4. source-audit declaration per expansion batch;
5. periodic sampled web-similarity checks using distinctive long fragments.
