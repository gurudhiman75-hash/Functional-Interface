## Boundary

ENG-003 CP013 implements **Common Usage / Idiomatic Grammar Fillers** by reusing the closed ENG-001 CP013 donor catalog and the human-approved ENG-002 CP013 sentence-improvement layer.

Reused rules: `GR-USG-001..009`.

Coverage includes:

- prefer X to Y
- senior/junior to
- different from (the exam convention used by this checkpoint)
- capable of
- insist on
- prevent + object + from + -ing
- despite / in spite of
- no sooner ... than
- hardly/scarcely ... when

No usage rule is re-authored in ENG-003.

## Filler transformation

Each question is converted into one focused blank. The verified ENG-002 correction is the answer and three safe alternatives come from the same approved donor scene. `No improvement` is removed.

Shared words are moved back into the sentence where safe so options stay short and exam-like.

## Explanation style

CP013 follows the simplified style approved in CP011:

**answer → simple rule → why it fits → corrected sentence**

Unnecessary textbook wording is avoided.

## Ambiguity guards

The checkpoint preserves ENG-002's important usage safeguards:

- `different to` and `different than` are not used as error distractors for `GR-USG-003`;
- the `prevent` rule is tested through the explicit `prevent + object + from + -ing` pattern;
- `despite` and `in spite of` are kept distinct from clause-linking rules such as `although`.
