# Difficulty Framework

## Easy

- Small given numbers.
- Small powers with familiar bases.
- Products with two small factors.
- Small digit counts for CP-004.
- Missing exponent cases with small answers.

## Medium

- Larger numbers and powers.
- Product expressions with two or three factors.
- Bases requiring logarithm use.
- Medium digit counts for boundary-number questions.

## Hard

- Large powers.
- Products with several factors.
- Digit counts requiring careful floor handling.
- Missing exponent questions where boundary cases are close.

## Difficulty Drivers

- Size of number.
- Base size.
- Exponent size.
- Number of product factors.
- Whether the answer is a direct count, a boundary number, or a missing exponent.
