# NS-FRACDEC-001

## Archetype

**ID:** NS-FRACDEC-001  
**Name:** Fractions, Decimals And Rational Numbers  
**Topic:** Number System  
**Subtopic:** Fractions, Decimals And Rational Numbers  
**Phase:** Phase A Architecture Discovery  
**Status:** Architecture only

## Educational Boundary

NS-FRACDEC-001 owns:

- Fraction simplification.
- Fraction and mixed-fraction arithmetic.
- Fraction comparison.
- Decimal arithmetic.
- Fraction to decimal conversion.
- Decimal to fraction conversion.
- Recurring decimal to fraction conversion.
- Terminating vs recurring decimal determination.
- HCF and LCM of fractions.

NS-FRACDEC-001 does not own:

- Percentage conversion as a final answer.
- Ratio and proportion applications.
- Profit/loss, interest or arithmetic word problems.
- HCF and LCM of integers as final answers.
- Prime factorization as final answer.
- Number of digits.
- Last digit or cyclicity.
- General algebraic simplification.
- rational vs irrational classification.
- natural number classification.
- whole number classification.
- integer classification.
- real number classification.

Classification ownership belongs to future NS-CLASS-001.

## Exam Relevance

This archetype covers recurring SSC, Banking, Railway, CDS, NDA, CAPF, Punjab and State PCS number-system topologies involving rational values, fractions and decimals.

The architecture is topology-first. It does not copy school-chapter subdivisions. Variants are retained only when they produce distinct educational tasks or outputs.

## Runtime Gate

No runtime files, generators, solvers, validators, reasoning graphs, pipelines, tests, audits or JSON libraries are authorized in Phase A.
