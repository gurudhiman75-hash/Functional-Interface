## Scope

Discover the minimum recurring exam topologies needed for surds and rationalization across SSC, Banking, Railway, CDS, NDA, CAPF, and State PCS style quantitative aptitude.

### Included
- Square-root and cube-root simplification (extracting perfect powers).
- Addition and subtraction of like surds.
- Multiplication and division of compatible surds.
- Mixed arithmetic expressions involving radicals.
- Comparison of surd values (by squaring/cubing or normalization).
- Ordering surds in ascending or descending order.
- Rationalizing monomial denominators (single-term radicals).
- Rationalizing binomial denominators (using conjugates).
- Evaluating expressions using algebraic identities (e.g., $(a+b)^2$, $(a+b)(a-b)$) with surds.

### Excluded
- Complex nested radicals beyond simple identity forms.
- Decimal representation and approximation-only questions.
- Irrationality proofs.
- Advanced surd equations involving multiple variables.
- Surd inequalities.
- Trigonometric radical values.

## Core Concepts

### Perfect Power Extraction
The process of factoring a radicand to find perfect squares or cubes that can be "pulled out" of the radical sign.

### Like Surds
Surds that have the same root index and the same radicand after simplification. Only like surds can be added or subtracted as coefficients.

### Conjugate
For a binomial $a + \sqrt{b}$, the conjugate is $a - \sqrt{b}$. Multiplying by the conjugate is the primary method for rationalizing binomial denominators.

### Normalization
Converting different surds to a form where they can be compared, either by bringing coefficients inside the radical or by equalizing root indices.
