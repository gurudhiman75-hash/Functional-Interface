# NS-SURD-001 Reasoning Patterns

## Pattern 1: Prime Factorization for Extraction
To simplify $\sqrt{n}$, factor $n$ into its prime factors. Group identical factors in pairs (for square roots) or triplets (for cube roots). Each group contributes one factor outside the radical.
- **Example:** $\sqrt{72} = \sqrt{2 \times 2 \times 2 \times 3 \times 3} = (2 \times 3)\sqrt{2} = 6\sqrt{2}$.

## Pattern 2: Conjugate Multiplication
To rationalize a denominator like $a + \sqrt{b}$, multiply both the numerator and denominator by the conjugate $a - \sqrt{b}$. This utilizes the identity $(x+y)(x-y) = x^2 - y^2$ to eliminate the radical in the denominator.
- **Common Mistake:** Forgetting to multiply the numerator, or using the wrong sign for the conjugate.

## Pattern 3: Common Surd Collection
Treat like surds as algebraic variables (e.g., treat $\sqrt{2}$ like $x$). Only combine terms that have the exact same radical part.
- **Example:** $3\sqrt{5} + 2\sqrt{5} = (3+2)\sqrt{5} = 5\sqrt{5}$.
- **Common Mistake:** Attempting to add radicands directly (e.g., $\sqrt{2} + \sqrt{3} = \sqrt{5}$ is incorrect).

## Pattern 4: Identity Expansion
Recognize surd expressions that fit the form of standard algebraic identities.
- **Pattern:** $(a+b)^2 = a^2 + 2ab + b^2$ where $a$ or $b$ are radicals.
- **Example:** $(\sqrt{3} + \sqrt{2})^2 = (\sqrt{3})^2 + 2(\sqrt{3})(\sqrt{2}) + (\sqrt{2})^2 = 3 + 2\sqrt{6} + 2 = 5 + 2\sqrt{6}$.

## Pattern 5: Normalization for Comparison
To compare $2\sqrt{3}$ and $3\sqrt{2}$, bring the coefficients inside the radical:
- $2\sqrt{3} = \sqrt{2^2 \times 3} = \sqrt{12}$
- $3\sqrt{2} = \sqrt{3^2 \times 2} = \sqrt{18}$
- Since $18 > 12$, then $3\sqrt{2} > 2\sqrt{3}$.
- Alternatively, square both sides: $(2\sqrt{3})^2 = 4 \times 3 = 12$ and $(3\sqrt{2})^2 = 9 \times 2 = 18$.
