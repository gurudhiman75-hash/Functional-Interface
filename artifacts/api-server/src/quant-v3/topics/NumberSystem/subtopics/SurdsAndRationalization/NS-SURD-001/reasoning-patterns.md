# NS-SURD-001 Reasoning Patterns

## Pattern 1: Extract The Perfect-Power Part

Used by:

- CP01
- CP02
- CP04

Recognition trigger:
The number inside the radical has a perfect square or perfect cube factor.

Reasoning:
Split the radicand into the extractable perfect-power part and the leftover part. Take the root of the extractable part and keep the leftover inside the radical.

Common mistake:
Students remove a factor that is not a perfect square or cube for the given root.

## Pattern 2: Combine Only Like Surds

Used by:

- CP02
- CP04

Recognition trigger:
The expression has addition or subtraction between radical terms.

Reasoning:
First simplify each radical. Then combine only terms with the same radical part. The coefficients can be added or subtracted, but unlike radical parts stay separate.

Common mistake:
Students add unlike surds as if \(\sqrt{a}+\sqrt{b}=\sqrt{a+b}\).

## Pattern 3: Multiply Or Divide Inside The Radical First

Used by:

- CP03
- CP04

Recognition trigger:
The expression contains multiplication or division between compatible radical terms.

Reasoning:
For compatible radicals, multiply or divide the radicands first. Then simplify the result by extracting perfect-power factors.

Common mistake:
Students simplify each radical separately even when combining first would be shorter.

## Pattern 4: Normalize Before Comparing

Used by:

- CP05

Recognition trigger:
The question asks for greater, smaller, increasing order, decreasing order, or equality.

Reasoning:
Simplify expressions first. If radical parts match, compare coefficients. If radical parts differ and expressions are positive, square or cube both sides to compare rational values.

Common mistake:
Students compare only the number inside the radical and ignore the coefficient.

## Pattern 5: Remove A Single Radical Denominator

Used by:

- CP06

Recognition trigger:
The denominator is one radical term.

Reasoning:
Multiply numerator and denominator by the radical factor needed to make the denominator rational. For square roots, this often means multiplying by the same radical. For cube roots, multiply by the missing factors needed to complete a cube.

Common mistake:
Students multiply only the denominator and forget to multiply the numerator.

## Pattern 6: Use The Conjugate For A Two-Term Denominator

Used by:

- CP07

Recognition trigger:
The denominator has two terms and at least one term contains a surd.

Reasoning:
Change the sign between the two denominator terms to form the conjugate. Multiplying by the conjugate turns the denominator into a difference of squares, removing the radical from the denominator.

Common mistake:
Students multiply by the same binomial instead of the conjugate.

## Pattern 7: Sequence Operations Before Arithmetic

Used by:

- CP04

Recognition trigger:
The expression contains several operations: extraction, product, quotient, addition, or subtraction.

Reasoning:
Simplify radical operations first, then collect like surds. Avoid calculating large decimal values.

Common mistake:
Students approximate early and lose the exact surd form.

## Pattern 8: Recognize Identity Before Expanding

Used by:

- CP08

Recognition trigger:
The expression resembles a standard algebraic identity.

Reasoning:
Identify the identity first. Apply it directly, simplify surd terms, combine rational terms, and then write the final answer.

Common mistake:
Students expand incorrectly or miss the middle term in \((a+b)^2\) and \((a-b)^2\).
