# NS-DIV-001 Difficulty Specification

## Purpose

Define how future NS-DIV-001 problems must be classified by difficulty after source review.

This document does not assign difficulty to any concrete problem.

## Difficulty Ownership

Difficulty classification for this archetype must be owned by NS-DIV-001 and must use reviewer-approved criteria.

## Difficulty Constraints

- Difficulty must not be assigned from a global Quant difficulty rule.
- Difficulty must not be assigned without canonical problem ownership.
- Difficulty must not be assigned without source evidence.
- Difficulty must not be assigned from unreviewed assumptions about student behavior.
- Difficulty must preserve the approved answer format and realism rules.
