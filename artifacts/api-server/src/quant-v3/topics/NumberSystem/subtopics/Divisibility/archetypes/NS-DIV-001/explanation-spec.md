# NS-DIV-001 Explanation Specification

## Purpose

Define the ownership and review requirements for future explanations attached to NS-DIV-001.

This document does not contain explanations, solution steps, teaching content, shortcuts, or worked problem content.

## Explanation Ownership

All future explanations for this archetype must be owned by NS-DIV-001 and must trace back to reviewed canonical problems.

No explanation may exist for this archetype unless the parent canonical problem and reasoning pattern references are approved.

## Explanation Inputs

| Input | Requirement |
| --- | --- |
| Archetype ID | Must be NS-DIV-001 |
| Canonical Problem ID | Required |
| Reasoning Pattern Reference | PENDING HUMAN REVIEW |
| Source Reference IDs | Required |
| Solver Trace Contract | PENDING HUMAN REVIEW |
| Explanation Style Profile | PENDING HUMAN REVIEW |
| Language Target | Required for localized explanations |

## Explanation Output Contract

| Output | Requirement |
| --- | --- |
| Explanation body | Must be produced only after implementation approval |
| Step metadata | Must be owned by canonical problem |
| Verification metadata | PENDING HUMAN REVIEW |
| Shortcut metadata | PENDING HUMAN REVIEW |
| Source trace metadata | Must preserve reviewed source references |

## Explanation Constraints

- A future explanation must not exist outside NS-DIV-001 ownership.
- A future explanation must not teach an unreviewed reasoning pattern.
- A future explanation must not introduce unreviewed shortcuts.
- A future explanation must not introduce unreviewed validation logic.
- A future explanation must not use generic global teaching text.
- A future explanation must preserve source-backed canonical problem ownership.

## Forbidden Explanation Behavior

- Do not create explanation text in this specification.
- Do not create solution steps in this specification.
- Do not create shortcuts in this specification.
- Do not create verification text in this specification.
- Do not create multilingual explanation text in this specification.
