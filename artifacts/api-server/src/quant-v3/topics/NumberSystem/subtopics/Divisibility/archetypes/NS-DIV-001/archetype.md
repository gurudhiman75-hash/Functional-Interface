## Mission

Define the complete specification architecture that this archetype must own before implementation begins.

This package is a specification package only. It does not create generators, educational content, explanations, stems, distractors, validators, or localization content.

## Archetype Boundary

This archetype is limited to source-backed problems where one digit is missing and the required digit is determined by a divisibility condition.

The exact accepted source patterns, divisor families, notation styles, answer formats, and difficulty bands must be supplied by human review before implementation begins.
