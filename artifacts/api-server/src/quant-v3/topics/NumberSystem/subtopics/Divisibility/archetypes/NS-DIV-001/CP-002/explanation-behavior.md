# CP-002 Explanation Behavior

## Scope

This file specifies explanation behavior for CP-002 only.

It does not create explanation language, explanation templates, rendered explanations, or new explanation styles.

## Approved Existing Explanation Styles

| Explanation Style ID | Name | Status |
| --- | --- | --- |
| ES-001 | Teacher Style | Use existing style only |
| ES-002 | Short Exam Style | Use existing style only |
| ES-003 | Detailed Teaching Style | Use existing style only |

No additional explanation styles are approved for CP-002.

## Teacher Style Structure

| Required Element | Requirement | Review Status |
| --- | --- | --- |
| Concept | Explain the relevant divisibility concept using approved explanation language. | PENDING HUMAN REVIEW |
| Application | Apply the concept to the given number pattern using graph output. | PENDING HUMAN REVIEW |
| Candidate Results | Show the valid digit set or approved equivalent representation. | PENDING HUMAN REVIEW |
| Selection | Show that the largest valid digit is selected. | PENDING HUMAN REVIEW |
| Answer | Give the selected digit. | PENDING HUMAN REVIEW |

## Largest Digit Explanation Requirements

| Requirement | Status |
| --- | --- |
| Explanation must identify the largest valid digit as the selected answer | Required |
| Explanation must not imply that any valid digit is acceptable when the task asks for the largest valid digit | Required |
| Explanation must use graph output as the source of truth | Required |
| Explanation must not mention implementation details | Required |
| Review Status | PENDING HUMAN REVIEW |

## Valid Digit Set Explanation Requirements

| Requirement | Status |
| --- | --- |
| Explanation must be consistent with the valid digit set produced by the graph | Required |
| Explanation must not omit valid candidates when the valid digit set is shown | Required |
| Explanation must not include invalid candidates in the valid digit set | Required |
| Representation of full candidate evaluation remains subject to human review | PENDING HUMAN REVIEW |
| Review Status | PENDING HUMAN REVIEW |
