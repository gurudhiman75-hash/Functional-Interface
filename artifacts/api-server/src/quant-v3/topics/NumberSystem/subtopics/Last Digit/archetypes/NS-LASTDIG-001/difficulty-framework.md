# Difficulty Framework

## Easy

- Bases with cycle length 1 or 2.
- Small exponents.
- One or two power terms.
- Direct cycle lookup.
- Options in CP-005 are clearly separated.

## Medium

- Bases with cycle length 4.
- Medium exponents.
- Product of two or three powers.
- Tower expressions requiring one exponent reduction.
- CP-005 options include more plausible distractors.

## Hard

- Very large exponents.
- Mixed cycle families in products.
- Repeated exponential expressions where tower reduction is required.
- Options in CP-005 require full cycle-position checking.

## Difficulty Drivers

- Cycle length: 1, 2, or 4.
- Exponent size.
- Number of power terms.
- Whether effective exponent reduction is required.
- Whether the output is a digit, a cycle pattern, or a missing exponent.
