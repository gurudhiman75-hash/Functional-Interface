# Reasoning Patterns

## RP-001: Direct Cycle Lookup

Use the last digit of the base, identify the cycle, and select the correct cycle position from the exponent.

Used by: CP-001.

## RP-002: Product Of Last Digits

Find the last digit of each power separately, then multiply the resulting digits and keep only the last digit.

Used by: CP-002.

## RP-003: Tower Exponent Reduction

Reduce the repeated exponent to the effective position needed for the base cycle.

Used by: CP-003.

## RP-004: Cycle Pattern Recognition

List the repeating last-digit cycle of powers of the given base.

Used by: CP-004.

## RP-005: Reverse Cycle Position

Use the target last digit to identify valid exponent positions, then choose the matching option.

Used by: CP-005.
