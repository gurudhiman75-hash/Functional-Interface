# NS-EXP-001 Reasoning Patterns

## Pattern 1: Same Base Means Exponents Carry The Work

Used by:

- CP01
- CP02

Recognition trigger:
The base is already identical across the expression or equation.

Reasoning:
The base is not the main calculation. The student should work on the exponents. Multiplication adds exponents, division subtracts exponents, and equality of same-base powers lets us compare exponents.

Common mistake:
Students multiply powers by multiplying exponents in every case. That is correct only for power-of-power, not for product of same-base powers.

## Pattern 2: Change The Base Before Doing Anything Else

Used by:

- CP03
- CP07

Recognition trigger:
Visible bases differ, but each can be written as a power of a smaller common base.

Reasoning:
The question becomes simple only after rewriting the bases. For example, \(8\) should be read as \(2^3\), and \(16\) as \(2^4\). After that, the expression may be simplified, compared, or solved by equating exponent expressions.

Common mistake:
Students compare visible bases directly and ignore the exponent effect.

## Pattern 3: Negative Exponent Means Reciprocal, Not Negative Value

Used by:

- CP04
- CP06

Recognition trigger:
An exponent has a minus sign.

Reasoning:
\(a^{-n}\) means the reciprocal of \(a^n\). The value is not negative merely because the exponent is negative.

Common mistake:
Students write \(2^{-3}=-8\). The correct value is \(\frac{1}{8}\).

## Pattern 4: Fractional Exponent Means Root And Power

Used by:

- CP05
- CP06

Recognition trigger:
An exponent is written as \(\frac{m}{n}\), or the expression contains roots that can be written as fractional exponents.

Reasoning:
The denominator tells the root. The numerator tells the power. For clean exam values, taking the root first usually keeps numbers smaller.

Common mistake:
Students divide the base by the denominator of the exponent. For example, \(16^{1/2}\) is not \(8\); it is \(4\).

## Pattern 5: Sequence The Laws In The Least Messy Order

Used by:

- CP06

Recognition trigger:
The expression has more than one exponent feature: different bases, negative exponent, fractional exponent, quotient, or nested power.

Reasoning:
First rewrite bases or roots into simpler powers. Then normalize negative exponents. Finally combine same-base powers.

Common mistake:
Students start calculating large powers numerically too early.

## Pattern 6: Compare Only After Making Expressions Comparable

Used by:

- CP07

Recognition trigger:
The question asks which expression is greater, smaller, equal, or ordered.

Reasoning:
Either make the bases the same and compare exponents, or make the exponents the same and compare bases. Without that, direct comparison is unreliable.

Common mistake:
Students assume the expression with the larger base is always larger.

## Pattern 7: Given Power Relation As Anchor

Used by:

- CP09

Recognition trigger:
The question gives \(a^x\) and asks for a related expression such as \(a^{x+k}\), \(a^{x-k}\), or \(a^{mx}\).

Reasoning:
Do not solve for \(x\) unless necessary. Rewrite the asked expression using the given power as a block.

Common mistake:
Students spend time finding \(x\) even when the asked expression can be evaluated directly.
