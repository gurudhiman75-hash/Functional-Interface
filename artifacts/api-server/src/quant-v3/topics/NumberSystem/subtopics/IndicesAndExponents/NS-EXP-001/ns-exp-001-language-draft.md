## Explanation Candidates

### ES-001

First check whether the base is the same in every term. If the base is the same, the calculation should be done on the exponents. For multiplication, add the exponents. For division, subtract the exponents. For a power raised to another power, multiply the exponents. After reducing the exponent, write the final power or calculate the value if it is small.

### ES-002

When both sides have the same base, the exponents must be equal. So ignore the common base for a moment and write an equation using only the exponents. Solve that simple equation, then check that the exponent found gives the same power on both sides.

### ES-003

When the visible bases are different, first check whether they can be written using one smaller base. After changing every term to the same base, use the normal exponent laws. The same method works for simplification, comparison, and exponent equations.

### ES-004

A negative exponent does not make the answer negative. It means reciprocal. First move the term to its reciprocal form or combine the exponents carefully. After that, write the answer with a positive exponent wherever possible.

### ES-005

A fractional exponent connects powers and roots. The denominator of the exponent shows the root, and the numerator shows the power. In most exam questions, take the root first because it keeps the numbers small. Then raise the result to the numerator power.

### ES-006

In a mixed expression, do not start by calculating large powers. First rewrite composite bases into a common base. Next handle negative or fractional exponents. Then combine same-base powers. This order keeps the expression short and avoids unnecessary arithmetic.

### ES-007

For comparison, make the expressions comparable first. If the bases can be made the same, compare the exponents. If the exponents become the same, compare the bases. Do not decide only from the visible base, because a smaller base with a larger exponent may be greater.

### ES-008

When a value such as \(a^x\) is already given, use it as a ready block. For \(a^{x+k}\), multiply the given value by \(a^k\). For \(a^{x-k}\), divide the given value by \(a^k\). For \(a^{mx}\), raise the given value to the power \(m\). This is faster than finding \(x\) every time.
