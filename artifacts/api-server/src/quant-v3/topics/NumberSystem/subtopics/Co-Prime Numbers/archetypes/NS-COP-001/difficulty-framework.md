# NS-COP-001 Difficulty Framework

## Difficulty Drivers

Difficulty is controlled by:

- number size
- whether numbers are prime or composite
- amount of common-factor overlap
- list length
- set size
- number of candidate distractors
- whether a ratio is already reduced or reducible
- whether the reasoning uses a direct property or repeated HCF checks

## Easy

Features:

- small numbers
- obvious HCF 1 or obvious common factor
- short lists
- small sets
- already-reduced ratios
- direct consecutive-number property

Expected learner work:

- identify HCF 1
- reject numbers with an obvious common factor
- divide a ratio once if needed

## Medium

Features:

- medium composite numbers
- multiple list values
- several candidate distractors
- medium sets with several pairs
- ratios reducible by a non-obvious HCF

Expected learner work:

- perform several HCF checks
- track counts accurately
- reduce ratios using HCF

## Hard

Features:

- larger composite numbers
- longer lists
- larger sets
- distractors with partial factor overlap
- ratios reducible by multiple common factors

Expected learner work:

- organize repeated pair checks
- avoid confusing prime with co-prime
- verify final reduced ratio terms are co-prime

## CP-Specific Notes

CP-001:

- Easy: prime and prime, or obvious common factor.
- Medium: prime and composite.
- Hard: composite and composite with less obvious HCF.

CP-002:

- Easy: shortList.
- Medium: mediumList.
- Hard: longList.

CP-003:

- Easy: one clear valid candidate.
- Medium: multiple distractors.
- Hard: distractors with partial factor overlap.

CP-004:

- Easy: smallSet.
- Medium: mediumSet.
- Hard: largeSet.

CP-005:

- Easy: directConsecutiveRule.
- Medium: hcfVerification.

CP-006:

- Easy: alreadyReduced.
- Medium: reducibleOnce.
- Hard: reducibleMultipleFactors.
