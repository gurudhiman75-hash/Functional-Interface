# PCT-001 Reasoning Patterns

## Pattern 1: Convert Percent To Part Of A Whole

Used by:

- CP01
- CP05

Recognition trigger:
The question gives a percent and a base quantity.

Reasoning:
Treat the percent as a fraction out of \(100\), then multiply by the base quantity.

Common mistake:
Students divide by the percentage instead of multiplying by it.

## Pattern 2: Convert Part-Whole Relation To Percent

Used by:

- CP02

Recognition trigger:
The question asks what percent one quantity is of another.

Reasoning:
Place the part quantity over the reference quantity and multiply by \(100\).

Common mistake:
Students reverse the numerator and denominator.

## Pattern 3: Convert Representation To Percent

Used by:

- CP03

Recognition trigger:
A fraction or decimal is given and percent form is asked.

Reasoning:
Multiply the fraction or decimal by \(100\), then attach the percent sign.

Common mistake:
Students attach the percent sign without multiplying by \(100\).

## Pattern 4: Compute Before Comparing

Used by:

- CP04

Recognition trigger:
The question asks greater, smaller, greatest, least, increasing order, or decreasing order.

Reasoning:
Find each percentage value first, then compare the resulting values.

Common mistake:
Students compare only the percentage numbers and ignore the base quantities.

## Pattern 5: Add Or Subtract One Percentage Change

Used by:

- CP05

Recognition trigger:
The question says increase, decrease, raise, reduce, or lower by a percentage.

Reasoning:
First find the percentage change amount. Add it to the base for increase, and subtract it from the base for decrease.

Common mistake:
Students subtract in an increase question or add in a decrease question.
