# PCT-001 Architecture Discovery

## Identity

- Topic: Percentage
- Subtopic: Percentage Fundamentals
- Package: PCT-001
- Phase: Architecture discovery plus human language draft
- Status: documentation-only

## Educational Scope

PCT-001 owns fundamental percentage operations only:

- percentage of a quantity
- one quantity as a percentage of another
- fraction to percentage conversion
- decimal to percentage conversion
- percentage comparison
- finding percentage value
- direct single-step percentage increase or decrease

PCT-001 does not own:

- successive percentage change
- reverse percentage
- population growth
- expenditure or income
- votes
- marks
- replacement or transfer
- percentage more than or less than

## Discovery Principle

Canonical problems are selected by repeated exam solving pattern. Variants are merged unless the solver, validator, or answer type changes.

## Active Canonical Problem List

| CP ID | Topology Name | Coverage Role |
|---|---|---|
| PCT-001-CP01 | Find a percentage of a quantity | Direct percentage value calculation |
| PCT-001-CP02 | Express one quantity as a percentage of another | Ratio-to-percentage comparison |
| PCT-001-CP03 | Convert fraction or decimal to percentage | Basic representation conversion |
| PCT-001-CP04 | Compare percentage values | Identify greater, smaller, or order after finding values |
| PCT-001-CP05 | Direct percentage increase or decrease | Single-step increase or decrease from a base value |

## Topology Count

Active topology count: 5

## Merge Decisions

Fraction-to-percentage and decimal-to-percentage are merged into CP03 because the answer type is the same and both require conversion into percent form.

Percentage increase and percentage decrease are merged into CP05 because both use one base value and one direct percentage change. The sign changes, but the solving and validation pattern remains the same.

Percentage comparison remains separate as CP04 because the student must first compute or normalize more than one percentage value and then compare them.

## Non-Goals

This package does not cover multi-step applications, reverse calculations, compound percentage change, or contextual applied chapters. Those must be handled by later Percentage packages.
