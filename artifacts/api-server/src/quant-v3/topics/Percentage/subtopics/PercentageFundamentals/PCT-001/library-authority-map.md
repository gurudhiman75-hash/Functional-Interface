## Coverage Categories To CP

- CP01: common percentages, fractional percentages, percentages above 100
- CP02: direct percent relation, non-100 reference values
- CP03: fraction conversions, decimal conversions, values greater than 1
- CP04: greater value, smaller value, greatest selection, least selection, increasing order, decreasing order
- CP05: increase, decrease, final value, change amount

## Variable Ranges To CP

- CP01: percentage values, base quantities, fractional percentages, percentages above 100%
- CP02: part quantity, reference quantity, clean and non-clean ratios
- CP03: fraction denominators, decimal precision, values above 1, terminating decimals
- CP04: number of values to compare, ordering direction, percentage complexity, base quantity differences
- CP05: increase/decrease direction, percentage values, base quantities, final value vs change amount
