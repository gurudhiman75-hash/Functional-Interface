## Explanation Candidates

### ES-001

To find a percentage of a quantity, change the percentage into a part out of \(100\) and multiply it by the given quantity. The result is the required value.

### ES-002

When one quantity is asked as a percentage of another, keep the asked quantity in the numerator and the reference quantity in the denominator. Multiply by \(100\) to convert it into percent.

### ES-003

To convert a fraction or decimal into a percentage, multiply it by \(100\). After simplifying, write the percent sign with the answer.

### ES-004

When percentage values are compared, first calculate each value separately. Then compare the actual values, not only the percentage numbers.

### ES-005

For a direct percentage change, first find the percentage amount. Add it to the original value for an increase, and subtract it from the original value for a decrease.
