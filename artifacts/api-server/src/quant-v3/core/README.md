# Quant V3 Phase 0

Quant V3 starts as an isolated architecture package. Phase 0 creates only the filesystem and registry contracts needed for future archetype mining.

This phase intentionally contains no archetypes, question generators, stem libraries, explanation libraries, shortcut libraries, distractor libraries, scenario libraries, validators, localization content, or educational assumptions.

Every future archetype must own its own student-facing and validation modules by default. Global educational fallback engines are not part of the Quant V3 architecture.
