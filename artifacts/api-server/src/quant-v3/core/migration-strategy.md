# Quant V3 Migration Strategy

Quant V2 remains untouched and operational. Quant V3 begins as a separate architecture package.

Future migration should happen one archetype at a time:

1. Map a V2 topic to a V3 topic and subtopic without copying V2 educational templates.
2. Mine archetypes from real question behavior, not from V2 family names.
3. Create exactly one archetype folder under one subtopic.
4. Move only archetype-owned content into that archetype.
5. Add validation proving no global educational fallback was used.
6. Register the archetype only after its owned modules are complete.

V2 family IDs may be retained as historical migration notes later. They must not automatically become V3 archetype names.
