# CP-035 Generic Multilingual Recovery

CP-035 extends deterministic Hindi/Punjabi localization to the source-independent generic English authoring templates introduced by CP-030:

- `verified_official_action_v1`
- `verified_award_result_v1`
- `verified_initiative_v1`
- `generic_verified_fact_graph_v1`

Canonical fact values remain verbatim inside localized copy, target-script and shared translation-quality checks still apply, and unsupported/manual authoring continues to require editorial review.

Only generic-template localization fingerprints are policy-versioned. Existing CP-010 template fingerprints remain stable, avoiding unnecessary rewrites of prior accepted localizations. Once an event localization becomes ready, existing CP-011 question-localization fingerprints naturally change because they include the localized event title; BANK_ONLY questions can therefore be re-evaluated without lowering question editorial gates.

This checkpoint grants no release, Question Bank promotion, notification, personalization, or learner-publication authority.
