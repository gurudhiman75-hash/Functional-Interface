# LP-009 — English Editorial Approval V2

Status: **APPROVED for the English review surface on 2026-09-09.**

This approval records the accepted learner-facing standard for `LP-CP-009` month-based and year-based scheduling questions after review of the regenerated explanation pack.

## Approved explanation contract

Every LP-009 explanation must:

1. begin with the direct entries that can be placed immediately;
2. apply the remaining clues one by one rather than jumping to the solved table;
3. state what each clue actually means for the named people/entities;
4. show the current candidate table after each meaningful deduction;
5. record newly forced placements as soon as they become fixed;
6. finish with the unique completed schedule;
7. answer the child question from the exact relevant row(s) of that schedule.

The explanation must not use generic filler such as "use all the clues", "apply the clues", or a bare final table with no deduction path.

The current runtime already uses direct-entry, clue-by-clue narrowing and progressive tables. This approval makes that behavior an editorial requirement for LP-009 rather than an incidental presentation choice.

## Approved learner-facing style

- simple, exam-like English;
- no unnecessary shortcut/trap sections;
- no machine-facing terms or internal IDs in the explanation;
- no local city/centre objects;
- month order is the displayed calendar order;
- year questions use ordered birth years and do not require age arithmetic;
- explanations may be longer for Medium/Hard questions when the deduction chain genuinely requires it.
