## Purpose

Wave 03 normalizes multiple 2024–2025 Banking memory/recall analyses into de-duplicated caselet-family signatures. The goal is not to count every platform headline as a distinct puzzle type. The goal is to ask whether repeated real-exam recall evidence exposes a hidden-state/query contract not already owned by Logic Puzzles or an adjacent reasoning chapter.

This is still Class C evidence. IBPS explicitly does not publish historical question papers/right answer keys, so these recalls are never re-labelled as official papers.

Permanent registry remains `LP-QL-001..047`; `LP-QL-048` remains unallocated.

## De-duplication rule

A recalled set is considered the same structural family when changing names, dates, colours, professions, cities or surface story does not change:

- hidden-state dimensions;
- cardinality/capacity constraints;
- ordering/adjacency semantics;
- query contract;
- or required solution-state representation.

Different exam shifts are still retained as independent observations for recurrence, but not as new semantic families.

## Recurrence conclusion

Across independent years and platforms, the dominant Banking recall pattern is not continual invention of new puzzle semantics. It is repeated recombination of a stable set of state structures with new surface variables.

For Logic Puzzles, the recurring source-backed structures converge on:

1. box/stack ordering;
2. box + attribute;
3. date/month/day scheduling;
4. variable/preference assignment;
5. multi-attribute matching/selection;
6. conditional child queries over those states.

All six are already represented by permanent LP authorities through `LP-QL-047`.

## Important boundary finding

A large share of Banking 'puzzle' frequency belongs to adjacent chapters:

- Seating Arrangement: linear, parallel-row, circular, square, uncertain/certain-number seating;
- Floor/Flat Arrangement: floor and floor+flat sets;
- Ranking/Order: comparison and pure age/year ordering.

Counting those as Logic Puzzle gaps would create duplicate engines and distort chapter weighting.
