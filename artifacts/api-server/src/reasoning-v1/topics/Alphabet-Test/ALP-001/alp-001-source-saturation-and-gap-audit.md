# ALP-001 CP-001–CP-005 Source Saturation and Gap Audit

## Method

Candidate formats were classified by underlying object, requested inference, reference direction, boundary policy, inverse status and repeated-token risk. A new QL was allocated only when the student must perform a materially different inference rather than read another stem variant.

## Duplicate candidates removed

- left rank of the opposite of a letter, because it equals the original letter's right rank;
- right rank of the opposite, because it equals the original left rank;
- a second equidistant-letter QL duplicating the single-midpoint inference;
- multiple stem-only variants of the same transformed-position task;
- dictionary order, meaningful-word formation, hidden coding rules and next-letter series, which belong elsewhere.

## Coverage summary

CP-001 covers direct and inverse rank relationships. CP-002 covers bounded and cyclic movement, direct and inverse. CP-003 covers interval, midpoint, endpoint, comparison and count tasks. CP-004 covers fourteen explicit alphabet transformations with direct and inverse queries. CP-005 covers direct, inverse, reconstruction, stable sorting and occurrence-aware word tasks.

## Remaining scope

Alphabet-pair formation inside words, explicit letter-class transformations, mixed alpha-numeric-symbol scanning and mixed-sequence rearrangement remain for later checkpoints. Their counts and ranges must be discovered rather than reserved in advance.

## Conclusion

Within the declared CP-001–CP-005 boundary, the final 104-QL inventory covers the materially distinct direct, inverse, edge, reconstruction and repeated-letter modes found in the design audit, with no known duplicate QL remaining.
