## Two-set / three-set topology ownership

The source evidence does not justify separate permanent QLs merely because a question contains two versus three sets.

Set count and topology complexity are generated-instance dimensions.

Therefore:

- two-set containment / separation / overlap;
- three-set nesting / separation / mixed overlap;
- number of circles alone;

must not create separate QLs.

## Provisional learner-contract inventory

Source evidence currently supports three distinct learner-facing contracts for freeze-readiness review:

1. **CLASS_CATEGORIES_TO_DIAGRAM**
   - input: named categories/classes whose relation is known or explicitly governed by an approved factual authority;
   - output: matching diagram.

2. **DIAGRAM_TO_CLASS_CATEGORIES**
   - input: a diagram/topology;
   - output: the category set matching that relation.

3. **NUMBERED_REGION_MEMBERSHIP_IDENTIFICATION**
   - input: labeled/numbered Venn diagram plus a compound membership condition;
   - output: the numbered region.

These are provisional learner contracts only. No `VEN-QL-*` IDs are allocated by this census.
