## Editorial remediation completed

Deep-audit Waves 02–04 removed the main machine-authored learner-surface defects.

Removed:

- repetitive `A survey...` / `In a survey...` openers;
- Hindi/Punjabi equivalents;
- anonymous first/second/third-group references;
- first/second/third-activity references where the actual activities are known.

- `A = ...`;
- `B = ...`;
- `C = ...`;
- questions phrased only as the relationship among A/B/C.

The visible stem now states the real relationship or directly names the real categories.

### Region-identification questions

CP004 no longer begins with `Study the diagram` / equivalent instruction boilerplate and no longer uses equality notation for the label mapping.

A/B/C remain compact visible diagram labels, with the mapping written as a natural learner-facing sentence.
