## What is evidenced and what is not

- Category triples → diagram is observed across multiple attributed papers.
- Diagram → category triple is observed in the earlier 2023 paper reproduction recorded in `VEN-001-SOURCE-PATTERN-CENSUS-V1.md`.
- Numerical set names such as whole, rational, and real numbers appear in the attributed question. Their class relationships are also solver-checked in the candidate record.
- This supplemental search did **not** confirm a standalone two-class category-to-diagram question. Two-set topologies remain required solver/render primitives and subrelations inside three-class questions; a separate CP001 generation pattern stays pending evidence.
- Numerical inclusion-exclusion/counting questions remain outside this CP003 pool.
