## 1. COMPLETE_MISSING_CODED_OPERATOR — seed 0

**Record:** INE-CP007-EDC33F7F · **Difficulty:** HARD · **Delivery:** EXAM_PRACTICE_PROTOTYPE · **Applicability:** BANKING_REGULATORY_PRACTICE_ONLY

Which coded symbol should fill the blank so that the required strongest relation is obtained?

### Code key

- A % B means A is greater than B.
- A $ B means A is less than B.
- A @ B means A is equal to B.
- A & B means A is greater than or equal to B.
- A # B means A is less than or equal to B.

### Given

- P ___ Q @ R
- Required strongest relation: P > R

### Options

1. &
2. %
3. #
4. $

**Correct:** 2. %

### Explanation

Q = R, so replacing Q with R does not change the comparison. To obtain P > R, the blank must be % (>).

## 29. IDENTIFY_ONLY_CONSISTENT_CODE_MAP — seed 0

**Record:** INE-CP007-54273303 · **Difficulty:** MEDIUM · **Delivery:** GUIDED_DISCOVERY · **Applicability:** GUIDED_CONCEPT_ONLY

Which complete code map is consistent with every test result?

### Given

- 8 % 3 is true
- 5 % 5 is false
- 3 $ 8 is true
- 5 $ 5 is false
- 5 @ 5 is true
- 8 @ 3 is false
- 8 & 3 is true
- 5 & 5 is true
- 3 # 8 is true
- 5 # 5 is true

### Options

1. % = >, $ = <, @ = =, & = ≥, # = ≤
2. % = ≥, $ = <, @ = =, & = >, # = ≤
3. % = >, $ = ≤, @ = =, & = ≥, # = <
4. % = <, $ = >, @ = =, & = ≥, # = ≤

**Correct:** 1. % = >, $ = <, @ = =, & = ≥, # = ≤

### Explanation

Equal-value tests distinguish strict from inclusive signs. Checking all the results gives: % = >, $ = <, @ = =, & = ≥, # = ≤.
