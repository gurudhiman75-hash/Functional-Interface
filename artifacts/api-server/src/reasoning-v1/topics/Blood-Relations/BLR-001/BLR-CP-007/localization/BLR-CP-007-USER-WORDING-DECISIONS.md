# BLR-CP-007 Hindi/Punjabi wording decisions

User-reviewed wording corrections applied on 2026-08-08:

1. Target relation clauses use the finite forms `है` and `ਹੈ` instead of `हो` and `ਹੋਵੇ`.
2. The Punjabi code-key introduction uses the more natural exam wording:
   `ਦਿੱਤੇ ਗਏ ਸੰਕੇਤਾਂ ਦੇ ਅਰਥ ਇਹ ਹਨ:`
3. Surrounding question templates were adjusted so finite `है` / `ਹੈ` clauses remain grammatically natural, for example:
   - Hindi: `सही कूटित विकल्प चुनिए, जिससे यह सिद्ध होता है कि C, D की माता है।`
   - Punjabi: `ਸਹੀ ਕੋਡਿਤ ਵਿਕਲਪ ਚੁਣੋ, ਜਿਸ ਨਾਲ ਇਹ ਸਾਬਤ ਹੁੰਦਾ ਹੈ ਕਿ C, D ਦੀ ਮਾਤਾ ਹੈ।`

These are learner-facing wording changes only. English semantic authority, code expressions, option order, correct answers, graph structure and lifecycle locks remain unchanged.
