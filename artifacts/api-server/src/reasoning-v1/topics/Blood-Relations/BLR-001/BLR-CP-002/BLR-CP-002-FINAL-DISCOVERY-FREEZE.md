```text

-> role-chain reduction
```

- anchor count;
- endpoint direction;
- one or both derived endpoints;
- role depth;
- broad versus gendered role vocabulary;
- `ONLY_CHILD` and no-sibling constraints;
- blood versus affinal output;
- relation value;
- self-identity collapse;
- photograph/portrait ownership rendering;
- names, clue order and difficulty.
