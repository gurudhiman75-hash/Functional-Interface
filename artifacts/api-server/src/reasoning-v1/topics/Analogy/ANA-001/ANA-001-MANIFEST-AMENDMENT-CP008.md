The 28 QLs own solve and presentation contracts, not one QL per numeric parameter.

Runtime contexts remain bounded inside their parent template. The admitted inventory contains 81 proven contexts, including:

Every generated instance must use an independently verified context, complete visible evidence and collision rejection against equal-or-simpler ANA authorities.

## 6. Option and explanation contracts

A direct-completion question must provide:

- one complete source pair and one target input;
- four unique typed output options;
- exactly one correct answer;
- no distractor that creates another accepted mixed relation with the source pair;
- complete source and target calculations;
- one explicit misconception rejection.

An odd-pair question must provide:

- four complete mixed pairs;
- exactly three pairs following one complete relation;
- one pair violating that relation;
- demonstrations for all three valid pairs;
- the expected output for the odd input;
- one correct option index.

## 7. Locale policy

All mixed tokens remain in uppercase Latin letters and Arabic numerals in English, Hindi and Punjabi interfaces.

- English uses candidate-facing English instructions and calculations.
- Hindi uses natural Hindi instructions while preserving token, option and answer parity.
- Punjabi uses natural candidate-facing Punjabi and avoids textbook-style terms such as `ਪਦ` and `ਸਾਦ੍ਰਿਸ਼ਤਾ`.

## 8. Runtime-complete criteria

ANA-CP-008 may be marked runtime-complete only after:

- all 28 QLs are registered continuously from `ANA-QL-223` through `ANA-QL-250`;
- all 81 admitted contexts remain reachable;
- deterministic generation passes across the seed matrix;
- the independent solver agrees with every generated output;
- ambiguity and alternative-answer rejection pass;
- every option set contains four unique values and one correct answer;
- odd-pair sets contain exactly three valid pairs;
- answer positions are balanced across the audit matrix;
- Hindi and Punjabi preserve QL, context, option and answer parity;
- editorial guards reject internal, translated or avoidably technical wording;
- no Question Studio, Question Bank, mock-test or public routing is enabled before manual review.
