# ANA-CP-007 Saturation Decision

Status: **pre-freeze decision; permanent QL and solve-mode counts remain open until pilot CI passes**.

## 1. Native word-structure authorities

The current source, ownership and pilot audits retain seven CP-007-native authorities:

1. remove vowels while preserving consonant order;
2. remove consonants while preserving vowel order;
3. select odd- or even-position letters while preserving order;
4. calculate the complete A=1 through Z=26 word sum;
5. apply a bounded word-length profile;
6. compare or preserve the canonical repeated-letter equality pattern;
7. shift vowels and consonants by different fixed amounts.

These are authorities, not predetermined QLs. Presentation modes will be frozen only after pilot evidence confirms materially distinct inference contracts.

## 2. Delegated authorities

### ANA-CP-006

The following inherited word-labelled families are generic A-Z cluster transformations and remain owned by CP-006:

- transform only the first letter;
- transform only the last letter;
- exchange first and last letters;
- reverse the complete word;
- other generic permutations, insertion, deletion, sorting and positional transformations.

### Cross-domain / coding authority

A word mapped to the individual alphabet positions of all its letters, for example `LION → 12-9-15-14`, is a letter-to-number sequence code. It is therefore excluded from CP-007 and delegated to the later cross-domain/coding authority.

The CP-007 pilot retains only the **complete alphabet-position sum**, because that is explicitly owned by the audited CP-007 manifest and has a distinct scalar answer contract.

## 3. Source-backed addition

`WORD_VOWEL_CONSONANT_DIFFERENTIAL_SHIFT` remains required. The representative relation `JANUARY → IBMVBQX` increases vowels by one alphabet place and decreases consonants by one. It cannot be represented by one uniform shift or by vowel/consonant removal.

The pilot tests bounded shifts from `-4` through `+4`, excluding identity and equal-shift contexts. The final production domain may be narrowed after yield, collision, explanation and difficulty audits.
