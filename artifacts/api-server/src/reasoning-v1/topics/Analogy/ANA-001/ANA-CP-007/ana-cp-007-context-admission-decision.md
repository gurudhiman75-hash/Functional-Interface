# ANA-CP-007 Context Admission Decision

Status: **pre-freeze production-context decision**

The pilot intentionally tested a broader bounded context space than the eventual production runtime. Pilot yield proves technical viability; it does not by itself prove exam-pattern ownership.

## 1. Word-length authority

A source-backed example gives:

```text
REASON → 5
BELIEVED → 7
```

The common rule is:

```text
code = number of letters − 1
```

`REASON` has 6 letters and gives 5. `BELIEVED` has 8 letters and gives 7. The corresponding target `GOVERNMENT` has 10 letters and would give 9.

### Admitted production context

```text
LENGTH_MINUS_CONSTANT, constant = 1
```

### Pilot-only contexts, not admitted yet

- direct word length;
- double word length;
- square of word length;
- length plus a constant;
- length minus 2 or 3.

These remain useful for collision testing and distractor research, but they must not enter the production rule registry until recurring exam evidence is documented.

This distinction prevents `WORD_LENGTH_RULE` from becoming an arbitrary formula-fitting family.

## 2. Alphabet-position sum

The scalar rule `A=1,…,Z=26` followed by complete addition appears in both analogy-oriented manifests and Coding-Decoding books.

Production decision:

- the arithmetic implementation belongs to the shared alphabet foundation;
- CP-007 may own the analogy presentation `WORD : NUMBER :: WORD : ?`;
- Coding-Decoding may own encode/decode presentations using the same shared authority;
- neither checkpoint may duplicate the underlying calculation code;
- alphabet-position **sequence** output remains excluded from CP-007.

## 3. Position extraction

Admitted contexts:

```text
ODD positions, forward order
EVEN positions, forward order
```

They remain contexts of one authority because the student performs the same inference—select every alternate source position while preserving order.

Reverse-order variants remain excluded until recurring source evidence is established.

## 4. Differential vowel/consonant shifts

The source-backed family is established by a relation in which vowels move one place forward and consonants one place backward.

The pilot proves the general bounded class-aware engine over shifts `−4..+4`, excluding identity and equal class movements. Final runtime admission follows this policy:

- the QL owns the class-aware solve strategy, not one particular shift amount;
- shift amounts remain bounded contexts;
- both classes must be active in source and target;
- equal shifts are rejected because they collapse to a uniform CP-006 rule;
- contexts repeatedly producing CP-006 collisions or weak distractors are rejected at generation time;
- published review must include explicit wrap calculations where applicable.

The exact production shift domain may be narrowed after the first full generated-corpus audit without changing QL ownership.

## 5. Repeated-letter equality pattern

The authority uses canonical first-occurrence numbering, for example:

```text
LEVEL → 1-2-3-2-1
LETTER → 1-2-3-3-2-4
```

The full equality pattern is required. Merely sharing a repeated-letter count is not sufficient.
