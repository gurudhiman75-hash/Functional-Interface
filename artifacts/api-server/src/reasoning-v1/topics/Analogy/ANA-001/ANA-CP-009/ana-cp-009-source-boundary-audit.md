## 1. Purpose

ANA-CP-009 is not a catch-all for difficult mixed analogy questions. It owns only source-backed analogy contracts in which the answer cannot be obtained by applying one stable pair-local transformation already owned by ANA-CP-003 through ANA-CP-008.

A candidate belongs here only when visible evidence requires a transformation parameter that changes systematically across complete pairs, interpolation/extrapolation from complete pair relations, a coupled invariant spanning domains, a meta-rule selecting the pair-local rule, or another genuinely advanced source-backed relation that cannot be represented honestly by an earlier checkpoint.

This audit assigns **zero permanent CP-009 IDs**.

## 2. Confirmed ownership boundary

The framing


does not make a question CP-009 when the same fixed pair-local rule applies to every pair. Multiple complete pairs can simply provide more evidence.

Examples found in SSC mirrors that remain pair-local include:

- `RA140 : PX420 :: CX238 : AU714 :: NL94 : LI282` — fixed letter movement plus `×3`;

Such questions belong to their pair-transfer owner; the extra complete pair is presentation/evidence, not a new meta solve contract.
