# ANA-CP-008 Presentation-Contract Decision

Status: **NON-QL PRESENTATION PILOT — PERMANENT TASK MATRIX OPEN**

## 1. Direct completion

Typical form:

```text
SOURCE : TRANSFORMED_SOURCE :: TARGET : ?
```

Mixed-analogy definitions and official questions repeatedly use this format. The answer may be a number, letter, letter-number token, number-letter token, or cluster-number token.

Decision:

```text
Source-backed and admitted for permanent consideration.
```

The existing direct-option audit already proves four unique answers with one correct option for every provisional context.

## 2. Equivalent-pair selection

Typical form:

```text
Two complete reference pairs follow one relationship.
Select the option pair that follows the same relationship.
```

This is a standard analogy task across letter and number checkpoints. Current mixed-analogy descriptions also define the task as selecting a mixed pair from options that preserves the relationship.

Decision:

```text
Pilot admitted.
Permanent mixed-task ownership remains pending an exact official mixed-pair fixture.
```

The presentation pilot requires:

- two complete reference pairs that uniquely establish one rule/context;
- four complete pair options;
- exactly one option that preserves the complete mixed relationship;
- three options that fail every registered rule when combined with the references.

## 3. Odd-pair selection

Typical form:

```text
Four complete letter-number pair relations are shown.
Three follow one rule; select the pair that does not.
```

SSC CHSL 2025 official papers repeatedly use this format for mixed cluster-number operations, including:

- fixed letter vectors plus whole-number deltas;
- exact rational multipliers such as 1.5;
- multiplication by 2;
- cube-minus-one and near-square transforms;
- large fixed whole-number changes.

Decision:

```text
Strongly source-backed and admitted for permanent consideration.
```

The pilot requires:

- three complete options that uniquely establish one intended context;
- one near-miss option;
- exactly three options that satisfy the intended relation;
- no duplicate pair options;
- the odd pair must fail the intended rule rather than merely use unusual surface values.

## 4. Inverse and double-missing tasks

Potential forms:

```text
? : OUTPUT :: INPUT : OUTPUT
# : OUTPUT :: INPUT : %
```

Such tasks are source-real in letter analogy, but an exact recurring mixed letter-number official pattern has not yet been recovered.

Decision:

```text
Deferred; not included in the CP-008 task matrix.
```

They may also overlap ANA-CP-009 advanced/meta analogy when more than one missing component must be solved jointly.

## 5. Technical presentation proof

The non-QL pilot now checks every one of the 74 provisional contexts for:

```text
DIRECT_COMPLETION
EQUIVALENT_PAIR_SELECTION
ODD_PAIR_SELECTION
```

For equivalent-pair selection:

- two reference pairs uniquely identify the intended context;
- one option pair is correct;
- three option pairs create no complete registered relation with the references.

For odd-pair selection:

- three pairs follow the intended context;
- one pair fails it;
- the three valid pairs uniquely identify the context.

Technical yield does not itself create a permanent QL. Source ownership, exam frequency, analytics value, and editorial distinctness remain required.
