## Wave 2 candidate registry

Sixteen source-backed candidate families are admitted for executable discovery.

### Ordered-pair transforms and predicates

1. `PAIR_CONSECUTIVE_PRODUCT_DIRECTION` — `b = a(a + 1)` or the fixed reverse direction.
2. `PAIR_SQUARE_CUBE_DIRECTION` — the two entries are `n²` and `n³` in a fixed order.
3. `PAIR_CONSECUTIVE_CUBES_DIRECTION` — the entries are cubes of consecutive integers.
4. `PAIR_REVERSED_CUBE_DIRECTION` — cube the source, then reverse the result.
5. `PAIR_CUBE_MINUS_ONE_DIRECTION` — target equals source cubed minus one.
6. `PAIR_AFFINE_3X_MINUS_10_DIRECTION` — exact source-attested transform only.
7. `PAIR_AFFINE_7X_PLUS_3_DIRECTION` — exact source-attested transform only.
8. `PAIR_AFFINE_6X_PLUS_2_DIRECTION` — exact source-attested transform only.
9. `PAIR_BOTH_PRIME` — both entries are prime.
10. `PAIR_DIVISIBILITY_DIRECTION` — one fixed position is an exact multiple of the other.
11. `PAIR_PRIME_ABSOLUTE_DIFFERENCE` — the absolute difference is prime.
12. `PAIR_DIGIT_PERMUTATION` — the entries have the same digit multiset in a non-reversal order.

### Triple predicates

13. `TRIPLE_UNORDERED_ARITHMETIC_SET` — the sorted values form an AP although the displayed order does not.
14. `TRIPLE_ALL_PRIME` — every entry is prime.
15. `TRIPLE_SAME_DIGIT_MULTISET` — all entries use the same digits in different orders.

### Four-number group

16. `QUADRUPLE_REDUCED_RATIO_VECTOR` — all four positions share the same reduced proportional vector.

The four-number source pattern reopens the current arity assumption. Pair, triple and quadruple may still merge into one eventual odd-number-tuple contract, but arity four must be executable and audited before that conclusion can be frozen.

## Admission discipline

Wave 2 does not permit unrestricted formula search.

The registry admits only:

- conventional mathematical predicates;
- stable digit transformations;
- exact source-attested transforms recorded by name;
- bounded position-preserving tuple signatures.

The following remain rejected:

- fitting arbitrary `ma + c` values after seeing the options;
- unrestricted polynomial interpolation;
- inventing a different equation for each option;
- missing-number or source-to-incomplete-target tasks;
- diagram completion;
- one-off digit concatenation rules that cannot be represented by a stable reusable contract without further source recurrence.

## Expanded ambiguity gate

The new source-gap verifier is independent of the Wave 1 constructor. It:

1. reconstructs all original Wave 1 signatures from displayed tuples;
2. independently evaluates all sixteen Wave 2 candidate families;
3. replays the approved 1,200 Wave 1 questions;
4. records whether broader source-backed rules support the original answer or create another defensible answer;
5. writes structured diagnostics before any Wave 2 generator is admitted.

An existing question remains eligible for later freeze only when every supporting Wave 1 and Wave 2 rule points to the same answer.
