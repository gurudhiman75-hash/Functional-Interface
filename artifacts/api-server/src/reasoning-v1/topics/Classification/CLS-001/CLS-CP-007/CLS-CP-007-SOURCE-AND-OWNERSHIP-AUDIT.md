# CLS-CP-007 — Letter-Cluster and Explicit Word-Pattern Classification

Status: `SOURCE_BOUNDARY_ESTABLISHED__EXECUTABLE_DISCOVERY_OPEN`

## Purpose

This checkpoint covers Classification questions whose complete displayed answer objects are English letter-clusters of three to five uppercase letters. The learner must identify the cluster whose visible internal alphabet structure differs from the others.

The decisive task remains classification. CP-007 does not ask the learner to continue a sequence, infer and apply a hidden code, calculate a requested alphabet position, or transfer a source relation to a target cluster.

Permanent QL and solve-mode totals remain open.

## Source evidence recovered

The uploaded Classification sources contain a sustained letter-cluster section rather than isolated examples. Recovered source forms include:

- three-letter clusters with equal forward or backward gaps;
- clusters sharing one complete adjacent-gap signature;
- four-letter clusters with gap profiles such as equal outer gaps and a different middle gap;
- scaled gap profiles whose numerical size changes while the signed ratio remains the same;
- clusters whose selected positions are opposite letters;
- triples where the first two alphabet positions combine to produce the third;
- four-letter clusters governed by the relation between the first-half and second-half position totals;
- two adjacent letter-pairs inside one cluster sharing the same local movement;
- clusters with one common vowel count;
- repeated-letter arrangements and equality topology;
- cluster position totals and bounded internal position relations.

Representative source controls include the printed classifications around questions 197–224 in the dedicated chapter. Source wording and answer keys are evidence only; every retained state must be reconstructed and independently checked against the complete admitted registry.

## Ownership decisions

### Retained in CLS-CP-007

- direct odd-one-out among complete three-, four- or five-letter clusters;
- exact signed adjacent-gap vectors;
- exact absolute adjacent-gap vectors;
- bounded normalized signed-gap ratios;
- equality topology among adjacent gaps;
- cluster vowel count;
- repeated-letter equality pattern;
- complete cluster position sum;
- bounded position equations internal to one cluster;
- first-half versus second-half position-total relations;
- opposite-letter pairings at declared cluster indexes;
- local adjacent-pair gap relations inside one four-letter cluster;
- central-gap relations in a four-letter cluster;
- four- and five-option presentation when the learner contract is unchanged.

### Retained by CLS-CP-006

- one complete single letter as the answer object;
- one complete ordered letter-pair as the answer object;
- pair gap, pair sum, pair opposite status and pair vowel/consonant composition.

A three-letter cluster is not reduced to CP-006 merely because one of its internal checks uses a pair of positions. The answer object and proof must remain the complete cluster.

### Reassigned to Series

- next, missing or wrong cluster in one ordered progression;
- repeated cluster sequence where term position is essential;
- missing letters inside a serial pattern.

### Reassigned to Coding-Decoding

- infer a hidden transformation from examples and apply it to a target;
- encode or decode a word or cluster;
- recover a substitution table or cyclic transformation.

### Reassigned to Analogy

- source cluster is related to target cluster and the same relation must be transferred;
- select another cluster-pair following a supplied source relation.

### Reassigned to Alphabet Test

- directly report a position, distance, midpoint, count or rearranged output;
- count requested letter-pairs inside a word;
- sort or reverse letters and report the result.

### Deferred or rejected

- visual shape, symmetry or enclosure of letters without a renderer-safe uppercase font contract;
- unrestricted equations fitted after seeing the options;
- arbitrary modular classes or constants with no recurring exam authority;
- semantic English-word classification already owned by CP-001 or CP-003;
- mixed letter-number or symbol clusters reserved for CP-008.

## Canonical boundary test

A candidate belongs to CP-007 only when all conditions hold:

```text
1. Every answer option is one complete uppercase letter-cluster of length 3, 4 or 5.
2. The final learner action is to select the cluster that differs from the others.
3. The intended property is internal to each displayed cluster.
4. The property belongs to a bounded declared cluster-rule registry.
5. The complete compatible registry is independently enumerated.
6. No comparable admitted rule produces a different outlier.
7. Ordered progression, source-to-target transfer and hidden encoding are absent.
```

## Initial merge/split hypotheses

- all complete-cluster outlier families may merge if the answer object and mismatch proof remain one complete cluster;
- cluster length is likely an instance variable unless length changes the solver contract;
