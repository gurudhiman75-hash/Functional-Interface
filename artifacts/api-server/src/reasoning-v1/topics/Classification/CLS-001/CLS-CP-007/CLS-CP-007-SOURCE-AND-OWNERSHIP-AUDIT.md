# CLS-CP-007 — Letter-Cluster and Explicit Word-Pattern Classification

Status: `SOURCE_BOUNDARY_ESTABLISHED__SINGLE_CLUSTER_AND_CLUSTER_PAIR_DISCOVERY_OPEN`

## Purpose

This checkpoint covers Classification questions whose complete displayed answer objects are either:

1. one uppercase English letter-cluster of length three to five; or
2. one complete pair of equal-length uppercase letter-clusters whose internal transformation is evaluated entirely inside that option.

The learner must identify the complete option whose visible alphabet structure or option-local transformation differs from the others.

The decisive task remains classification. CP-007 does not ask the learner to continue a sequence, infer and apply a hidden code, calculate a requested position, or transfer a supplied source relation to an incomplete target.

Permanent QL and solve-mode totals remain open.

## Source evidence recovered

The uploaded Classification sources contain a sustained letter-cluster section rather than isolated examples. Recovered forms include:

- three-letter clusters with equal forward or backward gaps;
- clusters sharing one complete adjacent-gap signature;
- four-letter clusters with equal outer gaps and a different middle gap;
- scaled gap profiles whose numerical size changes while the signed ratio remains the same;
- clusters whose selected positions are opposite letters;
- triples where the first two alphabet positions combine to produce the third;
- four-letter clusters governed by first-half and second-half position totals;
- two adjacent letter-pairs inside one cluster sharing a local movement;
- common vowel counts;
- repeated-letter arrangements and equality topology;
- complete cluster position totals;
- complete cluster-pair options in which corresponding letters of the right cluster are expected to be alphabet opposites of the left cluster.

Representative source controls occur in the dedicated Classification letter section. Source wording and printed answer keys are evidence only; every retained state must be reconstructed and independently checked against the complete admitted registry.

## Ownership decisions

### Retained in CLS-CP-007 — complete single clusters

- direct odd-one-out among complete three-, four- or five-letter clusters;
- exact signed and absolute adjacent-gap vectors;
- bounded normalized signed-gap ratios;
- equality topology among adjacent gaps;
- cluster vowel count;
- repeated-letter equality pattern;
- complete cluster position sum;
- bounded position equations internal to one cluster;
- first-half versus second-half position-total relations;
- opposite-letter pairings at declared cluster indexes;
- local adjacent-pair gap relations inside one four-letter cluster;
- central-gap relations in a four-letter cluster.

### Retained in CLS-CP-007 — complete cluster-pair options

- direct odd-one-out among options where each option contains a complete left cluster and complete right cluster;
- position-wise opposite-letter transformation;
- exact corresponding position-sum vector used as a competing-rule proof;
- exact corresponding signed or absolute shift vectors used as competing-rule safeguards;
- complete direct-reversal or reversed-opposite checks used as ambiguity safeguards;
- four- and five-option presentation when the answer object and solve contract are unchanged.

A cluster-pair option remains Classification only when its relation is solved independently inside that same option. No source pair is transferred to a separate target.

### Retained by CLS-CP-006

- one complete single letter as the answer object;
- one complete ordered two-letter pair as the answer object;
- pair gap, pair sum, pair opposite status and pair vowel/consonant composition.

A three-letter cluster is not reduced to CP-006 merely because one internal check uses two indexes. The answer object and proof remain the complete cluster.

### Reassigned to Series

- next, missing or wrong cluster in an ordered progression;
- repeated cluster sequence where term position is essential;
- missing letters inside a serial pattern.

### Reassigned to Coding-Decoding

- infer a hidden transformation from examples and apply it to a target;
- encode or decode a word or cluster;
- recover a substitution table or cyclic transformation.

### Reassigned to Analogy

- a supplied source cluster-pair defines a rule that must be transferred to another incomplete pair or target;
- select a target completing a source-to-target relation;
- pair-to-pair comparison where the first pair is external evidence rather than one answer option.

A list of complete self-contained cluster-pair options is not Analogy merely because each option contains two clusters.

### Reassigned to Alphabet Test

- directly report a position, distance, midpoint, count or rearranged output;
- count requested letter-pairs inside a word;
- sort or reverse letters and report the result.

### Deferred or rejected

- visual shape, symmetry or enclosure without a renderer-safe uppercase font contract;
- unrestricted equations fitted after seeing the options;
- arbitrary modular classes or constants with no recurring exam authority;
- semantic English-word classification already owned by CP-001 or CP-003;
- mixed letter-number or symbol clusters reserved for CP-008;
- cluster-pair transformations with no repeated source authority beyond use as competing-rule safeguards.

## Canonical boundary test

A candidate belongs to CP-007 only when all conditions hold:

```text
1. Every answer option is either one complete cluster or one complete cluster pair.
2. Every cluster uses uppercase A–Z and a governed length.
3. The final learner action is to select the complete displayed option that differs.
4. The intended property is internal to that option.
5. The property belongs to a bounded declared rule registry.
6. The complete compatible registry is independently enumerated.
7. No comparable admitted rule produces a different outlier.
8. Ordered progression, source-to-target transfer and hidden encoding are absent.
```

## Merge/split hypotheses

- all complete single-cluster outlier families may merge if the answer object and mismatch proof remain one complete cluster;
- cluster length is likely an instance variable unless it changes the learner action;
- exact gap values and direction are instance properties;
- exact vectors, normalized ratios and equality topology require collision evidence before compression;
- position equations and opposite-pair topology may share an answer object but use different proof traces;
- complete cluster-pair classification should remain separate from single-cluster classification until answer-object and proof-topology audits justify otherwise;
- option count, answer position and difficulty remain instance properties;
- a reference-cluster matching task, if later source-backed, requires its own audit.
