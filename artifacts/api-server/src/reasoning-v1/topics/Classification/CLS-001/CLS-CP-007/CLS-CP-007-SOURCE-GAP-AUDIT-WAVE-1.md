- signed adjacent-gap vector versus absolute adjacent-gap vector;


The quality layer additionally proves that:

## Uncovered source answer object

The source inventory also contains options that are themselves complete pairs of letter-clusters. A representative printed form is structurally equivalent to:

```text
OPR–JKL
```

The learner is not given a source analogy followed by an incomplete target. Instead, every answer option is one complete cluster pair and the task is to identify the pair whose internal transformation differs.

This remains Classification when:

```text
1. every option contains a complete left cluster and complete right cluster;
2. the relation is evaluated independently inside each option;
3. all but one options share the relation;
4. the learner selects the complete outlier pair;
5. no source relation is transferred to a separate target.
```

It becomes Analogy only when one supplied pair defines a rule that must be applied to another incomplete pair or target.

