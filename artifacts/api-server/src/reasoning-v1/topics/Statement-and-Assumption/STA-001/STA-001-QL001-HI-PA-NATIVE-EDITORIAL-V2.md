# STA-001 QL001 Hindi/Punjabi Native Editorial V2

Status: **REVIEW CANDIDATE V2 / UNFROZEN**

V1 passed semantic parity but is explicitly not approved for localization freeze after direct learner-artifact review found translation-heavy terminology and several awkward constructions. V2 is an editorial overlay only; it does not change the frozen English authority or any semantic answer identity.

## V1 review findings corrected

- Hindi explanation terminology moves from `मान्यता / अंतर्निहित` to the more exam-natural `पूर्वधारणा / निहित`.
- Punjabi moves from translation-heavy `ਮਾਨਤਾ / ਅੰਤਰਿਨਿਹਿਤ` to `ਧਾਰਨਾ / ਨਿਹਿਤ`.
- repeated generic explanation lead is removed; explanations now begin directly with candidate decisions.
- awkward portal, verification-call, projector/adapter, help-line and map-pin wording is naturalized.
- Hindi `लेक्टर्न` is replaced with the more familiar `पोडियम`; Punjabi uses `ਪੋਡਿਅਮ`.
- Punjabi `ਯੂਜ਼ਰ` is replaced with `ਵਰਤੋਂਕਾਰ` where it occurs.
- mixed/awkward `ਫਾਲੋ ਕਰੋ`, equipment-setup wording and temporary-bay rationale are rewritten.
