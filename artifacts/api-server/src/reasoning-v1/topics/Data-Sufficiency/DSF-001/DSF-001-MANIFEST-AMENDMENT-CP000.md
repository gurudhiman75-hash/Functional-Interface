## Identity policy

`DSF-QL-001` represents the learner task and solver contract, not a source chapter or wording template.

The following remain solve-mode, adapter, source-profile or rendering metadata and do **not** create new QLs by themselves:

- Number System vs Algebra vs Ranking/Order source domain;
- scalar, categorical, rank, identity, direction, relation, comparison or count target;
- Banking five-option vs reordered five-option display;
- SSC four-option display profile;
- names, numbers, story surface or difficulty;
- option position/order;
- English wording variants that preserve the same semantic class.

## Semantic freeze

A statement set is sufficient when:

1. at least one valid underlying world survives; and
2. every surviving world gives the same normalized answer to the asked target.

Complete-world uniqueness is **not** required.

Statement I, Statement II, and their conjunction must each be evaluated from the same base problem state.
