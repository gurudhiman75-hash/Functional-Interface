# WOR-001 — Word & Dictionary Order

WOR-001 is a deterministic, multilingual, review-only Reasoning chapter for English A–Z dictionary ordering.

## Implemented scope

- `WOR-CP-001` — complete ascending/descending order and first/last word;
- `WOR-CP-002` — kth position, rank, predecessor, successor and middle word;
- `WOR-CP-003` — insertion, new rank, inserted-word predecessor, misplaced word, incorrect adjacent pair and partial order;
- `WOR-CP-004` — hard common-prefix versions of ordering, position, rank and insertion.

The runtime supports `en-IN`, `hi-IN` and `pa-IN`. English words remain unchanged logic tokens in all three locales. Instructions, task conclusions and explanations are localized.

## Runtime guarantees

- explicit case-insensitive ASCII comparator; no `localeCompare()` dependency;
- separate selection-sort verifier that does not call the generator comparator;
- deterministic seeded word-set construction from **30 curated families / 360 globally unique provisional words**;
- state-derived difficulty: generated states are scored structurally and resampled deterministically until they satisfy the requested difficulty band;
- exactly four unique options and one answer;
- distractor misconception IDs derived from the actual wrong transformation rather than option position;
- broad Easy vocabulary plus structurally deeper Medium/Hard common-prefix states;
- task-specific explanations in English, Hindi and Punjabi;
- explicit source-evidence status on every prototype and generated question;
- commit-fresh Markdown/JSON review packs generated by CI rather than stale checked-in snapshots.

## Source-evidence states

- `PYQ_SUPPORTED` — directly supported by sampled competitive-exam paper evidence;
- `PLATFORM_SUPPORTED` — supported by established exam-preparation material, with direct PYQ pinning still desirable;
- `EXPLORATORY_SOURCE_GAP` — mechanically valid but not eligible for permanent-QL freeze until recurring source evidence is established or the pattern is merged/removed.

CP-003 remains executable for review, but all six CP-003 contracts are currently `EXPLORATORY_SOURCE_GAP`.

## Lifecycle

- permanent QLs: unallocated;
- lifecycle: `REVIEW_ONLY`;
- corpus editorial state: `PROVISIONAL_REVIEW`;
- Question Studio adapter: implemented but not discoverable;
- Question Studio visibility: disabled;
- public release: disabled;
- native Hindi/Punjabi dictionary collation: not implemented.

The chapter must remain review-only until source-gap saturation, corpus/editorial approval, native-language review and permanent-QL decisions are complete.

## Verification

The remediation CI gate runs:

1. `wor-001.test.ts` — comparator, deterministic generation, independent solver parity, requested-vs-derived difficulty, multilingual parity, option diagnostics, ambiguity controls and review rendering;
2. `wor-001-source-evidence.test.ts` — source-evidence governance and release-lock checks;
3. `wor-001-corpus.test.ts` — 30-family/360-word uniqueness, tier reachability and prompt-set diversity;
4. review-pack generation and artifact upload;
5. API production build.

Review files are generated from the exact tested commit as the `wor-001-review-packs` workflow artifact.
