# WOR-001 — Deep Audit Wave 02: Diversity Model

Date: 2026-10-01

Status: `STRUCTURAL_AND_OBJECT_DIVERSITY_AUDIT_IN_PROGRESS`

## Audit interpretation

WOR-001 is not a puzzle chapter where every question should have a different deduction graph.

For simple dictionary-order authorities, the recurring solve rule is itself the exam construct. Artificially inventing extra rule topology merely to reduce a normalized-template repeat rate would make the chapter less exam-real.

Therefore Wave 02 separates diversity into two layers.

### Layer A — lexical-instance diversity

Across every frozen prototype and supported difficulty:

- visible word/cluster sets must vary strongly across seeds;
- source families must not collapse onto a narrow subset;
- answer positions must cover the full option range;
- real-word and Banking reservoirs must remain broadly reachable.

### Layer B — multi-stage parameter diversity

For Banking CP005 multi-stage authorities, the audit also normalizes away the actual letters and measures variation in:

- normal/reverse order;
- left/right rank direction;
- requested rank;
- local/global character index;
- left/right character direction;
- alphabet offset;
- transformation type;
- original/transformed answer mode.

This is the correct WOR analogue of puzzle-topology diversity.

## Existing pool authority

The chapter already contains:

- 60 real-word families / 720 globally unique words;
- 18 Easy, 20 Medium and 22 Hard real-word families;
- 60 Banking cluster families / 720 globally unique clusters;
- 20 Easy, 20 Medium and 20 Hard Banking families;
- existing corpus tests require >=90% unique prompt sets over 900 classic samples;
- existing Banking pool tests require >=95% unique visible sets over 1,000 samples.

Wave 02 does not expand the pools blindly. It first proves whether the live frozen prototypes actually consume that breadth.

## New large-sample diagnostic

For every frozen release-candidate prototype × supported difficulty, Wave 02 generates 180 deterministic samples and requires:

- >=85% unique lexical instances;
- all valid answer positions observed;
- at least 10 classic source families or 12 Banking source families reached in the sample;
- Banking parameter-shape floors scaled by solve-contract complexity.

If this gate exposes a narrow live path, remediate the generator or pool routing. If it passes, do not churn a 1,440-object reservoir merely to increase raw counts.

## Next step

After the diagnostic is green, inspect the measured rows and continue with difficulty realism / late-character discrimination and distractor quality.
