## Source families to normalize before freeze

The later source pass must independently normalize examples of:

- one-sided word rearrangement;
- one-sided number rearrangement;
- mixed word-number machines;
- two-ended/double shifting;
- alternating actions;
- numeric operation machines;
- word/alphanumeric transformation machines;
- multi-stage Banking-Mains machines;
- box/table/cell machines;
- missing/reverse/step-identification forms.

Each normalized source record must capture exam/source identity, task surface, machine semantics, step behavior, query family and ownership disposition.

## Ownership decisions already safe

### Alphabet Test

Direct alphabet position, alphabet scanning, static rearrangement and mixed-sequence scanning remain Alphabet Test unless the learner must infer a sequential machine from demonstrated states.

### Coding–Decoding

Direct code mapping, artificial-language mapping and static symbol substitution remain Coding–Decoding. A stepwise machine can transform tokens, but the decisive burden must be tracing the sequential state rule.

### Mathematical Operations

Interchanged operators and symbol arithmetic remain Mathematical Operations. Arithmetic inside an IOP machine is a component, not an ownership transfer, only when the machine trace is the dominant reasoning burden.

### Number System / Simplification

Digit properties and arithmetic retain Quant ownership when asked directly. IOP may use them only as source-backed transformation keys inside a sequential machine.

### Series

Sequence continuation remains Series. Repeated whole-state transformation remains Input–Output.

### Seating Arrangement / Puzzles

Constraint satisfaction over an unknown state remains Seating/Puzzles. Deterministic transformation of a supplied state remains Input–Output.

## Merge/split rule

Two temporary prototypes should merge when they differ only by presentation or parameter while preserving the same learner inference and step semantics.

They should remain separate when any of these materially changes:

- number of actions per visible step;
- blocked versus alternating schedule;
- simultaneous versus sequential placement;
- token transformation versus movement only;
- forward versus genuinely reverse inference;
- line versus box/table topology when the topology changes reasoning;
- answer semantic requiring a different proof.
