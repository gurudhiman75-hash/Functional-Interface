# SER-CP-002 — Multiplicative and affine recurrence discovery plan

## Objective

Extend `SER-001` with bounded first-order integer recurrences while keeping source saturation and permanent identity allocation open.

The candidate pool contains:

```text
UNIFORM_MULTIPLICATIVE_RATIO
a(n + 1) = multiplier × a(n)

AFFINE_MULTIPLY_THEN_ADD
a(n + 1) = multiplier × a(n) + addition, where addition is non-zero
```

The uniform family is deliberately included in the same independent-solver pool as the affine family. A generated affine item is accepted only when it cannot also be solved as a simpler zero-adjustment ratio sequence.

## Temporary templates

Each candidate authority is exercised through next, interior-missing, previous and wrong-term tasks.

```text
SER-CP-002-TMP-001..004  UNIFORM_MULTIPLICATIVE_RATIO
SER-CP-002-TMP-005..008  AFFINE_MULTIPLY_THEN_ADD
```

These are disposable discovery IDs. They allocate no `SER-QL-*` identities and do not predetermine the final QL count.

## Safe domains

- integer multipliers from 2 through 4;
- zero adjustment only for the uniform family;
- non-zero adjustments from -12 through 12 for the affine family;
- positive integer starts;
- five to seven canonical terms;
- generated and option values bounded to absolute value 100,000;
- constant, repeated, unsafe and ambiguous sequences rejected;
- wrong-term corruptions rejected if they duplicate a valid term.

Negative ratios, fractions, decimals, alternating signs and division-led forms remain outside this prototype pending ownership and source review.

## Independent solver

The solver receives only the task kind and displayed sequence.

For every multiplier and adjustment in the complete candidate pool it:

1. derives possible starts from each visible position;
2. reconstructs the complete recurrence;
3. counts mismatches against displayed terms;
4. retains exact matches for completion tasks;
5. retains one-mismatch matches for wrong-term tasks;
6. rejects unless exactly one recurrence remains.

The accepted solution reports the inferred rule family, start, multiplier, adjustment, target position, displayed answer semantic and correct replacement.

## Options and explanations

- exactly four unique integer options;
- deterministic exact answer placement;
- wrong-term distractors are other displayed terms that satisfy the recurrence;
- completion distractors model ignored adjustment, wrong multiplier and operation-order errors;
- explanations state the recurrence, show the decisive calculation and analyse every option;
- learner-facing text contains no internal IDs or unresolved placeholders.

## Audit contract

The executable audit generates:

```text
8 temporary templates × 120 seeds = 960 questions
```

It verifies:

- deterministic replay;
- lifecycle and permanent-allocation locks;
- expected rule-family ownership;
- uniform-versus-affine collision rejection;
- independent-solver parameter and answer agreement;
- exactly one compatible recurrence from the full pool;
- four unique options and one answer;
- next, missing, previous and wrong-term shapes;
- recurrence integrity and bounded integers;
- complete learner explanations;
- exact four-position answer balance;
- exact Easy, Medium and Hard reach;
- at least 80 mathematical fingerprints per temporary template.
