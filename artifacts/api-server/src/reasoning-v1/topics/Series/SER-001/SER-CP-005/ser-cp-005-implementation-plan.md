## Independent solver contract

The independent solver evaluates all ten source representations in one pool, groups equivalent projected sequences by canonical authority, and rejects every displayed series unless exactly one canonical projection remains.

For each accepted question it independently proves:

- the required answer;
- the target position;
- the correct replacement for wrong-term tasks;
- the canonical authority;
- all source representations that generate the same projection;
- one-authority ambiguity closure.

A representation collision is therefore retained as evidence rather than counted as a second authority.
