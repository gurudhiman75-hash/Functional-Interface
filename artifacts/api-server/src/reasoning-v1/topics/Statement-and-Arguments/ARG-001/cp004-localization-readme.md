# ARG-001 CP004 — Trilingual Localization Parity

CP004 localizes the certified CP003 variableized Statement & Arguments engine to Hindi and Punjabi without changing semantic authority.

For every `(QL, seed)` in the 2,048-slot semantic cycle, EN/HI/PA must share:
- template ID
- variant index/key
- semantic slot
- archetype
- difficulty
- argument order/reversal
- argument strengths
- answer class
- correct index

Only learner-facing statement, arguments, options and explanation are localized.

CP004 does **not** register the package in Question Studio. CP005 remains the integration checkpoint.

Question Bank, tests, mocks, public delivery and automatic learner publication remain locked.
