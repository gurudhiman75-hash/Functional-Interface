## Solver contract

The generator owns a complete hidden canonical scene and an explicit missing rectangular patch. Learner stimulus removes the hidden fragment and displays only the surrounding context plus the missing-region boundary.

For every option the independent completion oracle:

1. translates the option fragment into the missing patch;
2. recomposes it with the unchanged context;
3. computes the canonical semantic fingerprint of the reconstruction;
4. compares it with the hidden complete-scene fingerprint;
5. requires exactly one matching option.

SVG strings are never answer authority.

## Distractor contract

Options are misconception-owned rather than random visual noise. V1 includes crossed endpoints, reversed direction, parallel substitution, wrong curvature, shifted curve peak, reversed curve direction, pairwise rather than common junction, offset junction, wrong junction arm, outer-only contour matching, inner-direction error, contour offset and marker-position errors.

Semantic option uniqueness and the existing two-unit spatial perceptual uniqueness gate are both required before delivery. Ambiguous/perceptually colliding seeded states are rejected and regenerated rather than credited as content.
