5. COA includes an evidence-sufficiency-before-intervention dimension.
6. CAE must preserve exact causal-state distinctions instead of collapsing independent/common-cause outcomes.
7. ASM is a cross-subject format; source-section ownership is mandatory and unrestricted world-knowledge truth judgement is prohibited.
8. Permanent QLs must be allocated only after source saturation, merge/split review and executable collision proof.
