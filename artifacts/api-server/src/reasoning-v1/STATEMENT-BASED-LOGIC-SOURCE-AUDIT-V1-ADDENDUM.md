## 3. ARG-001

Banking evidence materially strengthens this chapter beyond the initial audit:

- IBPS PO Mains memory-based papers contain three-argument strong/weak sets;
- SBI Clerk Mains memory-based papers contain both two- and three-argument sets;
- SBI PO Mains material uses the standard important-and-directly-related strength convention;
- SIDBI Grade A memory-based material shows that opposing pro/con consequences can both be strong.

Consequences:

- `candidateCount` is source-profile metadata;
- two and three arguments are both supported Banking presentations;
- pro/con symmetry must be audited;
- strength requires relevance **and materiality**;
- competing material consequences may need explicit conflict evidence.

ARG V1 state is upgraded from `PARTIAL SATURATION` to `STRONG PARTIAL SATURATION`.
