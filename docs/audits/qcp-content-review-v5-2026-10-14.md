The reviewed corpus contains 25 publisher-practice items from the two pages in the source ledger. ## Implemented contract

Use `generateQcp001Question({ sourceMode: "SOURCE_CATALOG", sourcePattern: "BA22-03", sourceScale: 1, language: "hi" })`. Pattern and scale are optional; deterministic seed selection fills them. Scale is 1–3, except the older-age pattern BA24-02 is limited to 1–2. These are 59 finite mathematical variants, not thousands of distinct authored problems. Seeds vary answer ordering and identity; profiles and languages add package forms. Existing modes and default selection remain compatible.

All 20 canonical cases match the adjudicated numeric fixtures and exclusive comparison classes. EN/HI/PA stems, exact fractional/surd value displays, worked derivations and four distractor diagnoses are produced. Mixed-surd equations retain both roots in each operand. The reverse urn count discards the impossible negative total. The train/man example explicitly says the faster man passes the train. The probability example BA24-10 explicitly requires a single colour; the original mixed-colour reading is retained only as a ledger annotation.

The catalogue is owned by the QCP composition adapter. It reuses shared exact rational and quadratic algebra, PNC combinations, the INT compound-interest inverse, TMW efficiency solver, MEN quadrilateral area solver and TSD medium solvers. Traceability lists authorities actually called. Other multi-step patterns compose exact rational arithmetic; they do not claim to call a closed topic solver merely because a topic name appears in the ledger. This does not reopen any closed source chapter.

## Verification and limits

The catalogue sweep checks 7,080 packages, 20 canonical known-answer cases, all 59 scale variants, 354 deterministic replays and malformed source/prompt/owner/root/request mutations. It also runs the existing foundation, word-problem and additional-family audits. The independent catalogue oracle uses closed forms without importing production rational derivations or root solving. Bounded floating projections permit only relative roundoff (1e-12) in numeric parity; displayed rational/surd forms remain exact. These small finite domains contain no unresolved near-equality comparisons.

The type-check import baseline has ten existing MEN/Probability diagnostics. QCP introduces no new diagnostics. Global type checking is not claimed clean. Hosted checks and merge evidence are recorded in the pull request.

The finite implemented catalogue is technically frozen, and the 25-item reviewed source ledger is disposition-complete. Human native-language approval and live verification are deferred to the user. Every package remains UNREVIEWED, not stored, ineligible, hidden from Studio and not publicly publishable. Further publisher material requires a new, separately identified corpus rather than silently widening this freeze.
